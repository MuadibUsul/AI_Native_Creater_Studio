## 当前安全边界

- 浏览器中的图形示意只用于设计对照；真实作品表现、价格、任务与发布状态必须由 SDK/API 返回，没有数据时显示未知或空态。
- 所有数据库测试必须显式设置独立的 `ANCS_TEST_DATABASE_URL`，且目标数据库名称须为测试库。不得连接 `ancs_dev` 运行集成清理。
- 先前开发库测试数据损失的恢复工作按用户要求延后处理。代码和参考设计文件仍在；此事不应以复制演示数据进入开发库的方式掩盖。
- 不购买、调用真实付费 Provider 或进行真实平台发布。推送、部署与生产操作仍按对应任务的授权和发布门执行。
