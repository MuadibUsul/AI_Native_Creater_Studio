# 0018 采纳 V6：AI 原生剪辑的产品定义与路线，作为当前唯一权威

- 状态：生效（2026-10-11，项目所有者在多轮讨论后明确："组成一个 V6 版本……以这个更清晰的版本为准，继续开发推进"）
- 前一裁决编号：`0017-ffmpeg-media-graph-final-render.md`
- 来源：`docs/V06/ANCS_v0.6_Product_Architecture.md`（以下简称 V6）

## 决定

1. **V6 是当前唯一的产品与架构权威。** 冲突优先级：项目所有者后续明确要求 → V6 → V5 架构裁决（0011—0017）→ v0.4 需求参考 → 更早的规范。
2. **V5 架构骨架继续有效：** 编辑内核、操作日志与投影器、引用图、RenderPlan、FFmpeg 后端、工作流引擎、配置注入、Provider 种类与生产禁 Mock、Edge 安全层。V5 的 M5 及以后的路线由 V6 §11（V6-0—V6-8）取代。
3. **推进顺序改为体验闭环优先：** 每个里程碑以可演示的用户体验收尾，并有实测指标；后端只做该体验需要的部分。V6-1（共看片室最小闭环：旅游 Vlog）是第一个产品里程碑。
4. **范围裁决（项目所有者已确认）：**
   - 通用型剪辑软件，中英双语，面向全球；
   - **AI 的剪辑、导演与调度能力是通用的，必须做到最强、最通用**：对各组件的调用和整体编排不依赖类型模板或策略包，导演与调度代码不按类型分支，所有组件经统一工具目录供 AI 自由组合（V6 §6.1—6.5）；
   - **策略剪辑是给用户的可选小功能**：策略包只是数据，用户选用时作为风格参考进入 AI 上下文，不限制 AI 的工具与编排；不选策略时 AI 同样要剪出好片（V6 §6.6—6.7）；
   - 首批类型依次为旅游 Vlog、知识解说（小林说风格）、娱乐（Mr.Beast 风格），作为通用能力的打磨与评测目标（评测以不选策略为主），不是写死的流水线；
   - "指着画面说一句就改好"为核心体验，"第一版就像样"同等重要；
   - 实时语音对标 OpenAI 流式对话体验，中英文都支持；
   - 移动端定位为批注式审片 + 统一局部重渲；
   - 保留文章转视频；
   - 数字人与嗓音保留，放在第二步；
   - 蒸馏器同时支持上传文件和粘贴链接，版权由项目所有者负责；
   - **代码生成视频列为核心能力**；重特效先报预估成本；
   - 预览可以低分辨率，但必须看得清。
5. **冻结（代码保留、不再扩展）：** 运营后台扩展、CMS 回写、播客、平台发布、企业功能；V4 N 系列任务账本冻结为历史，`spec:check` 继续校验其一致性但不新增条目。
6. **下线计划：** 旧 Scene/Article 渲染流水线和旧多页面编辑器，在 V6-5（文章转视频建立在组合模型上）和 V6-1（新编辑器外壳）就绪后下线。
7. **交付记录：** 每个 V6 里程碑记录在 `docs/V06/milestones/<id>.md`（目标、验收、实测数据、交接）；CI 全量校验、真实证据优先、浏览器操作验证等原则不变。

## 影响

- `AGENTS.md` 的权威说明与启动步骤更新为以 V6 为准。
- V5 M4-3（工作流引擎 + 素材工程终渲染）作为 V6-0 收尾交付。
- 已 `VERIFIED` 的 N 任务证据保持不变，不因路线调整清零。

## 回滚

本裁决只改变权威顺序与推进顺序，不删除代码或数据。若项目所有者调整方向，以新的明确要求和新裁决为准。
