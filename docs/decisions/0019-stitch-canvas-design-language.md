# 0019 界面改用"画布"设计语言（参照 Google Stitch），取代 ANCS Monochrome 的部分禁令

- 状态：生效（2026-10-15，项目所有者明确要求："参照 https://stitch.withgoogle.com/ 的交互方式 继续设计项目。要求界面风格要趋于一致，目前的界面太丑了。"）
- 前一裁决编号：`0018-v6-adoption.md`
- 依据：AGENTS.md 冲突优先级"项目所有者后续明确要求 → V6 → V5 → v0.4"。本裁决修改 v0.4 设计系统（`docs/V04/ANCS_v0.4_Design_System.md`、`ANCS_v0.4_Design_Tokens.json`）中与所有者要求冲突的条目；未提到的条目继续有效。
- 设计说明与测得数值：`docs/design/stitch-redesign-2026-10.md`。

## 决定

1. **交互模型对齐 Stitch。** AI 是主角：
   - 首页是一个居中的大输入框（"你想做一条什么样的视频？"），起点（素材 / 文章）、画幅、语音都在输入框里，下面是建议与最近作品；
   - 共看片室改为"左侧 AI 对话栏 + 右侧点阵画布"：对话、试改、报价卡、风格与制作规则、输入框都在左栏；画布中央是看片屏幕，左缘是浮动工具条（添加素材 / 框选画面 / 素材 / 学风格 / 快捷键），底部是浮动的播放与时间带卡片，右上角是轻顶栏（审片、任务、语言、主题、导出）；
   - 语音是画布底部的浮动胶囊（Issue #9 已有，改成玻璃质感），AI 工作时有"正在想"的流光提示。
2. **视觉语言改为"画布"（ANCS Canvas）：** 深色优先（默认仍跟随系统），近黑点阵画布、浮起的圆角面板、胶囊按钮、Google Sans 字体。所有页面共用同一套 token 与共享原语（`ui-tokens.css` 统一改写旧底座的按钮、输入框、面板、徽标、分段、侧栏、顶栏），不再三套外壳三种样子。
3. **放开的禁令（只在受控范围内）：**
   | v0.4 禁令 | 现在允许的范围 | 仍然禁止 |
   |---|---|---|
   | 装饰渐变 | AI 身份色（蓝→紫→青）只用于：AI 标识（✦）、AI 工作中的流光/描边、主输入框聚焦光晕、首页主视觉背后的一团极光；一律经 `--ui-ai-*` token | 普通按钮、卡片、KPI、数据图表、文字正文用渐变；彩虹语音波形 |
   | 装饰背景模糊 | 玻璃质感只用于浮在画布或视频上的控件（顶栏、工具条、语音胶囊、浮动时间带、对话框遮罩）；一律经 `--ui-glass-*` token | 内容卡片、列表、表单用模糊 |
   | 非中性色 | 仅上述 `--ui-ai-*` 与玻璃 token 的定义可以出现非灰色值 | 在规则里直接写彩色十六进制 |
   | 小圆角（8–16px） | 按钮与筛选为胶囊；输入框 14px；卡片 20px；大容器 28px | — |
4. **继续有效的约束：** 所有文字与背景组合 ≥ 4.5:1，控件边界与图标 ≥ 3:1（指定色对由测试逐对校验）；状态不只靠颜色（文字、形状、描边）；`prefers-reduced-motion` 下流光、极光漂移、进入动画全部停止；媒体像素、作品主题、用户内容的颜色不受界面主题影响；不连续播放装饰动画（极光静止，只有 AI 工作中才有流光）。
5. **字体：** Google Sans 以 SIL Open Font License 1.1 开源（googlefonts/googlesans），仓库内置拉丁与拉丁扩展子集（`apps/web/public/fonts/google-sans/`，附 `OFL.txt`）；中文回退到系统字体（PingFang SC / 微软雅黑 / Noto Sans CJK）。v0.4 "不得内置专有字体"一条不受影响（该字体不是专有字体）。
6. **测试守卫随之改写：** `ui-tokens.test.tsx` 从"界面 CSS 不得出现渐变、模糊、彩色"改为"渐变、模糊、彩色只能出现在 `--ui-*` token 定义里，规则只能引用 token"；`--ui-ai-gradient` 的使用位置有白名单。

## 影响

- `docs/V04/ANCS_v0.4_Design_Tokens.json` 改名 "ANCS Canvas"，主题色值、圆角、字体更新，新增 AI 与玻璃 token；`apps/web/src/app/ui-tokens.css` 同步。
- 共看片室、首页、审片、新建、形象与声音、工作区页面按新布局与样式调整；功能、接口、权限、数据不变。
- 浏览器验收脚本中依赖旧布局位置的步骤随之更新（依旧以角色与名称定位）。

## 回滚

本裁决只改界面层（token、样式、布局组件），不改契约、领域与数据。回滚即恢复 token 文件与上述界面文件。
