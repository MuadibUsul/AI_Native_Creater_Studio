## 决定

1. **两种协作模式，一个工程内核。** 在共看片室（交互剪辑）之外新增**自主制作**：用户开工前一次交代需求、风格（可选）、硬约束、预算与可用能力，AI 完成素材理解 → 构思 → 粗剪 → 自检修复 → 交付；之后可以进入共看片室在同一个 `ProjectDocument` 上精修。两者共享操作日志、`RenderPlan`、资产、版本历史与成本台账。

2. **工作方式与内容来源是两个独立维度，不得合成一个枚举。** 内容来源仍是 `FOOTAGE_EDIT / HYBRID / GENERATIVE`（`productionPolicy.mode`）；工作方式是新增的**审批档位**（`productionPolicy.autonomy.approval`）：
   | 档位 | 含义 | 付费生成 | 采用改动 |
   |---|---|---|---|
   | `ASK_EACH` 逐项审批（默认） | 现状：每轮结果是试改，由用户采用 | 每次报价由用户确认 | 用户 |
   | `AUTO_SAFE` 自动审批 | 常规剪辑、字幕、免费工具由 AI 直接执行 | 仍由用户逐次确认（单次超阈值、超总预算、数字人 / 克隆声音、覆盖或删除原素材都属于高风险） | 自主制作结束时由系统采用（通过自检门禁后） |
   | `FULL` 完全授权 | AI 全程自主，用户只看成片 | 单次不超过单项上限、累计不超过总预算时可由系统代为确认（审计记录引用用户签署的授权版本） | 同上 |

   - **总预算是硬上限，任何档位都不得超过**（所有者 2026-10-19 已确认）。总预算按美元微单位计，包含 AI 模型调用成本与付费生成。
   - **授权是"预算上限 + 允许的能力"，不是无限支出或无限身份使用。** 数字人与克隆声音另外需要身份档案里有效的授权记录（V6-7，只增不改、可撤回）；审批档位不能授予身份权利。
   - 授权必须由用户显式签署（谁、何时、哪一版）；没有签署时一律按 `ASK_EACH` 处理。

3. **与 V6 "付费生成先报价、用户确认"规则的共存（0.1 §8.2 要求的正式裁决）：** 共看片室的每一轮、以及 `ASK_EACH` / `AUTO_SAFE` 档位下的自主制作，付费生成照旧逐次确认；只有 `FULL` 档位、且报价在签署的上限内时，系统才可代为确认。不满足时自动降级（用现有素材、图解或留白替代），继续其它工作，不得擅自付费，也不得伪称完成。首个里程碑（V6-9）的自主制作**不调用付费生成**，代为确认的路径随 V6-10 的预算预留与对账一起实现。

4. **规划视图不是第二套真相。** `NarrativeBlueprint`（全局蓝图）与 `SceneContract`（场景契约，含 0.2 的剪辑意图 `intents[]`）是可重建、带版本的规划记录，引用工程版本号；时间线仍只由 `ProjectDocument` + 编辑操作 + 版本日志决定，组合表仍只经投影器写入（R11 不变）。规划记录过期（工程版本变了）时如实标注，不阻塞编辑。

5. **编辑候选层是派生视图。** 剪点候选（句末、停顿、镜头边界、静音段）、可延伸的前后余量（handles）与禁止切断区间，由现有统一媒体索引经纯函数派生，带证据与来源；理解层只标注、不判定"有用 / 无用"，取舍只属于导演。

6. **自主采用的边界。** 自主制作结束时，草稿先过自检门禁（`review_draft` 无阻断项、服务端硬约束校验通过），才在 `AUTO_SAFE` / `FULL` 档位下由系统采用；采用是一次普通的版本提交（操作者记为 AI 自主制作 + 授权版本），可以整体撤销。门禁不通过时保留为试改并在交付报告里写明原因。

7. **交付报告必须诚实。** 每次自主制作结束输出报告：用了哪些原片、哪些是生成内容、哪些约束没能满足、实际花费（未定价的调用如实标为未定价）、自检发现与处理。不伪称成功。

8. **评测先于默认。** 导演提示词、工具目录变更沿用 V6 §6.5：以不选策略的通用能力为主做评测；自主制作在真实模型上的评测与真实素材验收会产生费用，须先征得所有者同意，未做之前在里程碑记录里标为"脚本导演 / 测试替身验证"，不计为真实验证。

9. **Proposal 0.2（待评审）的处理。** 只先做两项不依赖人类剪辑工程文件、只提供依据与建议的部分：
   - A0 剪辑意图：场景契约下的 `intents[]`（固定枚举 + 理由 + 被放弃的备选），导演输出蓝图时填写；
   - B0 节奏谱：只算切点密度与语速两项，给出实测曲线与目标的偏差，进交付报告，不自动改片。
   品味先验（CutPrior，AP-16～18、21）在工程文件的来源与授权解决前暂停；风格规格、虚拟观众、审片校准、结构锦标赛等待评审结论。所有模块都要做消融，相对基线无增益就不进默认流程。

## 里程碑（接在 V6-8 之后，按体验交付）

| 里程碑 | 交付的体验 | 关键工作（提案编号） |
|---|---|---|
| **V6-9 自主制作最小闭环** | 上传素材 → 写一句需求、设好档位与预算 → AI 自己剪出可播放、可继续编辑的第一版 → 看交付报告 → 进共看片室精修 | 审批档位与预算门禁（AP-03）；编辑候选层与原声字幕（AP-01）；导演蓝图与场景契约 + 剪辑意图（AP-04、0.2 A0）；主动回看沿用现有看素材 / 看成片工具（AP-02）；串行闭环、自检、按档位采用、交付报告（AP-05）；节奏谱 B0 |
| V6-10 制作图与并发 | 长素材分章并行，局部失败不阻塞其它章节 | 动态任务图、资源池限流、预算预留与对账、有限重试与降级、整片审片后定向重规划（AP-06～AP-10） |
| V6-11 补镜头与一致性 | 发现缺镜头，按"原素材 → 变体 → 图解 → 授权生成"顺序补救 | AP-11～AP-15 |

## 影响

- 契约：`productionPolicy` 增加 `autonomy`（档位、总预算、单项上限、签署记录）；新增规划记录、编辑候选、交付报告、节奏谱契约。
- 数据：新增规划记录表与自主制作运行表（迁移）；`projects.production_policy` 只扩展字段。
- 领域：新增纯函数（预算门禁、编辑候选、节奏谱）与导演工具（写蓝图 / 场景契约、查剪点候选、按原声加字幕）；Agent 运行时增加自主制作用途，导演代码依旧不按视频类型或策略分支（裁决 0018）。
- 界面：新建页增加"让 AI 自己剪完"的一次性交代（需求、档位、预算），共看片室显示自主制作进度与交付报告；中英双语。

## 回滚

自主制作是新增路径：档位默认 `ASK_EACH`，不签署授权时行为与现状一致。回滚即隐藏入口并停用新工作流；新增表与字段可保留（只读、不影响现有路径）。
