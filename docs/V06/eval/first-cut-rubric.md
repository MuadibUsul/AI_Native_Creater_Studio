# 初剪评测：人工评分标准与自动指标（V6 §6.5）

初剪质量以**人工评分为主**，自动指标只抓机械问题。评测以**不选策略**的通用能力为主；选用了策略的用例额外评"风格贴合度"，不替代通用项（裁决 0018）。

## 怎么跑

```bash
# 前置：本地 Postgres / Redis（同集成测试），pnpm build 已执行
ANCS_TEST_DATABASE_URL=postgres://… ANCS_TEST_REDIS_URL=redis://… \
  node scripts/eval-first-cut.mjs                       # 默认 evals/first-cut/smoke.json，脚本导演（SCRIPTED）
node scripts/eval-first-cut.mjs --set evals/first-cut/travel.json --model anthropic --export
```

| 参数 | 说明 |
|---|---|
| `--set <file>` | 用例集（格式见 `evals/first-cut/travel.example.json`；素材路径相对仓库根目录，原片放在已被忽略的 `Videos/`） |
| `--model scripted\|anthropic` | `scripted` = 脚本导演，只验证框架闭环，**不代表剪辑质量**；`anthropic` 需要环境变量 `ANTHROPIC_API_KEY`（可选 `ANCS_AGENT_MODEL`） |
| `--export` | 每个用例导出一条成片（真实 FFmpeg），供人工评分观看 |
| 环境变量 `DEEPGRAM_API_KEY` | 有则转写真实语音（句子完整性指标才可评估），无则该指标为"无法评估" |

输出在 `.artifacts/eval/first-cut/<runId>/`（已被 `.gitignore` 忽略）：`report.json`、`report.md`（自动指标）、`rating-sheet.md`（人工评分表）以及 `--export` 的成片。

## 金样集怎么建

1. 每个用例一组你有权使用的真实旅游素材（3–20 条，含有人声的片段、空镜、明显的高光画面），放在仓库根目录的 `Videos/`（已在 `.gitignore`），**不提交原素材**。
2. 写一句真实的用户请求（例如"剪一条 30 秒的冰岛旅行短片"），需要时写目标时长 `targetSeconds`。
3. 同一组素材至少跑两次：不选策略 1 次（主评测）；需要时再选一个策略包跑 1 次（只额外评风格贴合度）。
4. 每次改提示词版本（`AGENT_PROMPT_VERSION`）、换模型或改工具目录后重跑同一集，和上一次的报告并排比较。

## 人工评分（每项 1–5 分，写一句理由）

| 项 | 5 分 | 3 分 | 1 分 |
|---|---|---|---|
| 叙事完整 | 有交代环境的开场、展开、最高光、有意收尾 | 结构可辨但某一段缺失或顺序别扭 | 片段堆叠，看不出开始和结束 |
| 节奏与剪点 | 镜头长度有变化且服务内容，剪点落在动作/句子/节拍上 | 节奏平均、偶有拖沓或过急 | 闪帧、拖沓、剪在话说一半 |
| 镜头选择 | 最好的画面都用上了，废镜头（抖动、黑场、对焦失败）没进来 | 漏掉个别好画面或混入少量废镜头 | 好画面没用上，废镜头明显 |
| 声音连续与音量 | 人声清楚、环境声连续、无突兀静音或爆音 | 个别跳变 | 声音断裂或缺失 |
| 满足这句话 | 时长、内容、语气都按要求 | 大体满足，有一处偏离且没说明 | 没按要求 |
| 整体 | 愿意直接发 | 改一两处再发 | 要重剪 |
| 风格贴合度（仅选了策略时） | 明显是所选风格（镜头长度、转场、声音习惯） | 部分像 | 看不出所选风格 |

两位评分人独立打分；分差 ≥2 的项讨论后取共识。报告里只写评分人编号，不写姓名。

## 自动指标（`packages/domain/src/agent-eval.ts`）

与 AI 自检工具 `review_draft` 用同一套检查（评测与自检口径一致）。每个指标给出原始值与 0–1 分；缺少分析层（例如没有转写）时为"无法评估"，不填分。

| 指标 | 原始值 | 计分 |
|---|---|---|
| `length_fit` | 成片秒数 | 1 − \|实际 − 目标\| / 目标；请求没有目标时长时无法评估 |
| `black_residue` | 用到素材黑场的次数 | 每次 −0.5；没有黑场检测时无法评估 |
| `sentence_integrity` | 剪在句子中间的次数 | 每次 −0.25；没有转写时无法评估 |
| `structure_cleanliness` | 闪帧 + 画面空洞 + 长度与内容不符（+ 空时间线 ×3） | 每次 −0.34 |
| `sound_continuity` | 有声素材的画面却听不到声音的次数 | 1 − 次数 / 画面片段数 |
| `shot_variety` | 同一段素材被用两次的次数 | 每次 −0.25 |
| `footage_coverage` | 用到的素材 / 全部素材 | 用到 60% 及以上记满分 |
| `style_pacing_fit`（仅选了策略） | 镜头时长中位数 | 落在策略的常见区间内记满分，偏离按区间宽度扣分 |

`automaticScore` 是可评估指标的平均分，只用于同一金样集前后版本的比较，**不是质量结论**。

## 证据要求

- 脚本导演（`--model scripted`）跑出的报告只证明评测框架闭环可用，不能写成"初剪质量通过"。
- 真实模型的报告要记录：模型 ID、提示词版本、每个用例的耗时与成本（报告自动写入）、人工评分表。
