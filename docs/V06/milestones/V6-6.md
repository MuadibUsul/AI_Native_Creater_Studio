- https://www.youtube.com/watch?v=4uQskImIBIY

1. **服务端下载（推荐用于部署）：** Worker 机器装 `yt-dlp` 与 FFmpeg，网络放行 `www.youtube.com`、`youtube.com`、`m.youtube.com`、`youtubei.googleapis.com`、`*.googlevideo.com`，配置
   `ANCS_REFERENCE_FETCH_CMD=yt-dlp --no-playlist -f mp4/bestvideo*+bestaudio/best -o {output} {url}`；然后在共看片室"从参考视频学风格"里直接粘贴这三个链接。先在本机验证：
   `ANCS_REFERENCE_FETCH_CMD='…' node scripts/distill-reference.mjs --json style.json <三个链接>`。
   YouTube 可能拒绝数据中心 IP（要求登录验证）；这时用方式 2。
2. **下载后上传：** 在自己电脑上下载这三条视频，用"添加视频文件"上传（或 `node scripts/distill-reference.mjs 文件1 文件2 文件3`）。

参考视频的使用须符合平台条款与版权（界面里已提示"参考视频的版权由你负责；系统只记录来源，只用来分析手法"）。拿到测量结果后应把实测数据补进本文（每条的镜头数、中位镜头时长、每分钟剪辑、卡点比例与随机对照、BPM、黑场、色彩与响度，以及合成的风格说明），并人工核对说明是否像这位博主。

## 设计要点

- **只说测得到的。** 剪辑 DNA 的每个数值都来自 FFmpeg 实测：硬切（场景分数 > 0.3，相邻剪点至少 0.2 s）、黑场（`blackdetect`，排除被硬切夹住的暗镜头，只算真正的淡入淡出）、剪点 = 硬切 ∪ 黑场中点、镜头时长分布（中位、P20–P80）、10 段节奏曲线、色彩（`signalstats`：亮度、饱和度、对比、冷暖）、响度（`ebur128`）与静音占比（`silencedetect`）、节拍（单声道 11 kHz PCM → 起音包络 → 自相关选速度 + 相位对齐；置信度 = 峰值/零延迟）。卡点比例 = 落在节拍 ±70 ms 内的剪点比例，同时给出随机剪的对照比例（节拍密度 × 窗宽），置信度低于 0.3 不算有节拍。说话占比与语速只在参考视频有**完成的**转写时计算（未配置/失败/进行中都算"没测"，不当作"没有说话"）。景别、推拉缩放、变速、字幕样式、叠化等**没有测**，在风格的可信度说明和结果卡里如实列出。
- **说明由谁写写清楚。** 没有配置模型时用规则版说明（数值直接来自统计，中英两份）；配置了导演模型时，模型看测量结果和镜头中点抽帧（最多 6 张）写名称、说明、结构建议、给 AI 的要点与评分项，数值仍只来自测量，模型的画面观察标为推断；模型回复不合格式 → 明确失败（`STRATEGY_COMPOSE_FAILED`），不自动无限重试。
- **风格只是数据。** 结果是一个 `DISTILLED` 策略包（剪辑 DNA + 旋钮 + 说明 + 评分项 + 来源与可信度），与内置预设同一结构；选用后只作为这一轮对话的 `optional_style_strategy` 上下文，不改变工具集合，导演与调度代码没有按策略分支（裁决 0018）。
- **工作流：** `REFERENCE_DISTILL`（获取 → 测量 → 撰写 → 保存），工作区级（不属于任何作品）。获取：上传的资产校验就绪与类型；链接直接下载（拒绝内网/保留地址，逐跳检查最多 5 次重定向，限制大小），网页交给部署方配置的下载命令（只继承代理/证书环境变量，硬超时），下载的视频存为工作区素材库草稿资产（30 天保留类，许可证"未知"，记录来源链接与最终链接；重放复用）。保存：包 id 由工作流 id 派生，重放不重复保存。每条最多分析 15 分钟、最多 5 条。
- **可编辑：** `PATCH …/strategy-packs/:packId` 改名称/说明/要点/结构建议（版本 +1），内置预设 409。
