## 设计要点

- **新进程 Realtime Gateway（`apps/realtime`）：** 浏览器麦克风 → AudioWorklet 重采样为 16 kHz PCM16 → WebSocket → 网关 → 流式识别端口。网关只做识别、断句与指代绑定；**不读写工程、不调用 AI、不替用户采用**。一句话说完交还浏览器，浏览器把它当作一轮对话发给 API（与打字同一路径、同一套权限/幂等/预算）。
- **鉴权：** 开麦前浏览器向 API 申请语音会话（N05-01 已有，需编辑权限），只拿到短期凭证；网关用同一把 `ANCS_VOICE_SESSION_SECRET` 校验（伪造 401、会话已关闭/过期 409）；浏览器来源白名单（403）。长期 Provider Key 只在网关进程。
- **音频时钟与指代（V6 §5.2）：** 音频时钟 = 已发送的采样数；每次选择或播放位置变化都带着时钟发一条指向样本。识别结果带逐词时间，网关在说出"这个/这里/this/here"那一刻（允许 0.3 秒内紧跟的点击）取指向；"从这里到这里"两处合成范围；没有明确选择时用当时的播放位置（前后各 1 秒）；没有指代词用开口时的选择；什么都没指 = 整条视频。证据种类如实带回（`DEICTIC_WORD` / `PLAYHEAD_AT_WORD` / `SELECTION_AT_START` / `NONE`），纯函数 `packages/domain/src/realtime-attention.ts`。
- **半句话与改口：** 以"但是/不对/除了/逗号"或 "but/except/and" 结尾的话先保留（`held`），后半句来了合成一句，等不到（4 秒）再交出；转写按修订号替换，不做字符串追加。改口（"删掉这段……不对，是把音乐去掉"）由通用导演按最后的说法执行（提示词 `director-v5` 一条通用说明）。
- **三种停止分开：** 停止说话（只停朗读，开口即自动打断）、停止进行中的一轮（"停止"）、撤回试改（"撤回"）——互不替代；朗读不影响试改与工程。
- **双语：** 会话语言跟随界面；识别参数按语言选模型（中文 nova-2 / 英文 nova-3，可配置）；中文转写去掉字间空格。
- **供应商端口：** `StreamingSpeechRecognizer`（`packages/contracts/src/realtime.ts`），Deepgram 实现在网关；国内供应商（区域路由）实现同一端口即可，界面与协议不变。
