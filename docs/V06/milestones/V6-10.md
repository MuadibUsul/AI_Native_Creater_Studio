## 要交付的体验

1. 上传一段长素材（例如 40 分钟），写一句需求，交给 AI。
2. 卡片上先看到 AI 定好的章节，然后逐章变化：
   - 「第 1 章 开场 · 完成」
   - 「第 2 章 · 剪辑中」
   - 「第 3 章 · 没剪成（原因）」
3. 一章失败不挡其它章节。AI 把完成的章节拼成第一版、通看一遍、修好接缝，再按档位交付。
4. 交付报告如实写明：哪些章节完成、哪一章没剪成及原因、各章花了多少。
5. 之后可以只重做没剪成的那一章（S5），也可以照常在共看片室里精修同一个工程。

## 现状核对（2026-10-29，读代码得出）

| 事实 | 出处 | 对设计的影响 |
|---|---|---|
| 自主制作是三步串行：等素材 → 一轮导演（最多 60 步）→ 交付 | `autonomous-production.ts` | 一轮导演要从头剪完整部长片，步数和上下文都不够 |
| 工作流引擎是线性步骤、每次运行只有一个推进者；可以 `WAIT_UNTIL` 轮询 | `workflow.ts` | 并行 = 父运行启动多个子运行，再轮询等它们结束 |
| Worker 一次只执行一个任务 | `apps/worker/src/main.ts` | 一章的导演占满一个任务。单个 Worker 时各章实际是排队执行；要真正并行，需要多个 Worker 进程，或给 Worker 加任务槽（S4） |
| 内核状态包含工程的全部序列；序列可以有父序列 | `kernel/timeline/types.ts`、`project_sequences.parent_sequence_id` | 每章放在主序列下的一个子序列里；各章草稿互不相干 |
| 共看片室只认最早的顶层序列（`parentSequenceId IS NULL`） | `studio.ts` | 子序列不会被当成作品，也不出现在共看片室 |
| 导演工具都按 `context.sequenceId` 读写 | `agent-operations.ts`、`agent-tools.ts` | 一章的导演只需把序列换成本章的子序列，工具目录不变 |
| 嵌套序列片段目前不能渲染（`nested sequence clip not compiled`） | `kernel/render/compile.ts` | 不用"把章节作为嵌套片段放进主序列"，改为**拼装**：把各章内容复制到主序列 |
| 有按给定范围与 id 原样重建片段的内核操作（`restoreClipId` 等） | `composition-edits.ts` | 拼装可以写成纯函数，产出普通编辑操作，再由内核验证 |

## 设计

### 何时分章

只按**可用素材总时长**判断，不按视频类型：就绪素材总长 ≥ `CHAPTER_MODE_MIN_SECONDS`（暂定 8 分钟）才分章；否则沿用 V6-9 的单轮路径，行为不变。

### 流程

工作流 `AUTONOMOUS_PRODUCTION` 升一个版本，旧版本的运行按旧定义走完：

1. **等素材**：不变。
2. **定计划**：一轮规划用的导演。
   - 只允许读与写计划：和讨论批注一样，在执行时拦下改动类工具，工具目录不变；
   - 用 `plan_production` 写出覆盖素材的场景契约；
   - 预算不超过剩余的 15%。
3. **分章并行**：每个场景是一章（最多 12 章）。每一章：
   - 建一个子序列；
   - 建一条章节记录；
   - 启动一个子运行 `AUTONOMOUS_CHAPTER`：同一个通用导演，在本章子序列上剪；交代里带本章的场景契约与整部的蓝图；预算是分到本章的份额。

   父运行按资源池限流：同时最多 N 章在剪（配置项）；一章结束就启动下一章；用 `WAIT_UNTIL` 轮询，直到所有章都结束。

   某章失败：有限次重试（默认 1 次）后记为失败，其它章照常进行（AP-08）。
4. **拼装**：内核纯函数 `assembleChapters`，按计划顺序把完成的各章复制到主序列的草稿里，产出普通编辑操作，并用内核模拟验证。
   - 复制的内容：片段（含随画面的声音、特效层、讲述）、字幕；
   - 偏移量 = 前面各章的长度，所以不会留空档也不会重叠；
   - 没剪成的章节**不拼进去，也不留占位**，在报告里写明。
5. **通看收尾**：在主序列上开一轮导演，草稿就是拼装结果，用于整部审片、修接缝、补字幕（AP-09 的第一步）。预算是剩余部分。
6. **交付**：沿用 V6-9 的门禁、按档位采用、交付报告。报告加上各章结果。

子序列只承载各章的草稿，从不被采用，所以作品里只有主序列的改动。拼装完成后，子序列标为已用完（S3 决定删除还是留作排查记录）。

### 预算（AP-07 的模型花费部分）

- 父运行开始前，用 V6-9 的门禁核对剩余预算。
- 按阶段预留：
  - 计划 ≤ 15%；
  - 各章按场景时长分配 60%；
  - 收尾拿剩下的全部。前面的阶段没花完的，也流向收尾。
- 每一章的上限就是它的预留额；对账用各轮实际记录的花费，现在每次模型调用都已计入。
- **付费生成（完全授权下代为确认报价）不在本里程碑**，放到 V6-11 与补镜头一起做。分章阶段照旧不调用付费生成。

### 不变的规则

- 导演与调度代码不按视频类型或风格分支；分章只看素材时长。
- 工具目录不变。
- 作品的改动只经提案与采用；采用前重新核对授权；运行期间用户改过作品，就不覆盖，留作试改。
- 循环与日志只追加（裁决 0022 第 6 条）。

## 进展

### S1 分章拼装（完成）

`packages/kernel/src/timeline/assemble.ts`：`assembleChapters(state, { mainSequenceId, chapters }, ctx)`。只读状态，产出普通编辑操作。

**它做什么：**
- 各章紧接着排在主序列现有内容之后。偏移按主序列时基精确计算，不用浮点。
- 轨道按"种类 + 名称"对应：主序列已有就复用，没有就新建一次，各章共用。所以特效轨（`FX…`）、讲述轨各自归位。
- 画面与随画面的声音完全一致的一对，用一条插入重建。
- 分别剪过、长度不同的一对（`split_av_cut` 产生的 J / L 剪辑），分别插入后，用底层的 `update_clip` 恢复同一个关联。`set_av_link` 要求等长，所以不能用它。
- 片段的变换、裁切、透明度，只为与缺省值不同的项发操作。
- 字幕只平移在序列上的位置。词的时间是相对字幕的，原样保留。绑在片段上的字幕，改绑到复制出来的那条片段。

**拼不了就报错，不悄悄丢掉。** 遇到下面这些内容，报 `CHAPTER_CONTENT_UNSUPPORTED`，并带上是哪一章：
- 变速片段；
- 嵌套序列片段；
- 独立音频区域；
- 组件自定义参数；
- 按语义点定时的字幕。

章节时基与主序列不同，报 `CHAPTER_TIMEBASE_MISMATCH`。现有导演工具都不会产生这些内容。

### S3 编排（完成）

**工作流 `AUTONOMOUS_PRODUCTION` v2**，Worker 同时注册 v1，升级前开始的运行按 v1 走完：

1. **等素材**：不变。
2. **定计划**：就绪的视频 / 音频素材总长不到门槛（缺省 8 分钟），直接走 V6-9 的一轮剪完。否则：
   - 进入 `PLANNING`，开一轮 `AUTONOMOUS_PLAN`；
   - 预算是剩余的 15%，同时不超过"剩余 − 一次调用余量"；
   - 改动类与付费工具在执行时被拦下，工具目录不变；
   - 计划少于两个场景，就退回一轮剪完。计划作为上下文交给那一轮，规划的花费照样计入。
3. **建章**：每个场景一章，最多 12 章。每章：
   - 一个主序列的子序列，同帧率，轨道照主序列的种类、名称、位置建；
   - 自己的会话；
   - 一条章节记录。

   各章预算合计为剩余的 60%，按场景素材时长分配。
4. **分章并行**：父运行用 `WAIT_UNTIL` 轮询。
   - **资源池**：同时最多 N 章在剪，缺省 3；一章结束就开下一章。
   - **每章一个子运行 `AUTONOMOUS_CHAPTER`**：同一个通用导演，在本章子序列上剪。交代里带本章的场景契约与整部的蓝图（`phase: CUT_CHAPTER`），草稿留在轮次上，不建提案。
   - **失败**：一章失败后用新的一轮重试，缺省 1 次，用完记为失败，其它章照常进行。
   - **超时或预算用完**：不再开始新的章，正在剪的取消。
5. **拼装**：
   - 完成的各章草稿一起在当前版本上模拟，再用 S1 的 `assembleChapters` 拷进主序列，结果在当前版本上验证；
   - 某章放不上去，或含拼装器不认识的内容，这一章记为失败并写明原因，其余照常拼；
   - 拼装结果成为收尾那一轮的初始草稿；各章位置记在步骤输出里。
6. **通看收尾**：沿用 `direct` 步骤，`phase: FINISH_CHAPTERS`，交代里带各章的状态与位置。
7. **交付**：沿用 V6-9 的门禁与按档位采用。报告增加：
   - 逐章结果：拼进了 / 空 / 失败，含位置与原因；
   - `CHAPTER_NOT_ASSEMBLED`；
   - 花费改为整个运行的全部轮次：规划、各章每次尝试、收尾。

**花费与轮次 id：**
- 规划、各章每次尝试的轮次 id 由运行、章号、尝试次数决定。步骤重试时找回同一轮，不重复付费；花费也能逐轮汇总进授权预算。
- V6-9 那一轮的 id 算法不变。

**停下：** 停下会取消父运行。收尾时：
- 取消还在剪的子运行；
- 没结束的章记为已取消；
- 规划那一轮若还在进行也一并结束。

**导演提示词升到 `director-v10`**，只多一条："交代里有 phase 时按该阶段的说明做"。

**不按视频类型分支：** 分章只看素材时长；每一阶段都是同一个通用导演与同一套工具，差别只在交代。
