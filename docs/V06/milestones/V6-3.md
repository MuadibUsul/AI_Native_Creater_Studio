- 依据：V6 §7.2（代码生成特效）、§7.3（特效优先代码生成）、§6.3（统一工具目录）、§11；裁决 0018；AGENTS.md（Custom Motion 代码不得在无隔离进程执行、纯素材项目禁生成约束在服务端生效）

## 设计要点

- **特效 = 一层透明视频片段。** 特效代码（模板库里的可信代码，或部署方开启后 AI 当场写的代码）+ 参数 + 种子，在 Worker 的隔离子进程里由 Remotion 无头浏览器渲染成**带透明通道**的图层（ProRes 4444 → 无损转 PNG 编码 QuickTime，rgba），存成资产（`CUSTOM_MOTION_RENDER`，来源 `GENERATED`），作为普通片段放在最上层的特效轨（`FX1`…）上：区域 = 片段变换（中心锚点、缩放 = 区域尺寸、位移 = 区域左上角），时间 = 片段范围。预览分段缓存、终渲染（FFmpeg 媒体图 `format=rgba` + `overlay format=auto`）、试改/采用/撤销全部沿用时间线的同一套机制，没有第二条渲染管线。
- **统一工具目录里的三个组件（裁决 0018）：** `list_effects`（模板与参数、时间线上已有的特效、项目规则是否允许、能否写代码）、`add_effect`（模板或代码 + 参数 + 时间 + 区域 + 种子）、`update_effect`（改参数/种子/区域/时长：同一段代码重渲，不再写代码）。缺省值取本轮指向：区域 = 框出的画面区域，时间 = 所指时间的起点。导演与调度代码没有按视频类型或策略分支；提示词 `director-v6` 只加了一条通用说明。
- **指画面：** 对话指向新增 `frameRegion`（0–1 归一化，原点左上；与审片框选同一形状 `frameRegionSchema`）。共看片室"框选画面"在当前帧上拖框；没选时间时以框选那一帧起 1 秒为"这里"的时间。语音：说"这里"时只框了区域 → 区域配上说话那一刻的播放位置（`realtime-attention.ts`）。
- **项目制作规则（服务端约束）：** 程序化特效属 `graphics.procedural`，素材工程（FOOTAGE_EDIT）缺省关闭。`add_effect`/`update_effect` 每次渲染前服务端校验，未允许时如实回给 AI（`PRODUCTION_POLICY_BLOCKED`），不渲染、不落资产。用户在顶栏"特效：关/开"显式切换（`PATCH /workspaces/:id/projects/:projectId/production-policy`，`project:write`，只改"允许"开关不改工程模式，写工作区事件 `project.production_policy.updated`，含改前改后）。
- **AI 写的代码（能力探测后开启，`ANCS_EFFECT_CODEGEN=enabled`）：** 先过 Custom Motion 四道门禁（静态分析 / 类型检查 / 沙箱评估 / 抽帧），不通过把门禁报告交还 AI 修改，不自动重试；通过后才渲染。模板库代码在测试里逐个过同样四道门禁。渲染页面里浏览器能力（fetch/XMLHttpRequest/WebSocket/document/window/localStorage/定时器/Function…）被遮蔽为 undefined；原型链逃逸由静态门禁拦截；渲染子进程只继承白名单环境变量（无连接串、无密钥）。
- **确定性：** 渲染键 = 代码哈希 + 参数 + 种子 + 尺寸 + 帧率 + 帧数；同键复用已有图层（崩溃续跑与"同样再放一次"不重复渲染）；`random(key)` 为确定性随机数（门禁沙箱与渲染页面同一语义）。
- **尺寸与格式：** 图层按区域在工程画布上的像素渲染，最长边 ≤ 960（终渲染按区域放大）；PNG/QuickTime 比 ProRes 小约 3 倍、比 QuickTime Animation（RLE）在渐变上小约 2.5 倍；给 AI 一张 ≤ 480 px 的中间帧预览图。

## 未验证与待办

- **真实模型：** 需要 `ANTHROPIC_API_KEY`。真实导演是否会在合适的时候选对模板、区域与时长，以及**写特效代码的质量与一次通过率**，都要用真实模型评测后再决定是否开启 `ANCS_EFFECT_CODEGEN`（V6 §7.2"模型能力探测与模板回退"）。评测方法：同一组"画圈 + 一句话"请求分别走模板与写代码，记录门禁通过率、渲染耗时、人工评分。
- **"再来一个"出候选：** 工具已支持换种子/换模板（`update_effect.seed` / `add_effect.seed`），界面还没有并排候选选择。
- **选区跟随：** 特效固定在框出的区域；跟随运动物体需要物体跟踪层（统一索引已有 `OBJECT_TRACK` 种类，缺跟踪驱动）+ 变换关键帧。
- **自动配音效：** 需要音效库或音效生成（`allowGeneratedSfx`，随 V6-8 的生成供应商与报价）。
- **参数面板：** 改参数目前经 AI（"换成蓝色"），不调用 AI 的直接参数编辑面板待做（同一 `update_effect` 语义，前端直接调用需要一个 API 端点）。
- **图层清理：** TODO（why：未采用提案留下的特效图层按 Custom Motion 渲染的缺省保留类 `KEEP_FINAL` 保存；dependency：提案产物绑定与引用边覆盖特效资产；interface：提案撤回/过期时把未被任何版本引用的 `CUSTOM_MOTION_RENDER` 资产降为 `DRAFT_RENDER_30D`）。
- **渲染进程网络隔离：** 特效页面已遮蔽浏览器网络能力、代码过静态门禁、子进程无凭据；操作系统级网络隔离（容器网络策略 / gVisor）仍属部署层待办（runbook §8 第 3 条）。
- **分辨率：** 图层最长边 960，1080p 成片里放大显示；需要更高清特效时提高上限（渲染耗时与存储随像素增长）。
