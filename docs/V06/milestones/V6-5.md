# V6-5 文章转视频：讲述配音 + 图解卡

- 状态：从文章开始 → AI 讲述 + 图解卡 → 试改 → 采用 → 导出的全链路已交付（真实浏览器 + 真实语音合成 + 真实特效渲染 + 真实 FFmpeg 预览/终渲染）。**语音合成只验证了本地 flite（英文、音质基础）与进程协议**，供应商配音（尤其中文）待你接入；AI 为**脚本导演**，真实 Claude 写讲述稿与选图解的质量待密钥评测；旧 Scene/Article 流水线**尚未下线**（见文末）
- 依据：V6 §4.2（文章转视频保留，建立在组合模型上）、§7.2（代码生成的图解动画）、§11（V6-5：文章拆解、代码生成图解、TTS/讲述轨、知识解说评测集与可选风格预设、旧 Scene 流水线下线）；裁决 0018；AGENTS.md（数据图表不得使用虚构数值；外部调用只经 Worker 端口；子进程环境白名单）
- 目标体验：贴一篇文章或讲稿 → 得到带讲述和图解动画的解说视频 → 在共看片室里接着改

## 设计要点

- **文章是"详细的提示词"，不是流水线。** 新建时贴文章，原文存进工程简报（`brief.article`），按段编号进入 AI 上下文（超过 12,000 字的部分用 `read_article` 按段读），标注为参考数据。AI 自己决定讲什么、怎么分段、配什么图——导演与调度代码没有按"文章类型"分支；系统提示（`director-v7`）只加了三条通用说明（图解卡、文章作为主要来源且不得添加文章里没有的说法和数字、讲述的用法与能力边界）。
- **讲述 = 时间线上的一条音频。** `add_narration` 把讲述稿逐句交给 Worker 装配的语音合成引擎，句间 0.25 s，拼成一条 24 kHz 单声道 WAV（经真实探测）存为 `VOICE_AUDIO`（来源 GENERATED），放到讲述轨（`VO1`…，音频轨，`linkAudio=false`）；连续调用自动接在已有讲述后面。每句一条字幕，时间来自逐句合成的真实位置，`speechAnchorId` 绑定讲述片段；`remove_narration` 连同字幕一起移除。同一段讲述（引擎、声音、语速、句子相同）复用已有音频。
- **规则与能力如实。** 合成语音受 `speech.generate`（`allowGeneratedSpeech`）约束：素材作品默认关闭，顶栏"配音：关/开"显式切换；从文章开始的作品按新建时"AI 配音讲述"的选择。字幕受 `captions.generate` 约束。每个声音声明会说的语言，讲述稿的语言（含汉字 → zh，否则 en）没有声音会说时明确拒绝，不拿英文声音硬读中文。没装配引擎时工具明确报"没有配置配音"。合成失败不自动重试。
- **图解卡 = 代码生成的特效图层。** 新增 6 个整画面模板：标题卡、要点、柱状图、大数字、步骤、引用（带底色；`backdrop=none` 时叠在素材上），与 V6-3 特效同一套工具、门禁、沙箱渲染与时间线机制；模板参数新增文字类型（长度上限、多项用 `|` 或换行分隔），图层最长 30 s。六个模板都过了 Custom Motion 四道门禁。
- **数据图的数字必须出自文章。** 柱状图、大数字（`numbersFromSource`）的每个数字都必须在文章里出现过（"1,200" 与 "1200"、"3.50" 与 "3.5"、全角数字视为同一个数）；推算、四舍五入出来的新数字被拒绝（`EFFECT_NUMBERS_NOT_IN_SOURCE`，告诉 AI 哪几个数找不到）；没有文章的作品不能用数据图。
- **自检认得图解卡与讲述。** 整画面带底色的图解卡算画面（不报"画面空洞"），讲述音频不算素材（不参与黑场/静音/重复使用等素材检查），时间线视图给讲述片段标讲述稿开头。
- **可选风格预设"知识解说"**（`builtin:explainer`，只是数据）：钩子 → 背景 → 每个要点一张卡 → 一句结论；旋钮"信息密度""图解（图文混合 / 多用数据）"。
