# V6-7 数字人与嗓音（含付费生成的共用流程）

- 状态：我的形象与声音（参考照片 + 声音样本 + 只增不改的授权记录）→ 作品里说"用我的数字人说这段" → AI 报价 → 你确认 → 预算预留 → 生成一次 → 拉回自有存储 → 有声画中画试改 → 结算，全链路已交付并在真实浏览器 + 真实 FFmpeg 上验证。**生成供应商在实测里是 FFmpeg 测试替身**（卡片上标明"测试替身"）；HeyGen（数字人）与 Fish Audio（你的声音、讲述配音）的适配器已写好、按两家公开 HTTP 接口用本地替身服务测过协议，**真实服务尚未验证：本环境的网络策略拦截了 `api.heygen.com`、`upload.heygen.com`、`api.fish.audio`**。AI 为**脚本导演**
- 依据：V6 §4.3（档案里建一次形象和声音，项目自动继承；只在明确要求时调用，授权记录可查）、§7.3（生成内容带成本预估）、§10（成本模型）、§11（V6-7：身份档案、数字人/声音供应商接入、授权记录）；裁决 0018；AGENTS.md（客户端不持有 Provider Key；供应商链接不当永久文件；付费生成不得无限自动重试；Mock ≠ 真实 Provider）
- 目标体验：档案里放一张照片、一段声音并授权 → 在任何作品里说"用我的数字人在右下角说「……」" → 看到报价卡、确认 → 你的形象用你的声音出镜，成为试改

## 设计要点

### 付费生成的共用流程（V6-7 与 V6-8 共用）

1. **AI 只能报价。** 统一工具目录新增 `list_generation_options`（READ：可用的生成类型、每秒价格区间、单次上限、语言、制作规则、身份档案就绪情况、工作区预算、最近报价）与 `quote_generation`（GENERATE、metered：只建一份报价——供应商、模型、时长区间、费用区间、30 分钟有效期）。确认、预留、生成、结算都不在工具里，AI 无法代为确认。系统提示（`director-v8`）加了一条通用说明：付费生成最贵、最不可控，优先用素材、剪辑和代码特效；只报价、告诉对方价格，不能说已经生成。工具与提示不按视频类型分支。
2. **你确认。** 共看片室对话下方出现报价卡：做什么、约几秒、预计 $a–$b、供应商模型（测试替身标明）、本期预算还剩多少；"确认生成（最多 $b）"/"不要了"。确认接口带上卡片上的报价上限（与报价不一致 → 409），只有编辑者能确认。
3. **预算预留（fail-closed）。** 沿用工作区预算与 Credits 预留（行锁下原子判定，并发确认同一报价只预留一次）；工作区没设生成预算 → 拒绝确认。1 Credit = US$0.01（规划假设，`MICROS_PER_CREDIT`，定价是业务决定）。
4. **生成一次。** 确认后开一轮"确认生成"（`purpose=GENERATE`，与 AI 轮次同一会话、同一互斥规则，在当前试改上继续），由 `PAID_GENERATION` 工作流执行：生成步骤只执行一次、不可重试；调用供应商前记下 `provider_called_at`，之后任何中断（超时、进程崩溃、Worker 丢租约）都进入**待对账**，绝不再次调用，预留保持。规则与授权在报价、确认、调用前各查一次——撤回立即生效。
5. **拉回自有存储。** 产物写入对象存储并真实探测（不可解码 → 按"已扣费"记录），资产来源 GENERATED、保留类 `KEEP_PAID_GENERATED`，元数据记供应商、模型、任务 id、请求与授权快照。
6. **放进试改。** 生成层放在 GEN 轨（数字人画中画缩到右下角；有声音时人声放 AV 轨并与画面关联），成为这一轮的提案：和任何修改一样预览、采用、撤回、撤销。放不下（期间你改了工程）时如实说明，片段留在素材里。
7. **结算。** 供应商报告的费用 → 按实结算；没报告 → 按报价上限结算并在回复与卡片里标明；明确未扣费的失败 → 释放预留；失败但已扣费 → 按扣费结算。

### 数字人与嗓音

- **身份档案** = 创作者身份 + 参考照片（形象）+ 声音样本（声音）。参考素材是工作区资产（照片必须是图片、样本必须是音频，且已就绪）。
- **授权只增不改。** `identity_consent_records`：每次授权或撤回追加一条（谁、何时、本人还是获授权的他人、声明版本 `v6-7.1`、所用语言与该语言声明文本的 SHA-256、针对的参考素材版本）。数据库触发器拒绝改写和删除（只允许随身份档案级联清理、用户注销时置空操作人）。当前有效 = 该类最近一条是授权且针对的正是当前参考——**换了照片或声音样本就要重新授权**。声明中英文同义，界面展示当前版本，提交的版本不是当前版本 → 409。
- **生成数字人片段**需要：制作规则允许生成画面与合成语音、形象与声音都已授权、供应商会说讲稿的语言、讲稿时长不超过单次上限。报价按讲稿语速估时长（中日韩按字约 4.5 字/秒，其他按词约 2.6 词/秒，外加 0.6 秒），费用区间按 0.8–1.3 倍时长计。
- **HeyGen + Fish Audio 适配器**（`ANCS_AVATAR_DRIVER=heygen`）：用声音样本在 Fish Audio 找到/建立私有声音（按样本内容哈希命名，同一样本只建一次）→ 合成讲稿 → 超过报价时长上限就停（不调用 HeyGen、不扣费）→ 上传照片（talking photo）与音频 → 提交生成（明确 4xx 拒绝 = 不扣费；连接中断/5xx = 结果不明）→ 轮询（失败 = 不扣费；超时 = 结果不明）→ 下载（签名链接，不带密钥）。HeyGen 接口不报美元费用，平台按报价上限结算并标明；缺省报价依据是 V6 §10.1 的规划区间（$2–6/分钟），部署方按套餐用 `ANCS_AVATAR_OFFER_JSON` 覆盖。
- **Fish Audio 讲述配音**（`ANCS_NARRATION_DRIVER=fish`）：V6-5 的讲述工具换成 Fish Audio 合成（多语言，含中文），声音由部署方在 `ANCS_NARRATION_VOICES_JSON` 里声明（id = Fish 声音模型 id）。
