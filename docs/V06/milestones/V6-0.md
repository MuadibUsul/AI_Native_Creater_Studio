- 状态：已交付（2026-10-11）
- 来源：V5 M4-3（裁决 0018 将其作为 V6-0 收尾）；架构依据 V5 §8（工作流）、裁决 0016（RenderPlan）、0017（FFmpeg 媒体图）

### 终渲染三步

1. **freeze**：REPEATABLE READ 事务内编译 RenderPlan 并建 `FINAL_RENDER` 工程版本；`expectedRevision` 不一致 → 409 `FINAL_RENDER_REVISION_CHANGED`；后端不支持的需求（如图形对象）→ 501，运行失败且无产物。
2. **render**：逐个暂存源素材并校验 sha256 与计划中的校验和（不一致 → 不可重试失败 `FINAL_RENDER_SOURCE_INTEGRITY_FAILED`）；执行 FFmpeg 媒体图；产物按 `(runId, kind)` 幂等入库，存储键带版本号，不覆盖旧版本。
3. **qa**：从存储读回产物复核哈希；清单 `planHash / graphHash / frameCount` 一致；有字幕时 SRT 与 VTT 均存在；真实探测解码通过、H.264、尺寸、帧数、AAC 48 kHz 双声道。
4. **补偿**：失败或取消时逆序补偿，已产出的资产标记 FAILED 并降为 `DRAFT_RENDER_30D` 保留类别。

## 已知限制与交接

- **真实 Provider：** 本里程碑不涉及外部付费调用；FFmpeg 为本地真实执行，不是 Mock。
- **画幅适配：** 源与画布比例不一致时的处理（V6 §13 未决事项）沿用 RenderPlan 当前语义，在 V6-1 定稿。
- **图形对象：** 终渲染后端尚不支持图形/动效图层（501 明确拒绝）；V6-3 代码生成动效以透明图层进入 RenderPlan 后补齐。
- **局部重渲：** 分段缓存（V6 §7.4）在 V6-1 实现，复用本里程碑的 RenderPlan 切片与执行器。
- **下一步：** V6-1 共看片室最小闭环（旅游 Vlog）——新编辑器外壳、素材理解、通用导演 Agent + 统一工具目录（V6 §6）、原地试改、局部预览、导出入口接本里程碑 API。
