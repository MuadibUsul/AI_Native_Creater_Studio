## 设计要点

- **审批档位与内容来源是两个维度（AP-03）。**
  - 档位存在 `productionPolicy.autonomy`，有逐项 / 自动 / 完全授权三档；内容来源仍是 `productionPolicy.mode`。
  - 授权包含总预算（美元微单位，含模型调用与付费生成）、单次生成上限、是否允许本人形象、每个任务的重试上限，以及签署信息（签署人、时间、版本，由服务端写入）。
  - 总预算在任何档位下都是硬上限。
  - 签署版本单调递增：撤回后再签也不复用旧版本号，所以旧授权下的花费不会算进新授权。
  - 门禁 `autonomySpendDecision` 是纯函数。
  - V6-9 不调用付费生成：自主运行里拒绝 GENERATE 类工具，界面只给两档；完全授权下代为确认报价放到 V6-10。
- **编辑候选层（AP-01）。**
  - `find_edit_points` 从转写、镜头边界、静音、黑场算出剪点候选（句末、停顿、换人、镜头边界，带窗口与余量）、可删段（长停顿、口头语、静音、黑场、片头、片尾），以及不能切的整句。
  - `caption_speech` 从原声转写按时间线生成整轨字幕，可替换已有字幕。
  - 两者都是统一工具目录里的通用工具。
  - 单个提案的操作上限从 256 提到 2048，长素材也能一次粗剪完。
- **导演蓝图、场景契约、剪辑意图（AP-04 + 0.2 A0）。**
  - `plan_production` 写一份带版本的计划：主旨、结构、节奏目标；每场的目标、素材区间、需要的制作、验收点，以及剪辑意图（固定枚举 + 想要的感受 + 理由 + 放弃的备选）。
  - 计划记录制定时的工程版本号。它是规划视图，不是第二套时间线；过期时如实标注。
  - 最新计划以 `<production_plan>` 进入上下文，所以"开头不够抓人"这类反馈能定位到对应的意图。
- **节奏谱（0.2 B0）。** `measure_pace` 按 5 秒窗口测切点密度和语速，与计划里的节奏目标对照，列出偏差。它只读，只给建议，不自动改片。
- **自主制作闭环（AP-05），工作流 `AUTONOMOUS_PRODUCTION`：**
  1. **等素材。** 素材上传、处理或理解中时，用工作流引擎新增的 `WAIT_UNTIL` 结果轮询，不消耗重试次数。没有素材会等到超时，然后如实失败。
  2. **导演。**
     - 先核对授权版本：等待期间授权被撤回或改动，就不开始花钱。
     - 本次模型上限 = 剩余预算 − 一次调用的余量。
     - 在这条视频的会话里建一轮 `AUTONOMOUS`：上下文带 `<autonomous_production>`（目标、时长、档位、预算），系统提示升到 `director-v9`。
     - 用户正在和 AI 说话时，等那一轮结束（有上限）。
  3. **门禁与交付。**
     - 自检只要有警告，就留作试改。
     - 授权在运行中被改动或撤回，就不采用。
     - 逐项审批时做成试改。
     - 自动档自检通过，就以 AI 身份采用（操作日志 actor 为 `AI / autonomous:<runId>`）。
     - 运行期间用户改过作品，则不覆盖，留作试改。
  4. **交付报告。** 只写服务端的事实：
     - 结果，以及为什么没采用；
     - 成片长度、画面片段数、字幕数；
     - 用了哪些素材、各多少秒，原片占比；
     - 生成内容（特效、合成讲述、生成镜头）；
     - 自检发现与没做的检查、节奏、计划；
     - 没满足的约束（时长偏差超过 20%、没用到原片、费用到顶、步骤用完、模型没有价格表）；
     - 实际花费与未定价的调用数。
- **停下是协作式的。** 停下会取消工作流，导演循环在下一次模型调用前停止；对话里的"停止"会取消同一个工作流。同一工程同一时刻只有一个进行中的运行，开始请求按用户作用域幂等。
- **通用能力，不按类型分支。** 导演与调度代码没有按视频类型或风格分支。风格包只以数据形式进入上下文，评测以不选风格为主。

### 浏览器实测（2026-10-21，`scripts/autonomous-browser-check.mjs`，5/5 通过）

环境：真实 PostgreSQL + Fastify + 进程内 Worker（真实 FFmpeg 探测、代理、索引、预览）+ Next 生产构建 + Chrome for Testing（1440×900）。AI 为**脚本导演**（测试替身）：写一份 3 场计划，每条素材取 3 秒拼成第一版，再做自检与节奏、写交付说明。它没有价格表，报告如实写"未定价"。

| 检查 | 结果 |
|---|---|
| 新建页交给 AI | 写需求，目标 15 秒，选"自检通过就直接用"，上限 $2 → 授权第 1 版由服务端签署 → 进入共看片室，卡片显示"等素材准备好" |
| 等素材 → 自己剪完 → 直接采用 | 放入 3 段素材，AI 等处理完自己开始；从放入素材到交付 11.4 s；版本 4 → 5（AI 采用）；计划 3 场。报告：9 秒、3 个画面片段、原片 100%、用到的素材各 3 秒、"没有检查：句中剪断（没有转写）"、"时长：目标 15 秒，实际 9.0 秒"、"导演模型没有价格表"、"花费 $0 / 上限 $2.00 · 另有 4 次调用未定价" |
| 中英、深色、手机 | 卡片与报告随语言切换；共看片室与新建页在 390 px 无横向溢出 |
| 共看片室里交给 AI（先给我看） | 画布"交给 AI 剪完…" → 对话框默认"先给我看" → 剪好后做成试改，作品版本不变 → 对话里"就这样"后才成为新版本 |
| 等素材时停下 | 没有素材的工程交给 AI → 停下 → "已停下"；没有开始导演，没有模型调用，作品没变 |

截图共 10 张，已人工查看：`docs/verification/artifacts/v6-9/`。实测中发现并修复了三处：

## 未验证与待办

- **真实模型。** 自主制作只用脚本导演验证过闭环。真实 Claude 是否会按 `director-v9` 先计划、用剪点候选、自检后修复，交付说明是否诚实，都要在真实素材上评测。会产生费用，需要你同意额度。
- **真实素材验收集（0.1 §12.2）。** 需要你提供 10 分钟口播、20 分钟 Vlog、30 分钟教学、60 分钟游戏，以及一份素材不足的故事素材，并给出使用授权。
- **浏览器实测没有语音识别。** 所以原声字幕与句中剪断检查在浏览器里没有覆盖，只在集成测试里用真实转写快照验证过。
- **默认档位与预算。** 现在新建默认"先给我看"、上限 $2，由你定。
- **完全授权 + 付费生成代为确认、并发制作、补镜头**（AP-06～AP-15）：V6-10 / V6-11。
- **0.2 CutPrior**（AP-16～18、21）：在人类剪辑工程文件的来源与授权解决前暂停。
- **导演模型用量计费。** 导演模型的花费已计入签署预算；但信用点账本只扣付费生成，统一计量入账见生产清单第 6 节。
