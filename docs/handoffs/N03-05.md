## 本项交付

变换参数命名空间（`packages/contracts/src/visual-transform.ts`：transform/crop/opacity + 关键帧路径 + 命中换算纯函数）、迁移 0077（片段 `parameters` jsonb）、三个规范原语 `set_clip_transform`／`set_clip_crop`／`set_clip_opacity`（v2 由 PLANNED 翻为 NATIVE），以及派生片段参数继承与 undo/redo 回退。

## 接手要点（下一项 N03-06 需要知道的）

1. **参数化 ≠ 重生成**：变换类编辑只写片段 `parameters` 并落 `SET_CLIP_*` 事件，**不得**触发 Scene 重写或 Provider 调用；测试用"Scene 行数不变"锁死这一点。新增任何"外观类"编辑都照此办理。
2. **参数合并用 `nextVisualParameters`**：局部变更合并进命名空间，保留其余字段与组件 `values`；不要整体覆盖（会丢组件参数）。
3. **命中换算必须复用纯函数**：`projectVisualPoint`／`invertVisualPoint`／`hitTestVisualObject`（裁切→缩放→旋转→位移），预览与命中检测共用同一实现，避免两套坐标系。旋转/裁切的可检验性由契约单测（数学）+ 集成测试（服务端读回参数）双层覆盖。
4. **两层校验**：非法参数（空裁切、缩放 0、透明度越界）由契约在**发请求前**拒绝（客户端 ZodError），服务端保留第二道（`CROP_AREA_EMPTY` 422）；对象锁用 STYLE 维度，经影响面门 + `assertObjectLockAllows` 两层。
5. **继承语义**：切分/复制派生片段**继承**父片段参数（`splitClipRow` 与 `duplicate_clip` 都复制 `parameters`）；新增创建片段的路径请同步处理，否则变换会"丢"在派生片段上。
6. **投影**：`clipSchema.parameters` 可选，缺省即旧语义；`toClip` 仅在非空时带字段，旧客户端读到的形状不变。
7. **已知缺口**：画布上的选择框/手柄/关键帧编辑器与渲染管线消费参数属 N03-08（多轨预览与真实合成）；像素级旋转/裁切一致性属 N03-16。
