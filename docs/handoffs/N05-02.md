## 接手要点

1. **精度必须如实**：只有"可验证音频位置 + 时钟采样 + 播放锚点"齐备才给 `AUDIO_RANGE`/`WORD_EXACT`；否则 `UTTERANCE_SNAPSHOT` 或 `UNAVAILABLE`。**禁止**在无词级时间时标成逐词精确。
2. **不使用墙钟/网络顺序**：映射只依赖本地单调时钟与 `VOICE_CLOCK` 采样；`seq` 只在生产者流内有序。
3. **能力协商 fail-closed**：请求未声明支持的标志 → 501 `VOICE_UNSUPPORTED_CAPABILITY`；未知一律不支持。
4. **采集隐私**：显式授权、可见开关、卸载/结束会话停止采集并停止音轨；本地只做电平，不做上传/推理。
5. **DOMException 判别**：权限拒绝在真实浏览器是 `DOMException`（未必 `instanceof Error`），按 `.name` 判断 `NotAllowedError/SecurityError`。
6. **接真实传输的落点**：把真实适配器接进 `VOICE_ADAPTER_CAPABILITIES`（按供应商文档逐项声明能力），客户端只拿短期凭证，工具执行仍在服务端；`VOICE_CLOCK` 由真实音频时钟替换夹具。
7. **回放路径**：见 `docs/verification/N05-02.md` 的"真实浏览器/媒体证据"。
