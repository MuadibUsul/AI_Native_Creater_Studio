# 播放链路真机测试清单（安卓 + iOS）

> 适用：**N03-12（播放源适配器）／N03-13（统一媒体时钟）／N03-16（帧与音频一致性测量）** 的"真"字证据。
> 这三项的逻辑层已交付并有自动化证据；**缺的只有真机确认**——所以这份清单很短，但必须由你在真机上跑。
> 前置：电脑与手机同一 Wi-Fi；若测**麦克风**功能需 HTTPS（见 `DEVICE-TEST-GUIDE.md`）。

---

## 一、准备（电脑上，一次）

1. 起依赖：`docker compose -f infra/docker-compose.dev.yml up -d`
2. 起 Web：`pnpm --filter @ancs/web dev -- --hostname 0.0.0.0`
3. `ipconfig` 找到形如 `192.168.x.x` 的地址；手机浏览器打开 `http://<该地址>:3000`

> 说明：现有播放面（`PlaybackSurface`）需要一个可播放的**proxy URL** 才能真放。若还没有真实素材走完转码链路，先做第二节的"无素材也可测"项；有素材时再做第三节。

---

## 二、无素材也能测（约 10 分钟）

### A. 界面与时间带（对应 N04-01）
- [ ] 页面排版无错位、文字无截断
- [ ] 时间带刻度与片段块对齐、清晰（高 DPI 是否发虚）
- [ ] 拖动标尺播放头跟手；点击片段有反应
- [ ] 滚动顺畅

### B. 播放控件与提示（对应 N03-12／N03-13）
- [ ] 点"加载"后状态变为 `READY`；点"播放"变 `PLAYING`；点"暂停"变 `PAUSED`
- [ ] 逐帧按钮 `◀|` / `|▶` 能把播放位置推进一步（时间码可见地变化）
- [ ] **音频未授权时看到明确提示**（"需要允许播放音频…"），且不是静默无声
- [ ] 无音轨素材显示"本片段没有音轨（使用虚拟时钟）"
- [ ] "支持的能力"一栏**只列出真正支持**的项；被声明为不支持的能力**不出现**

## 三、有真实 proxy 素材时（对应 N03-12 适配器 + N03-16 测量）

> 每项都要在 **Android** 与 **iPhone(Safari)** 上各做一遍。

### C. 基本播放与呈现一致性
- [ ] 加载后能播出画面（**不需要** WebCodecs/WebGPU —— 这是硬要求）
- [ ] 播放中"实际呈现"数字**持续变化**，且与画面进度吻合
- [ ] 播放 2–3 分钟后，画面与时间码**没有越来越偏**（长样例漂移）
- [ ] 拖动进度到中间再播，**画面与声音仍然同步**
- [ ] 分数帧率素材（如 29.97）下，帧号显示**连续不跳号**

### D. 连续 seek（对应"连续 seek 后旧音频不播放"）
- [ ] 快速连续拖动进度 5 次以上，**不会**听到旧位置的音频片段闪出
- [ ] 停止拖动后声音从**最后一次**位置开始

### E. 后台/恢复（对应"后台恢复不快进、不重复音轨"）
- [ ] 播放中切到后台/锁屏 30 秒再回来：**不快进**（时间码停在离开时的位置附近）
- [ ] 恢复后**没有**重复播放同一段音频（无叠音）
- [ ] 恢复后画面与声音同步

### F. 签名 URL 过期（对应"过期 URL 刷新不重置选区"）
- [ ] 若后端签名 URL 有效期很短（可临时调小），播到过期时**画面继续**、**位置不回到开头**、**时间选区不被清空**
- [ ] 若刷新失败，界面给出**明确失败**提示（不是静默卡住）

### G. 冷/热缓存首帧（对应 N03-16 的"冷/热分别测"）
- [ ] **冷缓存**（首次进入该片段）记录首帧出现耗时
- [ ] **热缓存**（再次进入同一片段）记录首帧耗时，应明显更快
- [ ] 两次都记录下来（数值给我，我会回填到测量报告）
