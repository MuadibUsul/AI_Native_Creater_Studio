# N02-03 交接｜代理转码与源时间映射

**状态：VERIFIED。** 依赖 N02-02、N01-03 已关闭；证据见 [`N02-03`](../verification/N02-03.md)，交互设计见 [`N02-03 UI 交付卡`](../design/features/N02-03.md)。

## 已实现

- 探测完成事务内自动建立 `PROXY` 派生、隐藏输出资产与 SYSTEM `MEDIA_PROXY` Job；复用 N01-10 的 `media_derivatives`，无新迁移。
- ffmpeg 视频 profile 输出 H.264/AAC、最大 1280×720；音频 profile 输出 AAC 48 kHz 立体声。
- 逐视频／音频流保存源与代理 time base、起始 PTS、持续 ticks 和开头／中间／结尾锚点；换算不依赖平均 fps。
- 播放 API/SDK 优先代理，生成中或丢失时仅在原件可直接预览时显式回退；签名地址可刷新。
- 代理失败或对象丢失可从素材详情重建，同一派生身份和输出版本复用，原件不变。
- 定向 unit 11/11、Web 17/17、API+worker integration 12/12；真实浏览器、三次 seek、删除与重建通过；最终 `pnpm verify` 1009/1009。

## 边界与下一项

- 生产对象存储必须实现流式 `materializeObject` 和 `persistFile`；worker 需要可控 ffmpeg/ffprobe。
- 当前验证 profile 是 Web 标准代理；HDR、图像序列、RAW、多轨母版和 Safari/macOS 仍由后续专业任务交付。
- N02-03 前已经探测的素材不会在 GET 中产生副作用；UI 对 `NOT_REQUIRED` 显示“尚未创建”，用户可显式生成代理。
