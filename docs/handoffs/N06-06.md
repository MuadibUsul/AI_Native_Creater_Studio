## 接手要点

1. **谱系定义**：同谱系 = `intentRevisionId` 相同；若为 null 则 `selectionAnchorId` 相同；两者都 null 视为**无谱系，不取代任何候选**。改动此规则会影响"最新意图"判定。
2. **代际是工程内单调递增**（`max(generation)+1`），**不**按谱系重置。产物判定用 `generation`（候选自身）+ `currentGeneration`（谱系当前最大）双门。
3. **隔离台账不是第二份作品状态**：`proposal_artifacts` 只记不透明引用（`kind`/`reference`）与绑定判定；绑定**不**修改候选行，也不碰工程。真正消费产物属 N06-08。
4. **取消 ≠ 丢弃**：`cancelProposal` **保留**试片缓存与产物（`discardProposal` 会删除试片缓存）；两者都让采用 409，但理由不同（`PROPOSAL_CANCELLED` vs `PROPOSAL_NOT_OPEN`）。
5. **保留清理**：`runRetentionSweep` 只清理 `bound=false` 的隔离行；`bound=true` 永久保留（结果证据）。TTL 配置 `retention.proposalArtifactQuarantineTtlHours`（默认 72）。
6. **接口幂等**：产物按 `(workspace, project, kind, reference)` 唯一 → 同产物重放 upsert 同一行，返回同 `artifactId`。
