## 接手要点

1. **身份不是坐标**：发出的是 `objectId`（+ 版本）；预览帧号/帧哈希不得当身份或授权（契约与 N04-09 服务端一致）。
2. **复用坐标权威**：命中与绘制都用 N03-05 的 `hitTestVisualObject` / `projectVisualPoint` / `invertVisualPoint`，不要另写变换公式。
3. **叠放顺序固定**：zOrder 降序 → `VISUAL_OBJECT` 先于 `CLIP` → 输入顺序；隐藏对象与其子对象不参与。
4. **重叠可轮换**：点击已选中的上层对象时切到下一个未选候选，避免"永远命中最外层 Scene"。
5. **选择动作永不改工程**：组件只发 `OrderedTargetRef[]`；父层用 `composeSelectionAnchor` 组装 `SelectionAnchor`，采用走统一编辑协议。
6. **测试指针**：同 N04-04-s1，用同名 `MouseEvent` 派发。
