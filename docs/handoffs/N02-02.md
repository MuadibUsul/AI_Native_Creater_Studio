## 已实现

- 迁移 0065 为 AssetVersion 保存探测生命周期和结构化媒体事实，未建立第二套可变原件。
- 音视频上传确认在同一事务创建 SYSTEM `MEDIA_PROBE` Job；图片等非音视频保持原有直接 READY 行为。
- worker 通过隔离 ffprobe/ffmpeg 子进程识别容器和真实流，不信任扩展名；记录时基、PTS、VFR、旋转、色彩、声道及能力摘要。
- Local storage 以流式物化供探测，探测成功或失败均保留原件；进程中断后可幂等恢复。
- 素材页展示分析、能力、流信息和失败恢复；直接播放器受 `preview` 能力约束。
- 定向 unit 12/12、Web 8/8、worker integration 2/2、API+Web 28/28；真实浏览器与实际媒体通过；最终 `pnpm verify` 1003/1003。

- 当前仅声明经样例验证的 Chrome/worker 能力；不等于全部专业格式、HDR、Safari/macOS 或生产对象存储已经支持。
