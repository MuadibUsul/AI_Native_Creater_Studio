# N03-04 交接｜多轨、AV 链接与轨道控制

**状态：** `VERIFIED`（2026-10-09）　**验证：** [`docs/verification/N03-04.md`](../verification/N03-04.md)

**依赖满足：** N03-02 ✅（另用到 N01-07 对象锁）。

## 本项交付

五个轨道层规范原语：`create_track`、`move_track`、`delete_track`、`update_track`（名称/位置/静音/独奏/隐藏/锁定/同步锁）、`set_av_link`（链接/解链）；迁移 0076 给 `sequence_tracks` 加 `solo`、`sync_locked`；轨道状态进入版本快照与客户端投影；同步锁参与涟漪范围判定。

## 接手要点（下一项 N03-05 需要知道的）

1. **迁移 0076** 是纯增量（两个 boolean NOT NULL DEFAULT false），无需回填。
2. **轨道重排必须两阶段写入**：`commitTrackOrder` 先把要动的轨道挪到 `+10000` 再写最终位置；直接逐条写目标位置会撞 `(sequence_id, position)` 唯一索引 → HTTP 500（本项真实踩到过）。`create_track` 的让位同理（先偏移 → 插入 → 再落位）。
3. **轨道自身 `locked` 标志不阻断轨道控制**：`loadTrackOwned` 不带 `locked` 检查（否则无法解锁），保护由**项目对象锁**（`assertObjectLockAllows`）表达；`loadTrack` 仍用于片段编辑路径。
4. **AV 链接语义**：`avGroupId` 是唯一关联标记；链接要求同序列 + 一视频一音频 + 时长相等；解链清空后各自编辑不联动。`set_av_link` 的 undo 走 `update_clip{avGroupId}`（恢复原关联）。
5. **同步锁**：`ripple_clip` 的单轨收缝范围为"本轨 + `syncLocked` 轨道"；AV 关联片段所在轨不在范围内即 409 `AV_SYNC_REQUIRES_CROSS_TRACK_RIPPLE`。新增任何会移动多轨的原语时都要复用这套范围判定。
6. **轨道状态投影**：`toTrack` 已带上 `solo`/`syncLocked`；旧版迁移投影（`composition-migration.ts`）补默认值。渲染管线的静音/独奏归一化属 N09 与 N03-08，本项只保证状态面一致。
7. **事件命名**：`CREATE_TRACK`／`MOVE_TRACK`／`DELETE_TRACK`／`UPDATE_TRACK`／`SET_AV_LINK`（片段侧副作用仍用 `UPDATE_CLIP`／`INSERT_CLIP`）。
8. **已知缺口**：UI 轨道头部控件（N03-08）、序列长度扩展、嵌套/轨道分组（N11）、跨素材 J/L cut（N03-05+）。
