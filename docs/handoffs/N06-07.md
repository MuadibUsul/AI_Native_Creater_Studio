## 接手要点

1. **保护门比对的是"试改后状态"**：`runDeterministicTrial` 现在返回 `{ trial, postState }`（postState = 回滚前采集的每个片段三轴指纹）。**不要**改回用已提交状态比对——附带移位发生在试改之后，用已提交状态检测不到。
2. **显式目标豁免**：`explicitTargetKeys` 来自 `computeWriteTargets(ops)`；受保护对象**被显式改动**是预期内的，不算范围外。只有"被改动但不在本批显式目标里"才 409。
3. **可选才收费**：只有传了 `protectionIds` 才多跑一次试改；不传时零额外开销。新增采用路径时保持这个门控。
4. **仅支持 CLIP**：`captureConfirmedContent` 对非 CLIP 显式 501。要扩到字幕/音频区域/视觉对象时，需同步扩展 `clipDigestsOf` 之类的指纹来源与 `postState` 采集。
5. **范围守卫未接线**：`resolveScopeGuard` 的判定语义已固定（SAFE / EXPLAIN_DURATION_CHANGE / EQUAL_LENGTH_PLAN_RECOMMENDED），但**尚未**在 `planRangeEdit` 里计算总时长变化并回带。接线时不要把"等长替代"实现成静默改写用户意图。
