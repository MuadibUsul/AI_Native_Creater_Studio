## 接手要点

1. **保护门比对的是"试改后状态"**：`runDeterministicTrial` 返回 `{ trial, postState }`（postState = 回滚前采集的三轴指纹）。**不要**改回用已提交状态比对——附带移位发生在试改之后。
2. **显式目标豁免**：`explicitTargetKeys` 来自 `computeWriteTargets(ops)`（部分采用时用**闭包后的操作**）；受保护对象被显式改动是预期内的。
3. **可选才收费**：只有传了 `protectionIds` 才多跑一次试改。
4. **扩保护类型时**：`captureConfirmedContent` 目前只支持 CLIP（其他 501）。扩到字幕/音频区域/视觉对象时，需同步扩 `clipDigestsOf` 等指纹来源与 `postState` 采集口径。
5. **总时长守卫是估算不是执行**：由操作负载推导（insert/ripple TRIM/delete）。**新增会改变总时长的操作原语时必须同步 `estimateRangeEditDurationDeltaMs`**，否则守卫漏判；估算不出时 `exact=false` → 一律要求解释，绝不当作等长放行。
6. **等长替代的判定**：当前规则是"计划里含涟漪（非 DELETE）→ 存在等长替代（不涟漪的变体）"。若要扩展其他替代形态，请把它做成确定规则并补测。
