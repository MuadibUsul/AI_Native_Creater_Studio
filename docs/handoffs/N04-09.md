## 本项交付

规范 `SelectionAnchor` 的唯一落点：契约（`packages/contracts/src/selection.ts`，含几何/时间/轨道/属性/区域模式/发话时间/重映射历史/指纹）、迁移 0079 的追加式修订日志、旧 inline 选择适配器、保存/读取/重映射三个 API 与 SDK 方法，以及越权/帧哈希/失效/歧义/过期的负面路径。

## 接手要点（N04-10／N05-01-s1／N04-02-s1 需要知道的）

1. **选择动作永不改工程**：保存锚点不写 `edit_events`、不推进 project revision。任何"选择即生效"的实现都是错的——生效必须走统一编辑协议。
2. **锚点行身份 = (workspace, project, anchorId, revision)**：这是追加式修订日志，`update` 语义通过"插入新修订"表达；`getSelectionAnchor` 返回最新修订并把载荷内 `revision` 同步成该修订号（避免两份"当前修订"）。
3. **越权 vs 失效**：`lookupTarget` 三态（PRESENT／MISSING／FOREIGN）。FOREIGN（同工作区其他项目）**永远拒绝**；MISSING 仅在锚点状态非 `RESOLVED` 时允许持久化——这是重映射能记录失效的前提（写成"存在才允许保存"会让 remap 无法落库）。
4. **帧哈希/预览帧不是身份也不是授权**：`assertNotFrameHashIdentity` 是服务端第一道；几何只定位，身份来自 `orderedTargetRefs` 的对象 id/版本（契约层还要求 TARGET 几何必须伴随目标引用）。
5. **发话时间**：`utteranceSequenceTime` 记录"说这句话时"的序列时间；语音接入（N05-01-s1）必须填它，不要用解析时刻顶替。
6. **重映射语义**：目标消失 → FAILED／部分消失 → PARTIAL／同一源版本多引用 → AMBIGUOUS（附候选证据，**不随机选一个**）／片段换源 → STALE；每次写入 `remapHistory`（含原因与缺失/过期目标）。N04-10 的自动恢复请在此基础上做触发与并发保护。
7. **旧入口**：分镜/时间线/“带到编辑器”等既有 UI 仍持有自己的临时选择；接入时应改为 `legacy` 字段或直接构造锚点，**不要**保留第二份权威选择状态。
8. **测试夹具**：`seedAsset` 的 mediaProbe 用最小合法形状即可；跨项目/跨租户用例请各自建工作区。
