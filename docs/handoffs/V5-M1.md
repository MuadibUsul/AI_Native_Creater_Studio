# V5-M1 交接｜唯一时间库 + 编辑内核

**状态：** 完成　**验证：** [`docs/verification/V5-M1.md`](../verification/V5-M1.md)　**裁决：** [`0012`](../decisions/0012-edit-kernel-and-time-library.md)

## 完成了什么

- `@ancs/time`：唯一有理时间库（精确运算 + 显示换算）；contracts 转出口，调用方无需改动。
- `@ancs/kernel`：28 个时间线操作的全部编辑规则（锁、边界、AV 同步、源范围、时间精度、原声保护）为纯函数；arch-check R9/R10 强制无 I/O、无墙钟、无随机。
- `kernel-timeline.ts`：领域层只做加载与持久化；事件 patch 与旧实现同形，撤销/重做不变。
- 修复 2 个真实缺陷（`update_track` 改位置 500；CUT_CONTENT 不查锁），以及插入切分丢参数。

## 接手要点

1. **新增时间线规则只写在内核里**：`packages/kernel/src/timeline/*-ops.ts`，配内核单测；领域层不要再出现编辑判断。
2. **事件顺序 ≠ 写入顺序**：内核返回 `writes` 与 `events` 两个列表；撤销逐事件进行，事件顺序要按"撤销时应先恢复谁"来排。
3. **快照形状**：事件里的 before/after 由 `composition-snapshots.ts` 统一生成；改快照格式会影响 `undo-redo.ts`。
4. **轨道位置**：内核只给最终位置，唯一索引冲突由 `persist()` 的两阶段落位处理。
5. **加载范围是整个项目**：查找时注意区分"项目范围"与"同序列"（与旧查询条件一致，否则错误码会变）。
