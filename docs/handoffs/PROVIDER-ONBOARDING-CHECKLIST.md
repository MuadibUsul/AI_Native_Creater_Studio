# 真实 AI 供应商接入清单（待你填写）

> 用途：把"模拟验证"升级为"真实验证"所需的最小信息。**凭据不要发在聊天里**——见第三节的存放方式。
> 背景：目前所有 AI 能力都是模拟实现（Mock），项目纪律是"模拟通过 ≠ 真实通过"，因此 G0 等总门**只认真实验证**。

---

## 一、总体说明（先看这段）

- 现在需要的是"**让程序能真的调用一家 AI 服务**"：一个地址 + 一把密钥 + 一个型号。剩下的适配代码我写。
- 我按**能力**分类，每类都建议"**1 个主用 + 1 个备用**"：主用挂了不至于整条链路瘫。
- **建议先小额试**（例如每月几十到几百元量级），跑通真实链路、拿到真实延迟与成本数据后再放量。
- 每类都请给出**月度花费上限**：程序里有项目/用户/每日预算与熔断，但**数字要你定**。

---

## 二、需要你填的表

### 1. 语音识别（ASR）+ 语音活动检测（VAD）——**优先级最高**
这是产品差异化（"对着画面说改哪里"）的基础。

| 要填 | 说明（白话） |
|---|---|
| 服务商名称 | 例如某云的语音识别、或 OpenAI/Deepgram/讯飞等 |
| 接入地址 | 服务商提供的 API 域名 |
| 密钥 | API Key / Token（**放环境变量，不要贴聊天**） |
| 型号 / 引擎名 | 服务商文档里的模型或引擎标识 |
| 服务地区 | 数据发到哪个区域（决定合规与延迟） |
| **是否支持"边说边出字"（流式）** | 决定能否做实时反馈；不支持就只能"说完再出结果" |
| **是否支持逐词时间戳** | 决定"这句话"能否精确定位到秒/词；不支持则只能给到整句时间范围 |
| 计价方式 | 每分钟音频多少钱 / 或每次调用多少钱 |
| **月度上限** | 例如"每月不超过 200 元" |
| 是否允许把**含人脸/人声**的用户素材发给他们 | 涉及隐私与合规；若不允许，我需要把相关能力改成"本地处理"或禁用 |

### 2. 大语言模型（LLM）——**优先级最高（和 ASR 并列）**
两个用途：一是把"去掉前面废话但保留原音"这类说法变成可执行操作；二是判断用户说的是"采用 / 再改 / 不要了"。

| 要填 | 说明 |
|---|---|
| 服务商名称 | 例如 OpenAI / Anthropic / 国内的某家 |
| 接入地址 | API 域名（很多服务商兼容 OpenAI 协议，那就给"兼容地址"） |
| 密钥 | API Key |
| 型号 | 例如某具体版本；**建议一个"便宜的"用于分类、一个"强的"用于规划** |
| 是否能强制"只输出结构化数据（JSON）" | 我的代码要求它按固定格式输出，否则会被拒；不支持则可靠性下降 |
| 上下文长度上限 | 决定一次能看多少字幕/片段描述 |
| 计价方式 | 按输入/输出字数计费 |
| **月度上限** | 数字 |

### 3. 视觉 / 画面理解（可选，第二批）
用于"AI 看着画面和你一起剪"（理解镜头内容、按画面定位）。

| 要填 | 说明 |
|---|---|
| 服务商 / 接入地址 / 密钥 / 型号 | 同上 |
| 计价方式 | 按图片张数或按分钟视频计费（我们是抽帧送过去，所以要"每帧多少钱"或"每分钟视频多少钱"） |
| 限流 | 每秒最多几次调用（决定处理一个长视频要多久） |
| **月度上限** | 数字 |
| 是否允许发送含人脸的画面 | 同上，合规相关 |

### 4. 音频分析（音乐 / 静音 / 说话句段）（可选）
| 要填 | 说明 |
|---|---|
| 方案 | **本地工具**（如 ffmpeg 系列，0 成本但要本机算力）还是**云服务**？ |
| 若云：地址 / 密钥 / 型号 / 计价 / 月度上限 | 同上 |

### 5. 语音合成（TTS，后面才需要）
用于"新旁白"之类。现在不阻塞，可先不填。

## 三、密钥怎么给我（重要）

**不要发在聊天窗口里。** 三种合规做法，任选：

1. **放到服务器环境变量**（推荐）：在部署环境的 `.env` 里填这两项（**只存后端，绝不下发到浏览器**）：
   - `ANCS_PLATFORM_PROVIDER_KEYS="供应商A:密钥A,供应商B:密钥B"`（逗号分隔，可加多个）
   - `ANCS_CREDENTIAL_KEYS=v1:<一串 base64>`（这是**用来加密用户自己填的密钥**的钥匙；生产环境必须显式配置，缺失会拒绝启动）
   - 两个变量的位置都在仓库根目录 `.env.example` 里有注释说明。
2. **只把密钥给我，我来放进本地 `.env`**（仅限本机开发，且该文件已在忽略列表里、不进仓库）。
3. **你开一个受限的子账号**：只给"只能用语音识别+大模型、月度上限 X 元"的权限，这样即使泄露损失也有限。

另外请顺手告诉我：**如果密钥要作废重发，你会怎么通知我**（避免我误以为挂了去重试花钱）。

## 四、我拿到之后会做什么（你只需知道会花多久、花多少）

1. **写适配器**（把"调用这家服务"翻译成我们内部统一的接口）——通常每个能力半天到一天。
2. **用 10–20 条代表性素材做评测**：中文、有口音、有背景音乐、多人对话都要有；测**识别错误率**与**逐词时间戳准不准**。
3. **量真实延迟**：用完到界面有反应的目标是"一半情况 <0.8 秒、95% 情况 <2 秒"；打断（用户中途插话）<0.3 秒；试剪预览出第一帧 <3 秒。这是**目标值，会用真实数据校准**。
4. **量真实成本**：每处理一分钟素材花多少钱，回填到成本表里。
5. **把相关任务的证据等级从"模拟验证"升级为"真实验证"**——只有那时 G0 才算真的能过。

## 五、如果暂时拿不到凭据（也没关系）

我会继续把**不依赖真实服务**的部分做扎实（协议、状态机、确定性夹具、界面、错误处理），并把相关任务保持为"等凭据"状态、**不虚报**。已交付的这种"待凭据"实现有：实时语音会话与短期凭证（N05-01）、语音采集与时间对齐（N05-02）、范围编辑计划（N03-09）等。

**优先级建议：** 先给 **ASR + LLM**（这两项能立刻解锁"说一句话就剪一段"的最小真实链路），视觉与音频分析放第二批。
