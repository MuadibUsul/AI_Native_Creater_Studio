# N02-01 交接｜有界内存的批量分片直传

**状态：VERIFIED。** 依赖 N00-06、N01-02 已关闭；证据见 [`N02-01`](../verification/N02-01.md)，交互设计见 [`N02-01 UI 交付卡`](../design/features/N02-01.md)。

## 已实现

- 迁移 0064 建立 multipart intent 字段与 `upload_parts`，所有读取和写入携带 workspace scope。
- API 支持 intent 状态、逐片短时目标、逐片确认、取消和最终确认；最终确认复用既有 MIME、大小、完整 SHA、额度与去重逻辑。
- SDK 对 Blob/File 分片读取，受限并发，支持进度、AbortSignal 暂停、同 intent 继续与批量文件结果。
- Local storage 以流式 compose 实现有界内存合并；接口允许后续 S3/R2 provider 用原生 multipart/compose 替换。
- 素材页上传对话框支持多选、队列、暂停、继续、取消、失败恢复和窄屏布局。
- 定向 unit 18/18、Web 15/15、integration 9/9；真实浏览器上传通过；最终 `pnpm verify` 994/994。

## 边界与下一项

- 未用 S3/R2 或第三方 Provider；证据边界为真实 LocalSignedStorage。浏览器重载后不能无授权恢复本地 File，当前保证页面会话内恢复，并提供 SDK/API intent 恢复能力。
- 本任务没有改变原素材 hash、最终 AssetVersion 生命周期或工作区额度权威。
