## 接手要点（N03-10 与增量设计首批切片需要知道的）

1. **计划不落库、零媒体调用**：`providerMediaCalls` 是字面量 `0`；任何生成式意图只能进 `outOfScope`，不得触发付费制作。Apply 必须走统一编辑协议（operations + 双 revision + 幂等键）。
2. **越界不整批失败**：不允许的操作、证据外引用、锁定目标、策略禁止的操作逐条记入 `outOfScope` 并带原因；只有**全部**不可执行才 422。UI 展示时应逐条说明"为什么没做"。
3. **不虚构素材**：规划器只能引用 `evidence` 里的片段 id；`referencedIds()` 覆盖 `clipId/leftClipId/rightClipId/videoClipId/audioClipId/captionId/audioRegionId/trackId` 与 `clipIds[]`。新增规范操作时若引入新的目标字段，**必须同步扩展 `referencedIds`**，否则幻觉引用会漏过校验。
4. **选择是最小形态**：本项只有 `selectedClipIds`；几何选择（点线面）与 `SelectionAnchor`／`IntentRevision` 属增量设计首批（见 `docs/design/mouse-voice-gap-map.md` 的 N04-09-s1），届时把 `IntentRevision` 挂到同一条路径上，不要新建第二套协议。
5. **原声保留判据**：`touchesAudioClock()` 与执行器的原声保护守卫同口径；计划里若出现改源时钟的音频操作，在保护开启时会被移入 `outOfScope(POLICY_FORBIDDEN)`。
6. **SDK 命名空间**：`rangeEditPlan` 与 `aiEditPlan` 同在 `client.narrative`（AI 编辑族），不在 `client.projects`；SDK 类型从 `src` 解析，但 API 侧类型检查曾因缓存误导，改 SDK 后请同时 `pnpm --filter @ancs/sdk build`。
7. **测试夹具**：`trim_clip` 遇到"本地区域超出新时长"的 CLIP_LOCAL 音频区域会 409（区域级时钟重算属 N03-06）——夹具请让区域落在裁剪后仍有效的范围内。真实媒体用例请放 integration 项目（unit = 无外部依赖）。
