## 接手要点

1. **右侧必须是"真跑一遍再回滚"的结果**：与 `previewProposal` 同一路径语义，不要改成"猜测/近似"。
2. **对齐优先级**：先按 `clipId`（同对象），再按**内容锚点**（`assetVersionId|nestedSequenceId|sourceRange`）唯一匹配。锚点匹配数 >1 时**不要**随便挑一个——进 `unmatchedAnchors` 让上层提示可能错位。
3. **对照必须回带实际素材版本**：`beforeAssetVersionId`/`afterAssetVersionId`/`assetVersionIds` 是"回到上一版得到实际资产而非重新生成"的证据来源，别删。
4. **恢复不要新写一套**：版本恢复沿用 N01-08 的补偿事件（`undo`/`redo`/`restore_project_version`）。本项只提供"差在哪"的载荷。
5. 对照是**只读**路径；新增字段不要让它在事务里落库。

## 第二轮要点（2026-10-11）

- **回放计划在客户端推导**：`buildComparePlaybackPlan(report, loopRange)` 是纯函数，面板直接消费 `compareReport`，**不新增服务端端点**（避免多一次往返与漂移）。
- **左右侧归属**：删除 → `LEFT`（只有左侧有区间）、新增 → `RIGHT`、修改 → `BOTH`；修改项定位取**试改后**区间（用户在看 B 时看到的才是新位置）。
- **不可定位的差异不得丢弃**：`range=null` 的仍列出并计入 `unplaced`；面板把它们单列出来。
- **空循环区间 = 不循环**：不要用"补一个小范围"的方式掩盖；没有选区就不该显示循环。
