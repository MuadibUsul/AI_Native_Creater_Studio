# N16-02 交接｜外观偏好、系统主题与首屏初始化

**状态：** `IN_PROGRESS`。N16-01 依赖已按任务级验证，N16-02 当前只完成 Web 设备覆盖与系统外观子步；跨设备账号偏好仍缺服务端合同、持久化与 API/SDK，D0/D1 未关闭。

## 实现与契约

- 新增 `apps/web/src/lib/appearance.ts`：三态外观、本地用户作用域覆盖、严格 cookie 解析与当前会话用户 ID 匹配。旧全局 `ancs-qf-theme` 不迁移到任何用户。
- `app/layout.tsx` 仅在存在合法覆盖 cookie 时请求内部 `/auth/session` 校验当前用户；固定外观在 SSR body 上设置，系统外观由第一个 body 脚本在可见内容前设置。脚本内容固定，不插入不可信值。
- `StudioShell` 响应系统深浅色变化；设置页新增跟随系统／浅色／深色选择；登录成功时为实际用户恢复设备外观 cookie。
- Contracts、Migration、Domain、API、SDK：本 Web 子步不适用；完整账号同步能力仍待按顺序建设。UI 主题与作品内容/品牌主题分离。
