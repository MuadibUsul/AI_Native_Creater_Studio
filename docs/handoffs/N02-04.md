- 迁移 0066 建立 source AssetVersion + processor version 唯一运行和分页条目；条目持有精确源 PTS/time base，缩略只返回短期签名 URL。

- 素材 API/SDK 支持按类别/游标分页和失败重建；跨租户不可枚举，错误/result 不含存储键。

- 故障注入证明索引失败不改变 Asset/Proxy，旧索引继续可见；真实浏览器由 UI 重新排队并恢复。
