# N03-07 交接｜字幕与转写驱动剪辑

**状态：** `VERIFIED`（2026-10-09）　**验证：** [`docs/verification/N03-07.md`](../verification/N03-07.md)

**依赖满足：** N02-05（转写词条）✅、N03-03（精剪原语，收缝语义对齐）✅。

## 本项交付

字幕文本纯函数（词条为权威、否定词与数字逐字保留、CJK 混排不补空格）、四个字幕规范原语（`create_caption`／`split_caption`／`cut_caption_range`／`delete_caption`）＋ `update_caption` 由 PLANNED 翻为 ACTIVE 并落地执行器、以及**显式模式**的转写驱动剪辑（`CAPTION_ONLY` 只改字幕 vs `CUT_CONTENT` 真正剪内容并收缝）。

## 接手要点（下一项 N03-08 需要知道的）

1. **改字幕永不动原音**是硬约束：`update_caption`／`CAPTION_ONLY` 只写字幕表；只有 `mode='CUT_CONTENT'` 才会剪片段，且**必须显式传**（契约层 `captionCutModeSchema`）。新增字幕相关编辑时不要"顺手"改片段。
2. **词条是权威**：字幕 `text` 由 `captionTextFromWords(words)` 重建，保留词条原文逐字不动（否定词 `没有/不/…`、数字 `3` 都在）。写文本时若同时改 `words`，请用重建结果而不是手拼字符串。
3. **切口映射假设**：`mapCaptionLocalToSequence` 用等速 1:1（局部跨度 = 序列跨度）把词条时间映射到序列时间，非等速 → 422 `CAPTION_MAPPING_UNSUPPORTED`。变速字幕（N11）落地时要替换这里的映射而不是放宽断言。
4. **CUT_CONTENT 的四类片段处理**：整段在切口内 → 删除；头部在切口内 → 保留尾部并左移；尾部在切口内 → 裁到切点；切口在片段内部 → 左段留 id + 右段重建（源按切口切分）。全部走 `identityForwardMapping` 校验，非 1:1 → 422。
5. **不静默删字幕**：与切口相交的其他字幕做裁剪 + 删词；**被切口完全包含** → 409 `CUT_CONTAINS_OTHER_CAPTION`，要求先手工处理。
6. **撤销**：`SPLIT_CAPTION` 的逆操作是"左段恢复 + 右段按 id 删除"两个操作的数组（`planUndo` 支持返回多个）；`DELETE_CAPTION` 的逆操作是 `create_caption` + `restoreCaptionId`（字幕是复合对象，复原按原 id 重建）。
7. **已知缺口**：片段原语（trim/ripple/move）**尚未自动平移字幕**——通用字幕轨道跟随属 N03-08／N11；转写版本回写属 N07。
