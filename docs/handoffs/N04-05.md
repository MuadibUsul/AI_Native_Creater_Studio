## 已交付

`packages/contracts/src/attention.ts`：

- `attentionEventSchema`：11 类事件（`POINTER_SAMPLE/POINTER_DOWN/POINTER_UP/HOVER_CHANGE/SELECTION_CHANGE/PLAYBACK_STATE/SEEK/VIEWPORT_CHANGE/PRESENTED_FRAME/VOICE_CLOCK/TRANSCRIPT_REVISION`），统一信封 `eventId/sessionId/epoch/seq/monotonicMs/producer`。
- `createAttentionBuffer` / `appendAttentionEvent` / `pruneAttentionBuffer`：有界（默认 8s、512 事件）；fail-closed（epoch 不一致 / 同生产者单调时钟回退 / seq 不递增）。
- `decimatePointerTrajectory`：最小距离去样 + 点数上限（保留末点）。
- `attentionSnapshot` + `attentionSnapshotSchema`：事件 + 轨迹 + 语音时钟映射，缺词级时间时 `wordTimingAvailable=false`。

## 接手要点

1. **时钟是单调的**：`monotonicMs` + `epoch`；不用墙钟，不靠网络到达顺序。重连换 epoch 必须**新建缓冲**，不能复用旧 seq。
2. **seq 是生产者内有序**，不是全局有序；不同生产者各自维护。
3. **呈现帧用真实呈现证据**：`PRESENTED_FRAME` 对应 `requestVideoFrameCallback()` 的 mediaTime，不要用每秒几次的 React state。
4. **轨迹最小保留**：默认只保留去样后的短时轨迹，不要在此基础上默认永久落盘。
5. **语音精确绑定**：只有供应商提供可验证词级/音频位置时才把 `wordTimingAvailable=true`；否则用发话快照 + 明确点击 + 短时上下文。
