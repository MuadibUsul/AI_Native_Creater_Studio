## 0. 核心裁决

**鼠标确定对象、形状和时间，语音确定意图；系统实时显示自己理解的目标，并在同一画布给出可撤销的试改。**

不是“给聊天框增加麦克风”，也不是“把传统编辑器所有按钮改成口令”。默认界面仍是大画布、紧凑横向时间带和一条可打断的对话栏；专业能力按需展开，不削减真实素材剪辑能力。

本增量继续使用 ProjectDocument、SelectionAnchor、AttentionSnapshot、Edit Operation v2、Proposal/Preview Branch、MediaIndex、现有权限/范围锁/历史/费用系统。不得另建一套权威时间轴、一份聊天工程或独立的语音编辑数据库。

用户本次明确强调的点、线、面、横向时间定位，以及快速流式语音，列为核心体验验收项。本文中接口字段、阈值、任务细分和性能数值均为建议，实施时按实际 schema 与基准测试定稿；不能据此更改已有 VERIFIED 状态。

## 2. 默认用户界面

### 2.1 三个常驻区域

**画布：** 展示真实视频/素材合成结果。轻量覆盖层显示悬浮轮廓、选区、路径、时间作用域标签和试改前后差异。文字与标签用真实 DOM/SVG 文本绘制，不通过生成图像重新生成中文。

**横向时间带：** 默认常驻一条紧凑缩略/波形带、播放头和独立时间选择。按需展开轨道、源入出点、关键帧和曲线，不能让用户在“看片模式”和“时间轴模式”间切换两份作品状态。

**对话栏：** 麦克风、最多两行实时转写、目标摘要、真实任务状态。候选就绪后显示“采用 / 继续调整 / 对比”。完整历史和技术差异放入抽屉，不占据主画布。

黑白主题、清晰边界、少量语义强调；不新增装饰渐变、霓虹或大面积毛玻璃。不能仅靠颜色区分监听、试改、确认等状态。

### 2.2 选择状态必须能看懂

示例：`字幕「增长放缓」 · 00:12.400–00:15.200 · 只改位置 · 试改版 3`。

对象、范围、属性与版本分别可以检查和修改。改变时间范围不清空空间对象；调整对象不自动扩大到整片。空交集必须显示“该对象不在这段时间出现”，不得静默扩大范围。

悬浮是短时提示，点击/框选是明确选择。选中的目标不随鼠标离开而消失，直到用户明确清除、替换，或系统标记其已失效。

## 3. 鼠标点、线、面的交互语法

### 3.1 点：选中目标，而不是只保存一个屏幕坐标

| 行为 | 默认结果 | 不允许的结果 |
|---|---|---|
| 悬浮 | 本地轻高亮命中候选；不暂停、不修改、不发昂贵分析 | 鼠标每动一次就调用视觉模型 |
| 单击结构化对象 | 选择 objectId 与其当前版本，显示标签；交互编辑时按需暂停 | 只把截图坐标拼进 prompt |
| 单击真实视频中的物体 | 立即显示点/区域证据；按需解析对象或跟踪 | 尚未分割就宣称“已选中独立人物图层” |
| 多选 | 保留明确选择顺序；形成 A、B 等临时标签 | 后一次点击无条件覆盖前一个目标 |
| 命中重叠对象 | 优先可见细粒度对象，允许轮换候选/打开小型对象列表 | 永远命中最外层 Scene |
| 精确拖动 | 拖动选中对象的明确手柄可直接变换 | 用户画线表达意图时把素材拖走 |

字幕文字、图表线条、形状、图片等原生对象应由组件注册真实命中信息。层级包括 `objectId / parentId / zOrder / localBounds / transform / supportedProperties`，具体字段并入既有契约。透明命中、裁切、遮挡与可见性不能仅用轴对齐包围盒代替。

对真实视频像素，区域锚点与可独立编辑对象分开。对象解析失败时仍允许几何区域处理或整 Clip 操作，但必须如实显示能力边界。

### 3.2 线：必须保存“这条线是拿来做什么的”

| 线类型 | 用户表达 | 系统解释 |
|---|---|---|
| 轨迹线 | 画一条弧线：“让标题沿这个方向出来。” | 运动路径；方向、起终点、时间范围与缓动分别绑定 |
| 边界线 | 沿地平线画线：“这条线以上压暗。” | 分区边界；明确选择哪一侧，不能只按封闭区域处理 |
| 指示线 | 从 A 划向 B：“把这个放到那里。” | source 与 destination 两个不同角色，不能让终点改写原目标 |
| 笔刷线 | 涂过几个区域：“这些不要动。” | 保护/包含/排除的局部提示；笔刷宽度和正负意义必须保留 |
| 已有线对象 | 点击图表曲线：“这条线更粗，数据别变。” | 修改原生线对象的样式，不重新生成图表数值 |

不能仅凭手画曲线“看起来接近闭合”就自动决定是蒙版还是轨迹。默认保留原始几何；语音补足用途。用途不明确时仅弹出一个小选择：“作为移动路径，还是圈出范围？”

手画速度不默认成为动画速度。几何按弧长重采样；时间与缓动由选定时间段和语言决定。原始采样用于复核，简化路径用于预览，两者都绑定版本。路径自动平滑必须可关闭，并允许控制点微调。

### 3.3 面：区分固定画面区域与跟随对象

矩形框、多边形、自由套索、笔刷区域均属于同一选择协议的几何变体。点/线/面不是三个独立编辑系统。

选中真实人物区域后，标签应明确：

- `固定在画面这个位置`：区域留在画布坐标上。
- `跟随选中的人物/物体`：使用指定对象轨迹与对应源版本。

用户说“这个人一直保持亮，其他地方暗一点”，默认提出跟随目标的处理；不能用固定矩形冒充跟踪。跟踪遇遮挡、出画、镜头切换或身份歧义时显示具体失效范围，允许补点/正负笔刷纠正。跨镜头不自动将相似人物视为同一目标。

“选区不变”与“选区外画面绝对不变”属于不同要求。确定性局部效果通过真实蒙版约束；生成式编辑若不能严格约束外部像素，应先说明并采用外部区域回贴/合成验证，不能承诺未验证的无损保护。

### 3.4 手势冲突裁决

默认“指向”工具负责悬浮、点击和空白处矩形拖选；选区出现后才显示移动/缩放手柄。上下文工具条提供“画线 / 圈选”，允许配置快捷键，但不强迫新用户记住大量组合键。

时间标尺拖动播放头负责 scrub；单独选择带的拖动负责选时段。时间范围把手负责调整范围，片段边缘手柄负责真实 trim。三者的可见命中区域不能重叠。

选择动作本身永不改工程。直接变换只在明确变换手柄/控制模式下发生，并进入与语音相同的操作与历史链路。按 Esc 取消当前手势或当前草案，不等于撤销正式工程。

## 4. 横向时间定位：从播放条升级为完整作用域

### 4.1 四类定位

| 类型 | 例子 | 必须记录 |
|---|---|---|
| 时间点 | “这里切开”“从这里开始淡入” | 当前序列、精确时基、边界方向 |
| 连续区间 | 横向拖选 12–15 秒：“这段音乐轻一点” | 半开区间 [start,end)、目标轨道/对象 |
| 多区间 | 多选三个停顿：“这些地方统一处理” | 多个显式 range，不合并成中间整段 |
| 语义时间段 | “刚才那句话”“人物转头之前” | 转写/事件证据、观看历史、解析出的精确范围 |

横向坐标先根据时间带可视窗口换算，再进入项目有理时基；不直接以浮点毫秒作为新工程权威时间。缩放以鼠标位置为中心，支持横向滚动、边缘自动滚动、逐帧步进和明确吸附提示。吸附优先级由活动上下文决定，提供临时关闭入口；不能为了吸附改变用户未同意的作用域。

### 4.2 时空联合选择

实际作用域 = 明确对象/区域 × 时间范围 × 目标轨道/属性 × 绑定版本。

“选中这个人 → 选 12–15 秒 → 说只把人物提亮”：目标是这一时间段内的对象/跟踪区域，不是全段视频；“选中音乐轨 → 选 12–15 秒 → 说小一点”：目标是音乐增益，不是视频亮度或所有音轨。

这不是简单集合相交就结束：编辑器还需要计算间接影响。删除时间、变速、转场、混响尾音、运动模糊等可能涉及选区外依赖。预览可包含前后句/前后镜头作为观看上下文，但实际编辑范围不得因此扩大。超出范围的涟漪位移或重算影响必须显式展示，并经过已有锁与影响集校验。

### 4.3 源与序列时间

原素材定位保留 assetVersionId、streamId、clipInstanceId 与源 PTS；工程定位保留 sequenceId 与序列范围。剪切、重复引用、slip、retime、嵌套后，由现有时间映射重新投影，不用一个“当前秒数”覆盖全部语义。

锚点明确其跟随对象、跟随源内容或固定序列位置的策略。移动 Clip 时，跟随对象的选择随之移动；固定序列区间不自动跟随。重复素材引用造成多个可用位置时返回 AMBIGUOUS，不随机选一个。

## 5. 共同注意力：把边说边指变成可复核协议

### 5.1 同一时间体系，保留不确定性

有限环形事件缓冲记录本地单调时钟、会话 epoch、播放版本、实际呈现帧、播放/暂停/seek、视口变换、显式选择、路径采样，以及语音采样时钟对应关系。

WebRTC 音频和控制消息不能靠网络到达顺序对齐。应记录事件时间与映射误差；只有供应商提供可验证的词段/音频位置时才精确绑定词语。缺少词级时间时使用发话快照、明确点击事件和短时上下文，必要时询问，不能把猜测标成逐词精确定位。[W01][W03]

`requestVideoFrameCallback()` 提供媒体呈现时间等信息，可用于原生视频呈现证据；Remotion Player 应使用自身帧事件/控制接口，并与内嵌媒体状态协调。不能用一个每秒几次的 React 状态更新当逐帧权威时钟。[W05][W08]

### 5.2 必须支持的指代

**“这个移到这里。”** 第一次明确指点锁 source，第二次指点锁 destination；不能句末只看鼠标最终位置。

**“不是这个，是旁边这个。”** 同一指令修订 target，取消或替代旧私有预览，不创建两个并行正式编辑。

**“从这里到这里。”** 两次时间点击配成 start/end；逆序时标准化顺序，但保留用户输入方向用于说明。

**“停，刚才那个。”** 先按发话时的观看记录定位候选，不按 ASR 返回时的播放头定位。跨 seek、倍速或回看时，用实际观看历史，而不是简单减去两秒。

**“这个保留，后面的都换掉。”** 分离 preserve scope 与 edit scope；先展示“后面”的实际范围，不自动取消已确认对象的保护。

### 5.3 证据优先级与冲突

明确语言范围与同轮明确选择都是强证据；互相冲突时不能武断只听其中一个。保留既有选择，展示解析差异，仅问影响结果的一个问题。悬浮是最弱证据，短时有效，不能覆盖持续的明确选择。

选择绑定于用户正在看的 preview/proposal revision。不能拿确认版的对象树解释另一个试改版本的画面。

## 6. 流式语音：快的是整个交互闭环

### 6.1 默认交互

首次用户显式打开麦克风后进入持续对话模式，可在看片/指点时自然发话并随时打断；结束会话立即停止采集。按住说话作为同等支持的控制方式，适用于嘈杂环境或用户主动选择，不把“每句按住按钮”设为唯一体验。

文字输入与语音进入同一 IntentSession，不维护两份对话、两套对象选择或两套编辑历史。

### 6.2 三条执行通道

**本地反馈通道：** 鼠标命中、选区绘制、时间范围、录音状态、立即停止 AI 播放、已缓存的确定性 ghost/参数预览。不给本地鼠标反馈增加网络往返。

**实时会话通道：** 流式音频/转写、指代解析、短回应、打断和意图草案。已授权会话保持可用连接，不每句话重新建立连接；空闲和显式结束后按策略释放，显示真实监听状态与计量。

**正式制作通道：** 工具授权、完整结构化操作、权限/锁/版本/预算验证、私有候选、耗时渲染/生成和原子采用。复杂制作使用既有 Worker，不阻塞继续说话或看片。

简单位移、字幕大小、局部音量等通过共享确定性操作内核试改，优先复用已有素材与参数。复杂创意再调度导演推理或生成。不能每次微调都上传整片、重写全部 Scene 或重新生成视频。

### 6.3 技术选择

浏览器默认优先 WebRTC 双工语音；ANCS 后端管理会话归属、工具执行、权限、预算与状态。供应商支持 sideband 时可让浏览器走音频、服务器走工具控制；不支持时由适配器使用受控转发。OpenAI 当前官方文档提供 WebRTC、短期客户端凭证和服务器侧控制通道作为可核对实现参考，不将其等同于已证明“中文最优供应商”。[W01][W02]

主路径不强制“整段录音上传 → 完整转写 → 完整大模型回答 → 再完整 TTS”的串行流程。可以用实时语音模型承担对话前台，也可以由适配器接流式 ASR/文本推理/TTS；语义提交、作品版本和权限都由 ANCS 协议控制，不能由供应商自动工具调用绕过。

不以浏览器 SpeechRecognition 作为唯一生产语音后端，其相关能力的浏览器覆盖仍有限。AudioWorklet 可承担需要显式采样时钟的轻量本地音频处理；不要在音频实时线程做大模型推理或重分割。[W06][W07]

音频与重素材上传应有独立的连接/队列与并发控制；用户说话时限速低优先级代理上传，避免上传占满上行。选择、ASR 和控制消息都携带事件标识与版本，不能靠“一个 WebSocket 保序”推导所有通道的全局顺序。

### 6.4 五类真实流式表现

| 阶段 | 用户看到/听到 | 系统能做什么 |
|---|---|---|
| 转写中 | 可修订文字，例如“把这条线……” | 本地选择反馈、只读查询、可撤销预备状态 |
| 目标解析中 | “图表曲线 A · 当前 3 秒” | 高亮候选，补齐 source/destination/range |
| 意图已锁定 | “加粗曲线；数据不变” | 校验完整操作，准备确定性私有试改 |
| 试改中 | 参数预览/跟踪覆盖/真实任务阶段 | 给出可观察结果，不编造百分比 |
| 可回放 | 自动局部回放与原版对比 | 用户微调/采用，记录确认决定 |

不要强制播放“好的，我已经理解您的需求”等空回应。目标明确就用画布行动；只在歧义、费用或结果解释需要时短答。字幕逐字显示不是全部流式体验，真实画布和操作状态也必须逐步可见。

## 7. 半句话、改口与打断

### 7.1 转写不可只做字符串追加

事件至少含 `utteranceId / transcriptRevision / replaceRange / text / isFinal / audioRange?`。供应商只提供追加 delta 时由适配器归一；最终转写可能修正前文，必须能替换。不同 utterance 的 completed 可能乱序，按项目内事件与 utterance 标识处理。[W03]

`partial transcript → draft intent → sealed intent → validated proposal → accepted edit` 是不同状态。ASR 把某段标成稳定，不等于用户在语义上已说完。VAD 静音也不等于授权确认。

### 7.2 提前计算的边界

可提前做：查询已有素材索引、缓存字体/代理、生成只读目标候选、准备可撤销的参数草案。

不可提前做：正式修改、删除源文件、付费重生成、发布、接受最终版本，或把尚未通过 schema 校验的流式 JSON 直接送入编辑器。

普通可逆修改可在完整语义子句成立后给出私有试改；未完整的句子最多显示预备态。用户说“把这段删掉……不是，我说把音乐去掉”，不得在前半句启动内容删除或付费修补。

### 7.3 断句

采用本地语音活动提示与服务端/语义断句的组合；支持按住说话的明确句末。短命令和长描述使用不同等待策略，遇到“但是、不要、除了、不对”等未闭合限制词时不抢先锁定意图。

VAD 与语义断句是供应商/模型能力，不可假定所有实时转写模型都支持同一配置；通过 capability negotiation 选择。更短静音阈值是响应速度与截断风险的权衡，不是越短越好。[W04]

### 7.4 三种停止仍严格分开

1. 打断播报：本地先停止 AI 音频，服务器同步未播放内容的会话状态。
2. 停止/替代试改：令当前 proposal generation 失效，晚到结果不得抢回画布。
3. 取消生成：向实际任务发取消请求；供应商不能取消时标明“已停止采用，任务可能继续产生费用”。

这三者都不自动撤销已采用的作品，也不自动退款。用户说“就这个”必须绑定已展示的具体 proposal revision；不能在 partial transcript 中执行采用。

## 8. 几何、时间与状态的建议契约

以下为设计字段，不是已实现 SDK。优先扩展现有类型，避免创建同义实体。schema 版本号按仓库规则分配，不把本文的产品文档版本直接用作 schema 版本。

### 8.1 GeometrySelection

```text
GeometrySelection
  kind: POINT | POLYLINE | RECT | POLYGON | BRUSH
  role: TARGET | MOTION_PATH | BOUNDARY | SOURCE | DESTINATION | PROTECT | EXCLUDE
  coordinateSpaceRef
  referenceFrame: { sequenceTime, sourcePTS?, previewRevision }
  data: 由 kind 决定的严格判别联合
  strokeWidth? / closed? / boundarySide?
  rawSamplesRef? / simplifiedGeometry
  geometryRevision
```

点线面都要验证有限数、坐标范围、点数和数据大小；多边形自交、退化线、空面、笔刷宽度等按用途拒绝或要求修正。不能所有几何都压缩成一个 bounding box，也不能用不受控 JSON 存全部含义。

### 8.2 SelectionAnchor 增量

```text
在既有 SelectionAnchor 上增加或归一：
  geometries[]: GeometrySelection
  orderedTargetRefs[]
  temporalSelection: POINT | RANGES
  sequenceRanges[]: MediaRange
  trackScope / propertyScope
  regionMode: SCREEN_FIXED | SOURCE_FIXED | OBJECT_TRACKED
  timeBindingPolicy: SEQUENCE_FIXED | FOLLOW_OBJECT | FOLLOW_SOURCE
  trackingRef? / referenceFrame
  resolutionStatus / evidenceRefs / remapHistory
```

实际类型需表达合法组合，例如路径需要方向，边界需要作用侧，跟踪区域需要有效 trackingRef。POINT 不伪装成长度为零的 RANGE；MediaRange 保留既有半开区间及有理时基语义。

### 8.3 IntentSession / IntentRevision

```text
IntentRevision
  sessionId / utteranceId / intentId / revision
  attentionSnapshotId / transcriptRevision
  targetBindings[]: { reference, role, evidenceRefs }
  interpretedAction / explicitConstraints / assumptions
  status: DRAFT | NEEDS_CLARIFICATION | SEALED | SUPERSEDED | CANCELLED
  supersedesIntentRevision?
  proposedOperationRefs[]
```

同一次用户意图的“再小一点、不是左边是右边”修订当前提案，而不是重新从确认版生成无关任务。改变目标、时间范围或重要限制后，旧计算结果失效。

### 8.4 事件信封

```text
EventEnvelope
  eventId / sessionId / clockEpoch / seq
  utteranceId? / intentId? / intentRevision?
  baseProjectRevision / proposalId? / proposalRevision?
  producer / occurredAt / receivedAt
  causationId? / supersedesEventId?
  payloadSchemaVersion / payload
```

seq 仅在定义的生产者/会话流内有序；不能把不同连接序号误作全局有序。服务端记录确认水位并提供恢复快照；断线重试使用稳定幂等键，重发不能生成新业务身份。

### 8.5 候选采用的完整性

候选采用绑定 `baseProjectRevision + intentRevision + selectionFingerprint + operationsHash + assetVersionRefs + proposalRevision`。服务器重新验证租户、对象归属、范围锁、间接影响、预算与有效能力，再原子写入。

本地预览只是预测性投影，不是授权结果。服务器校验失败时不得显示“已采用”；原确认版必须仍完整。用户修订、取消、版本变化后，旧回调只能记入相应私有任务，不能更新新候选。

### 9.3 性能实现注意

所有命中本地优先；只在明确选中、稳定停留且有预算策略，或明确要求语义识别时才做重分析。范围变化时取消过时的只读请求或隔离结果。

预览缓存至少包含媒体源版本、项目/候选相关依赖、参数与操作 hash、时间映射、输出规格、渲染器版本。局部重算要包含真实时间依赖，不能为求快裁掉转场/音频尾音/跨帧效果。

不要为了支持点线面把现有播放器全部换成截图生成。使用已有播放器加交互覆盖层；生成资产只在真实需要时引入。

## 10. 响应指标：建议验收目标，而非实测结论

### 10.1 温连接、就绪素材的目标

| 指标 | 起止定义 | P50 目标 | P95 目标 |
|---|---|---:|---:|
| 选择反馈 | 指针事件到正确轮廓/选区首帧 | ≤16 ms | ≤50 ms |
| 录音反馈 | 用户启用/本地检测发话到可见状态 | ≤50 ms | ≤100 ms |
| 首段有效转写 | 首个可识别语音音频进入客户端到有意义文字 | ≤300 ms | ≤700 ms |
| AI 播报打断 | 本地检测用户发话到 AI 音频停止 | ≤100 ms | ≤200 ms |
| 完整意图确认 | 用户实际说完到正确目标+动作显示 | ≤500 ms | ≤1,200 ms |
| 确定性真实试改 | 用户实际说完到可播放的参数修改结果 | ≤800 ms | ≤1,800 ms |

“已收到”、空转圈、预先缓存的无关画面、不含真实修改的占位，不计入完成。局部参数试改目标只适用于已支持、无需新增素材或重视觉分析的动作，不适用于生成式补全、视频重生成、慢速代理或长片渲染。

冷连接建立、素材未就绪、跟踪/分割、复杂导演推理和长任务单独统计，不能从报告中剔除。耗时制作展示真实阶段、已有部分结果和取消状态，不作统一“2 秒出片”承诺。

### 10.2 测试条件

记录客户端硬件、浏览器、显示刷新率、项目规模、缓存状态、音频设备、供应商/模型版本、网络 RTT/抖动/丢包和代理链路。基线至少覆盖正常网络与注入 150 ms RTT / 1% 丢包的压力组；这是建议测试条件，不代表用户现实网络。

至少 200 条真实中文测试指令，覆盖否定词、数字、小数、单位、对象名、中英专业术语、长句、改口、外放回声、多对象指点与边说边拖选。评估目标/范围/属性是否正确，而不只计算文字识别率。

建议门槛：预先定义的清晰指令集合，联合目标/范围/动作成功率 ≥95%；所有高影响操作和越权/已锁定保护用例必须通过。压力测试中观察到“零越界修改”不能宣传为任意场景绝对零错误；需报告样本规模和失败情况。

以完成一个有效修改的时间为核心指标：从表达开始，到可判断候选、到最终采用；同时报告平均修正轮次、无谓澄清率、误执行率、失败恢复时间和每次被采用编辑的成本。

## 11. 核心验收旅程

### A. 点选 + 快速语音

上传真实素材，在已有字幕上点击，说“往上移一点，其他不动”。显示准确对象与作用段，给出真实参数试改，能原位 A/B 与局部回放；采用一次仅产生一组正式事件。原声音轨、源素材与其他字幕不变。

### B. 线 + 时间区间

选中标题，画弧线，再在时间带选择两秒，说“从这边沿线进去，开始快、结尾慢”。路径作为运动轨迹，不误作蒙版或素材拖动；保留源目标与终点，按时间范围生成可编辑关键帧/路径；预览与导出检查真实位置与时序。

### C. 面 + 跟踪

在真实视频中圈出人物，选择三秒，说“背景压暗，他别动”。明确区分人物保护区与背景处理区；跟踪失败范围可见，不能把固定框当跟踪；区外保护与最终输出对照。

### D. 多对象指代

依次指 A 和 B，说“把这个标题放到这里，别碰旁边的数字”。A 是目标，B 是位置；数字为保护约束。最终鼠标在 B 不得导致修改 B 本身。

### E. 时间轴与音频

选音乐轨、框选时间段，说“这段低一点，原声不变”。仅生成音乐增益/自动化操作，不重配音，不剪掉内容、不改变序列长度，不改未选轨道。

### F. 流式修订

“把它移到右边……不对，左边。”临时计划可被修订，最终一个活动候选；旧异步结果晚到不得覆盖左移版。转写修正正确替换，不重复追加。

### G. 播放、打断与 seek

播放中说“停，刚才那个”。绑定发话时观看版本和事件时间。句中 seek 后不以模型返回时的播放头猜定位。用户发话能快速停止 AI 播报；视频自身声音不获得编辑权限。

### H. 并发、刷新与断网

候选未采用时刷新/重连，恢复确认版与可用候选状态；重复确认只产生一次正式提交。项目 revision 冲突、对象已删除、素材版本变化时拒绝或清晰重映射，不静默采用陈旧计划。

### I. 成本与外部任务

不允许 partial transcript、悬浮或普通选择触发付费制作。取消不可中断的供应商任务时保持实际费用记录；晚到资产不自动进入当前画面。会话费用与制作费用分开显示，不能称全部规划/语音免费。

### J. 显示与精度

16:9/9:16、不同缩放/高 DPI/全屏、裁切+旋转+嵌套、多次重复引用、29.97/59.94、VFR、代理映射和音频采样级边界均有测试。对象高亮位置与实际画面一致；中文标签、时间码、目标名称清晰且不被遮挡。

## 13. 运行、安全与隐私

麦克风采集必须有明确授权与可見开关；离开/结束会话停止采集。原始语音、鼠标轨迹、截图证据遵循最小保留策略；长期保留的是用户已确认的指令/决定和必要审计，而不是默认永久保存全程录音与鼠标轨迹。

内容与命令隔离：片中字幕“删除全部”、说话人读出的指令、参考视频里的提示和 AI 自己声音，都不得成为用户授权。回声消除和降音只是辅助，不能当成授权安全边界。

短期凭证不能替代后端工具授权或硬预算。缓存、对象索引、语音会话、提案与事件恢复都必须绑定 workspace/project 权限；断开权限后不得由旧连接继续写入。

真实 Provider 依赖缺少授权凭据时保持未验证，不用合成转写文本宣称语音已通。测试使用独立测试库，不触碰开发/生产原始数据，不自动购买服务。
