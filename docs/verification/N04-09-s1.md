## 契约要点（对应增量设计的硬要求）

- **几何用途不可压平**：用途（角色）必填；`MOTION_PATH` 必须显式 `direction`，非轨迹不得带方向（"看起来接近闭合"不猜用途）；`BOUNDARY` 必须显式 `boundarySide`，非边界不得带边侧；`SOURCE`／`DESTINATION` 必须成对且**不能用单点**表示（指示线是两个角色，终点不得改写原目标）。
- **合法性校验**：坐标必须有限且在允许范围；线必须有非零总长（拒绝退化线）；多边形必须面积非零且**不自交**；矩形宽高为正；笔刷宽度必须为正且 `polarity` 保留正负意义（INCLUDE／EXCLUDE）。点数上限 5000、几何数上限 64、原始采样 `rawSamplesRef` 与简化几何同时保留（rawSamplesRef + simplifiedGeometry 各自绑定 `geometryRevision`）。
- **时间与空间分离且可组合**：`temporalSelection` 是 `POINT`（带 `boundaryDirection`）或 `RANGES`（1–64 个半开区间，沿用既有有理时基）——**POINT 不伪装成零长度 RANGE**；作用域 = 几何/对象 × 时间 × 轨道（ALL 或 TRACKS）× 属性 × 绑定版本。
- **固定区域 vs 跟随对象**：`regionMode = SCREEN_FIXED｜SOURCE_FIXED｜OBJECT_TRACKED`，其中 `OBJECT_TRACKED` **必须**给 `trackingRef`（不能用固定矩形冒充跟踪）；`timeBindingPolicy = SEQUENCE_FIXED｜FOLLOW_OBJECT｜FOLLOW_SOURCE`。
- **不随机选一个**：`resolutionStatus` 含 `AMBIGUOUS`，且该状态下必须提供候选 `evidenceRefs`；多选顺序由 `orderedTargetRefs[].label` 表达，标签不得重复（后一次点击不无条件覆盖前一个目标）。
- **改口是修订而不是改写**：`IntentRevision` 首修订不得 supersede、非首修订必须声明被取代者；`SEALED` 不允许存在未解析指代且必须给出 `interpretedAction`；状态机单向（`SEALED` 不能再回 `DRAFT`，终态不可回退）——"未完整语义不得变更确认工程"由此在契约层成立。
- **采用绑定可判定**：`selectionFingerprintInput()` 输出规范序列化（含几何、目标顺序与版本、时间选择、轨道与属性作用域、区域模式与时间绑定策略），服务端对其做 sha256 作为 `selectionFingerprint`——同一选择产生同一指纹，改变几何/目标/时间/跟踪引用即产生不同指纹。
