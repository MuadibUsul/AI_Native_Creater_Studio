# N01-02｜ProjectDocument 与模式约束验证

日期：2026-10-08。状态：**VERIFIED**。依赖 N01-01 已 VERIFIED。

## UI 交付卡

- **用户目标 / 角色 / 空间：** 创作者可建立纯素材、纯生成或混合项目；“只剪我的素材”等限制必须成为项目规则。
- **入口 / 对象 / 范围：** 本任务扩展现有项目创建契约与服务端生成入口，作用于单个 Project。项目模式可随创建请求写入；面向用户的模式选择和设置交互由 N03-08/N01-09 接入。
- **主流程 / 恢复：** 创建项目时保存 Brief 与细粒度 ProductionPolicy；读取时从同一规范化聚合组装 ProjectDocument；旧 SceneGraph 作为只读兼容投影。策略阻止不会创建 Job、调用 Provider 或产生费用。
- **权限 / 费用 / 锁定：** 沿用项目写权限；生成许可在 Provider 路由、Job 和费用之前由 domain 强制。项目 Provider allowlist 非空时还需匹配实际路由。
- **设计覆盖：** UI 不适用。本任务是 contracts、migration 和 domain 基础；没有新增用户界面，也不把尚未实现的模式 UI 称为完成。
- **业务 / 测试：** 真实隔离 PostgreSQL、API/SDK 创建路径和生成路由均有集成证据；Mock/真实 Provider 均未调用。

## 实现

- 新增 `project-document.ts` 契约：`schemaVersion=1.0`、Brief、三模式、细粒度 ProductionPolicy、IdentitySnapshot、可空 SemanticPlan、Composition、依赖图、锁、RenderProfile 与 SceneGraph 兼容投影。
- `FOOTAGE_EDIT` 默认禁用生成视频、图片、语音、音乐、音效、补帧、生成填充和脚本改写，同时允许分析已有素材并保护原声与原顺序。`HYBRID` 默认保守开放分析、字幕和程序化图形，其余生成能力需显式开启。`GENERATIVE` 保持旧创建调用兼容，但声音替换仍默认关闭。
- 迁移 0057 在规范化 `projects` 聚合增加 `document_schema_version`、`brief` 与 `production_policy`；旧行以兼容的 `GENERATIVE` 策略回填。没有新增可独立写的大 JSON 工程表。
- `assembleProjectDocument` 从现有项目和 SceneGraph 组装统一读模型；空纯素材项目的 SemanticPlan 可为 null，Composition 可先存在。旧 Scene 通过稳定 `cmp_<sceneId>` 关联语义与合成对象。
- `requestSceneGeneration` 在 Provider 路由、Job 创建和费用之前调用项目策略门。禁用能力返回 409 `CAPABILITY_UNAVAILABLE`，details.reason=`PRODUCTION_POLICY_BLOCKED`，并给出合法替代说明。

## 边界与回滚

- N01-02 定义统一文档和模式门，不包含 N01-03 的正式 Sequence/Track/Clip、N01-05 的旧版本迁移、N01-09 的完整工程 API/SDK 读写，也不包含 N03-08 的三模式 UI。
- `compatibility.sceneGraph` 是同一状态的只读投影，不能作为第二个写入口。现有规范化项目/场景表仍是事务权威；后续对象继续并入同一聚合。
- 旧行兼容策略允许原有生成链保持行为；新纯素材/混合项目采用保守默认。迁移回滚前须先停止写入新增字段；回滚不得删除项目、场景、媒体或版本。
- 没有真实 Provider、外部网络、生产数据或费用。
