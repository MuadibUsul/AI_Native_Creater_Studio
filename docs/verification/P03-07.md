- **本次修复的工程问题（诚实记录）**：
  1. **完成迁移覆盖处理器结论**：处理器做对账标记（FAILED_RETRYABLE）后，执行器仍会 `completeJob` 将其推回 SUCCEEDED（非法迁移 → 级联误判）——执行器增加**完成前状态复核**（仅当仍 RUNNING 才完成）。
  2. **重复回调的不同路径**：同一回调经进程内路径二次到达时，state 已 COLLECTED 但流程继续注册+回收 → 重复落资产；回收服务对已 COLLECTED 直接幂等跳过。
  3. **Mock 提交签名**：初版 Mock 的 `submit` 只要求 `{jobId,inputHash}`，与契约 `GenerationSubmitRequest`（含 workspaceId/providerId/modelId/operation/parameters）不一致——按契约收紧（避免"Mock 能过、真实适配器不能过"的假绿灯）。
  4. **慢任务的 inline 误判**：inline 首版只轮询一次 → 慢任务被当作"仍在进行"即返回，端到端测试看不到完成；改为**有界轮询到终态**（上限可配）。
