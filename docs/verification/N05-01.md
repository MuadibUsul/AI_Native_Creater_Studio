## 实现证据

- **短期凭证、长期 Key 永不下发**：创建会话返回 `{ session, credential }`，凭证是 HMAC-SHA256 签名的**短期令牌**（作用域 `voice:stream`／`voice:tools`，TTL 15 分钟）；**凭证只返回一次**，之后读取会话不再回带任何凭证材料；未配置签名密钥（`ANCS_VOICE_SESSION_SECRET`／`buildServer({voice})`）时创建会话 **501 fail-closed**，绝不回退到 Provider 长期 Key。
- **权限不信任客户端**：会话创建需要 `project:write`（无权限/跨租户 → 404 抗枚举）；会话绑定 `selectionAnchorId` 时校验锚点属于同一工程。
- **能力显式**：`VOICE_ADAPTER_CAPABILITIES` 按传输方式声明 supported/unsupported（`SERVER_RELAY` 全支持；`PROVIDER_SIDEBAND` 无逐词时间戳与服务端工具；`BROWSER_SPEECH_FALLBACK` 只承诺流式 partial，明确不承诺服务端 VAD／逐词时间戳／服务端工具／打断）；未列出一律视为不支持。
- **流式协议状态机**：事件信封含 `eventId/kind/sessionId/clockEpoch/seq/generation/utteranceId/requestId/intentRevision`——序号只在会话流内有序；`TRANSCRIPT_PARTIAL`／`TRANSCRIPT_REVISED` 写会话草稿（改口产生新修订并 `supersedesRevision` 取代旧修订），**partial 只读**：不写 `edit_events`、不推进工程 revision（响应显式带 `projectUntouched: true`）。
- **代际与状态门**：`generation` 不匹配、`clockEpoch` 不匹配、序号倒退、会话 `CLOSED/EXPIRED/REVOKED` 一律 409/422（晚到结果不得抢回新画面）；读取过期会话时顺目标记 `EXPIRED`；`close` 幂等。
- **封存即意图**：`sealUtterance` 把某 utterance 的**最新**转写修订 + 解释动作 + 目标绑定封存为规范 `IntentRevision`（`status: SEALED`）——被新修订取代的旧修订、或存在未解析指代时 422／409；**封存需要会话绑定选择锚点**（无锚点即无可验证作用域）；封存同样不改工程，正式变更必须走统一编辑协议。
- **API／SDK**：`POST/GET .../voice-sessions[/:id[/events|/seal|/close|/revoke]]` 六个端点与对应 SDK 方法。
