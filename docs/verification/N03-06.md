## 实现证据

- **契约**（`packages/contracts/src/audio-crossfade.ts` + `composition-edits.ts`）：
  - 判据常量 `AUDIO_MIX_GUARD_REASONS`（`MIX_CLIPPING_DETECTED`／`MIX_EMPTY_OUTPUT`／`ORIGINAL_SPEECH_PROTECTED`）；
  - 等功率曲线纯函数 `equalPowerFadeGains`／`sampleEqualPowerCurve`（`out² + in² = 1`）与 dB↔线性换算；
  - 新规范原语 `apply_audio_crossfade`（`leftRegionId`／`rightRegionId`／`duration`，两区域必须不同），`EDIT_OPERATION_TYPES` 38→39，v2 覆盖层新增来源操作并登记为 NATIVE（来源操作 40→41）。
- **执行器**（`packages/domain/src/edits.ts`）：
  - `apply_audio_crossfade`：校验同序列、**严格相邻**（无缝隙无重叠，`CROSSFADE_REGIONS_NOT_ADJACENT` 422）、时长必须同时放得进两侧区域（`CROSSFADE_DURATION_OUT_OF_RANGE` 422），然后给左侧写 `fadeOut`、右侧写 `fadeIn`（等功率语义），各落一条 `APPLY_AUDIO_CROSSFADE` 事件（含 before/after）→ 可逐条撤销。
  - **原声保护**：`assertOriginalSpeechPreserved` 在 `update_audio_region` 上生效——项目策略 `preserveOriginalSpeech=true` 时，凡是触碰**源时钟**的改动（`sourceStreamId`／`localRange`／`timeBinding`）一律 409 `ORIGINAL_SPEECH_PROTECTED`；增益／淡入淡出／声像／声道映射／参数这类**非破坏混音**改动照常允许（语言内容由此保证不被改写）。
- **混音计划**（`packages/domain/src/audio-mix.ts`，`planClipAudioMix`）：
  - 只读区域与轨道状态（增益、淡入淡出、声像、声道映射、`muted`／`solo`），不写任何数据、不触碰源素材、不触发生成；
  - 每轨估计峰值 = 源峰值（`parameters.values.sourcePeakDb`，缺省保守参考 −1 dBFS）+ 增益 + 声像衰减（居中 0 dB、极端 −3 dB），并给出 `headroomDb`；
  - **fail-closed**：估计峰值 > 0 dBFS → 422 `MIX_CLIPPING_DETECTED`（不静默削波）；存在音频区域但可听轨数为 0 → 409 `MIX_EMPTY_OUTPUT`（不静默产出无声混音）。
- **undo/redo**：`APPLY_AUDIO_CROSSFADE` 的逆操作用 `update_audio_region` 把该区域的淡入/淡出恢复到交叉前值（另一侧由自己的事件恢复）。

## 范围边界与记录

- **削波判据基于声明源峰值**：真实峰值需音频分析（N02 已有分析链路）产出 `parameters.values.sourcePeakDb`；未声明时用保守参考 −1 dBFS，因此任何正向增益都会被拦下（宁可拒绝也不静默削波）。真实响度/归一化（LUFS、limiter）属 N09-09—11 正式混音后端。
