# N01-04｜图形、效果、字幕与音频对象验证

日期：2026-10-08。状态：**VERIFIED**。依赖 N01-03 已 VERIFIED。

## UI 交付卡

- **用户目标 / 角色 / 空间：** 创作者需要在同一作品内移动可编辑组件、设置效果和关键帧，并让字幕与音频跟随正确的片段局部时间；这些对象在重排后仍须保持稳定身份。
- **入口 / 对象 / 范围：** 本任务扩展 Project Composition 的 VisualObject、EffectInstance、AnimationBinding、CaptionSpan、AudioRegion。真实时间轴、Inspector 和直接操作入口由 N03/N04 后续任务接入。
- **主流程 / 恢复：** 对象保存稳定 ID、时间绑定、局部范围、解析后的序列范围、参数 schemaVersion、组件／效果版本。移动对象更新同一行，不创建新身份。Undo/Redo 与完整前后状态由 N01-08 接入。
- **权限 / 费用 / 锁定：** 全部引用按 workspace/project/sequence 校验，锁定轨道拒绝写入；本任务不调用 Provider、不创建生成 Job或费用。旧渲染器未声明新对象能力时在 Render Job/费用之前 fail closed。
- **设计覆盖：** UI 不适用；这是后续专业时间轴与 Inspector 的领域基础，没有添加临时页面或在前端复制权威状态。
- **业务 / 测试：** 使用精确隔离 PostgreSQL 执行真实迁移和读写；完整回归验证现有组件输入 schema、Web、Render 与 golden 均未破坏。

## 实现

- 新增 `composition-objects.ts` 契约：四类时间绑定（Sequence、Clip Local、Source、Semantic Cue）、七类 VisualObject、版本化参数、版本化 EffectInstance、线性／保持关键帧、CaptionSpan 逐词 timing、AudioRegion 声道／gain／pan／fade。
- 新增迁移 0059 与五张规范化表：`composition_visual_objects`、`composition_effect_instances`、`composition_animation_bindings`、`composition_caption_spans`、`composition_audio_regions`。所有实体带 workspace/project/sequence 范围和稳定 ID。
- 组件对象保存 `componentId + componentVersion` 与独立参数版本；移动／换轨只更新时间和轨道字段，ID、组件引用及参数不变。旧 Scene `props` 和现有组件输入 schema 未改写。
- Clip Local 范围通过有理数边界映射到 Sequence；映射后必须可精确反算，否则以 `TIME_PRECISION_LOSS` 拒绝。字幕词范围必须位于 CaptionSpan；音频 fade 总长不得超过 region，source stream 必须与绑定 Clip 一致。
- 效果类型和版本来自固定 registry；未知类型／版本返回 `UNSUPPORTED_EFFECT`。每个效果保存 `requiredCapability`；执行层未声明能力时返回 `EFFECT_EXECUTION_UNAVAILABLE`。
- 当前 legacy Render 尚未消费规范化对象；任何可执行新对象存在时，`createRender` 在权益、快照、Job 与费用之前返回 `NORMALIZED_COMPOSITION_RENDER_UNAVAILABLE`，避免静默漏渲。N03/N09 接入执行能力后替换此门。
- `ProjectDocument.composition` 同源读取五类新对象；旧 SceneGraph 仍为只读兼容投影，没有第二套工程权威。

## 边界与回滚

- API、SDK、UI 在本任务不适用：N01-09 统一交付工程 API/SDK/事件，N03/N04 交付真实编辑入口与 UI。当前 domain 能力不是用户可见产品切片。
- 关键帧只支持 `LINEAR` / `HOLD`；贝塞尔、路径、曲线和嵌套动画由 N11-01。效果 registry 只定义模型与能力要求，没有冒充渲染后端已实现。
- Reverse Clip 的 Source-bound 对象暂时明确返回 `REVERSE_SOURCE_BINDING_UNSUPPORTED`；N03-03/N11-02 实现反向／曲线时间映射后再开放，当前不会给出错误序列时间。
- Semantic Cue binding 必须先解析为可执行时间，否则返回 `SEMANTIC_CUE_UNRESOLVED`。字幕导出、专业音频混音和真实渲染分别由 N03/N09/N11/N12 接入。
- 回滚须先停止新对象写入，再删除 0059 五表和相关契约／domain；0058 Sequence/Track/Clip、旧 SceneGraph、原媒体与既有版本不受影响。
