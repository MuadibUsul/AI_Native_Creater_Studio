- **本次修复/发现的工程问题（诚实记录）**：
  1. **Router 无候选是"抛错"而非"返回 null"**：`resolveProviderRoute` 在无可用候选时抛 501 CAPABILITY_UNAVAILABLE（P03-04 的 fail-closed 设计）。初版 Director 只判 `decision === null`，导致整个规划接口 501（集成测试暴露）。修复：捕获该明确错误 → 记 `NO_CALLABLE_PROVIDER` 警示 + blocked 任务；其它错误照常上抛（不吞异常）。
  2. **金额精度**：成本估算全链路用 BigInt 定点十进制（乘/加自实现并单测），杜绝浮点累计误差（§4.1 的纪律延伸到估算）。
  3. **查询参数契约**：`policy` 以 JSON 字符串经 querystring 传输（fastify-zod 对对象型 querystring 校验失败），服务端显式解析并给出 400 明确原因。
  4. **`sceneDraft` 扩展的兼容性**：新增字段均带默认值（既有调用不受影响）；undo/restore 的内容快照对旧事件缺失字段采取"保留现值"策略，避免历史重放误清空。
