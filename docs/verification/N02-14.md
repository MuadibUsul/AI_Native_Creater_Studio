## 实现证据

- ASR 每次重分析先保存新的原始机器版本，再从上一个 ASR 之后的不可变版本链提取人工纠错与术语覆盖；只覆盖已确认片段，未校正片段继续采用新模型结果。机器原文、人工来源、操作者与受影响片段均保留。
- 统一 Media Index 仅在转写 run 为 `READY` 时投影当前转写；用户标签继续使用 `USER_MARKER`/`USER_SUPPLIED`，人工纠错使用 `USER_CONFIRMED` 与 `correctionRecordId`，三类证据不会混写。
- 软删除在数据库事务内先把统一索引 entry 标为 `DELETED`、相关 run 与已启用阶段标为 `STALE`，随后删除派生缩略/波形对象并清空 storage key。重复调用可继续未完成的对象清理；恢复素材不会让旧索引重新生效。
- Segment search 与 Media Index 分页响应固定 `Cache-Control: private, no-store` 和 `Vary: authorization, cookie`；每次请求重新执行 Workspace 权限检查。前端删除成功后立即失效当前 Workspace 的片段搜索查询。
- 相同内容跨 Workspace 上传仍产生不同资产/版本 ID；撤销成员后旧 cursor 请求与跨租户索引读取均为 404。
