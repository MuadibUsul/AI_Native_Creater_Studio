## 缺陷修复（各附在旧行为上失败的回归用例）

| 缺陷 | 回归用例 | 旧行为验证 |
|---|---|---|
| 切换到组合权威后**全部**编辑被拒，已迁移项目无法编辑 | `composition-migration`：切换后 `update_track` 成功、`update_scene` 仍被拒 | 去掉"只拦 Scene 操作"的判断 → 该用例失败 |
| `delete_track` 级联静默删除字幕/音频区域/视觉对象（不可撤销） | 内核 `structure-ops.test.ts`；`op-log`：字幕轨与图形轨删除 → 409 `TRACK_NOT_EMPTY`，对象保留 | 换回旧 `structure-ops.ts` → 两个用例均失败 |
| A/B 对照把数据库故障等包装成 422 | 由试改引擎统一分类（与 M0 修复的提案试改一致） | — |
| 事务连接上 `Promise.all` 并发查询（pg@9 将移除） | 集成运行不再出现 pg 弃用警告 | 修复前 `composition-history` 运行可见 1 条 |
| 直接创建 API 不锁行、不推进 revision（试改缓存可能过期） | `op-log`：DIRECT 日志行 revision = base + 1 且与项目 revision 一致 | — |

**测试有效性：** 内存试改等价性用例在关闭 jsonb 归一后 7 组批次全部失败（键顺序差异导致片段行与三轴指纹不一致），恢复后通过。
