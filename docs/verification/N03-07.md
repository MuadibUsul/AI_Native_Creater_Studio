## 实现证据

- **文本契约**（`packages/contracts/src/caption-text.ts`，平台中立纯函数）：
  - `captionTextFromWords`：字幕文本**由词条重建**（词内文字原样保留；CJK 与数字/拉丁混排不补空格，拉丁词间补一个空格，标点随词条）；
  - `NEGATION_MARKERS`／`containsNegation`／`containsDigits`／`preservationTokens`：否定词与数字的保留断言工具（含"没有/不是/不要/不能/不会"等多字否定）；
  - `removeWordRange`／`splitWordsAt`：删词与断句只动**词条集合**，保留词条的文字逐字不动。
- **规范原语**（`composition-edits.ts`）：`create_caption`（含 `restoreCaptionId` 精确复原）、`split_caption`（断句，`atWordIndex`）、`cut_caption_range`（`wordFrom`／`wordTo`＋**显式 `mode`**：`CAPTION_ONLY`｜`CUT_CONTENT`，`closeAcrossTracks` 默认 true）、`delete_caption`。`EDIT_OPERATION_TYPES` 39→43；`update_caption` 由 PLANNED 翻为 ACTIVE（P06-06 遗留占位清理）；v2 覆盖层 `update_caption_segment` 由 PLANNED 改为 `COMPILED_ALIAS → update_caption`，新增 `cut_caption_range`／`split_caption` 两个 NATIVE 来源操作（41→43）。
- **执行器**（`packages/domain/src/edits.ts`）：
  - `update_caption`：只改文案/样式/区间（空文案 422 `CAPTION_TEXT_EMPTY`、越界 422 `CAPTION_OUTSIDE_SEQUENCE`），**不触碰任何片段或音轨**；
  - `create_caption`：校验字幕轨同类、词条时间落在本地范围内、区间在序列内，按 `restoreCaptionId` 或新 id 落库；
  - `split_caption`：按词条边界切开，两侧文本**按词条重建**，切口时间由 `mapCaptionLocalToSequence`（等速 1:1 假设，否则 422 `CAPTION_MAPPING_UNSUPPORTED`）映射到序列时间；
  - `cut_caption_range`：先按模式分流——`CAPTION_ONLY` 只删词改文案（时间线分毫不动）；`CUT_CONTENT` 把映射出的序列切口**真正剪掉**：整段落在切口内的片段删除、头部落在切口内的片段保留尾部并左移收缝、尾部落在切口内的片段裁到切点、切口落在片段内部时左段留 id + 右段重建（源按切口切分，切换处内容连续），跨全序列轨道收缝（或按 `closeAcrossTracks=false` 只收字幕轨 + 同步锁轨）；字幕侧：目标字幕删词并缩短、切口之后的字幕整体左移、与切口相交的字幕裁剪并删掉落在切口内的词、**完全包含另一条字幕 → 409 `CUT_CONTAINS_OTHER_CAPTION`**（不静默删字幕）；
  - `delete_caption`：显式删除（断句撤销的逆操作共用）。
- **undo/redo**：`UPDATE_CAPTION`／`SPLIT_CAPTION`（逆操作为"左段恢复 + 右段按 id 删除"两个操作）／`CUT_CAPTION_RANGE`／`DELETE_CAPTION`（逆操作 `create_caption` 按原 id 复原）／`CREATE_CAPTION` 全部登记；被平移的片段沿用各自的 `UPDATE_CLIP` 事件回位。

## 范围边界（明确未做）

- **转写版本与人工纠错**：词条来源（ASR 转写版本）在 N02-05／N02-14 已落地，本项只消费词条；从词条回写转写版本的闭环属 N07 系列。
- **跨切口字幕的二分**：`CUT_CONTENT` 对与切口相交的**其他**字幕做"裁剪 + 删词"，不做二分；完全被包含时 fail-closed 要求先手工处理（避免静默删字幕）。
- **字幕跟随其他原语**：`trim_clip`／`ripple_clip`／`move_clip` 等片段原语**尚不自动平移字幕**（本项只在字幕驱动的剪辑路径内平移字幕）；把字幕纳入通用涟漪属 N03-08／N11 的字幕轨道建模。
- **字幕样式渲染与安全区**：`captionStyleSchema`／`wrapCaption`／`buildSubtitles` 已在 N01/P06 落地并在本项复用（SRT/VTT 产物）；画布渲染与安全区视觉校验属 N03-08。
