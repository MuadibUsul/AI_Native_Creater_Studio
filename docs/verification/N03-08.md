# N03-08 验证｜多轨媒体预览与真实合成

**结论：** `VERIFIED`（2026-10-09）

**需求：** V03-03、V03-41、V03-61、V04-10、V04-14

**UI 适用性：** 本项交付**播放快照与服务端合成计划**（权威层投影）；播放器接线与画布渲染属 N03-11（PlaybackEngine 契约）与 N03-12/13（proxy 与 WebAudio 主时钟）的既定范围。关联用户切片：多轨时间线能连续播放（不是静态截图），且预览与服务端合成的是同一份工程。

## 实现证据

- **播放契约**（`packages/contracts/src/playback.ts`）：
  - `playbackSnapshotSchema`：`documentRevision` + 帧率 + 时长 + 能力 + 视频段 + 音频段 + 字幕 + 被排除轨道 + warnings（**回带 revision**，防止播放器持有隐藏工程状态）；
  - 视频段携带源版本、源/序列区间、时间映射、`transform`/`crop`/`opacity`（与 N03-05 编辑参数同源）与 `sourceHasAudio`；音频段携带增益/声像/淡入淡出与**归一化后的可听性**；字幕携带文本与区间；
  - `playbackCapabilitiesSchema`：后端类型（`HTML_MEDIA_BASELINE`／`SERVER_PRECOMPOSED`）+ 视频/音频精度（`FRAME_ACCURATE`｜`KEYFRAME_APPROXIMATE`｜`NOT_SUPPORTED`）+ 显式 `supported`／`unsupported` 标志列表；
  - `playbackFrameAt`（时间→帧）与 `frameIndexToMediaTime`（帧→时间）共用同一帧数学。
- **域投影**（`packages/domain/src/playback.ts`）：
  - `buildPlaybackSnapshot`：只读同一份工程行（序列/轨道/片段/资产版本/音频区域/字幕/视觉对象），按轨道状态归一化（`muted`／`solo`／`hidden`），**不写任何数据**；
  - 能力表 `PLAYBACK_BACKEND_CAPABILITIES`：baseline 后端 `videoPrecision = KEYFRAME_APPROXIMATE` 且**不支持** `GRAPHICS_COMPONENT_RENDER`（v0.4 增量要求：不得把所有视频强制按 React 逐帧渲染）；服务端预合成后端 `FRAME_ACCURATE` 且支持逐帧图形；`playbackSupports` 对**未列出**的能力一律返回 false（未知能力不得展示为支持）；
  - `buildServerSynthesisPlan`：由快照派生服务端合成计划（段/字幕/音频的起止帧、`documentRevision`），**不引入第二套工程状态**——预览与合成共用快照，逐帧可对照；
  - fail-closed：无任何可播放内容 → 409 `PLAYBACK_EMPTY_TIMELINE`；片段源未就绪/缺校验和/无存储键 → 409 `PLAYBACK_SOURCE_NOT_PLAYABLE`；baseline 后端遇到图形对象 → 501 `PLAYBACK_UNSUPPORTED_CAPABILITY`（带 `capability` 与后端名，不用静态截图冒充连续播放）。
- **真实媒体校验**：测试用 worker 的 `createFfmpegSourceMediaProbe` 真实解码 `packages/testing/fixtures/media-v04/` 下的 MP4/WAV，把**真实探测结果**写入资产版本后再投影快照——源区间、时长、音轨标志都拿真实解码结果对照，不用声明字段自证。

## 实测中修掉的产品缺陷

**隐藏视频轨仍会产出可播放段**：`excludedTrackIds` 已经列出了隐藏轨，但视频段循环只按 `kind` 过滤而没跳过 `hidden` 轨——即"隐藏的轨道照旧播放"。测试（隐藏视频轨后应报 `EMPTY_TIMELINE`）抓出并修复为：隐藏视频轨不进入播放段，同时保留在 `excludedTrackIds`/`warnings` 中显式说明。
