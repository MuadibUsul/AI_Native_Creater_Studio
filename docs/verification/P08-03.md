- **本次修复/发现的工程问题（诚实记录）**：
  1. **无 pg_dump 的环境**：本机 PATH 无 `pg_dump`——演练以 `CREATE DATABASE ... TEMPLATE`（点即物理副本）为等价物；脚本检测 pg_dump 存在性并在输出中如实标注（生产用 pg_basebackup/WAL，手册明确）。
  2. **日志序列化默认不含请求头**：Fastify 默认日志不落请求头，Secret 本就不出现；但为防"自定义序列化把请求头带进日志"的部署配置，redact 在**对象形式 logger 选项**下同样强制并入，并以显式序列化用例断言。
  3. **指标端点与 typed 路由**：文本响应与 zod response schema 冲突 → 指标路由采用非 typed 注册（hide schema；守卫仍走统一装饰器）。
