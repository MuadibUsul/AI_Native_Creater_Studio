- **本次修复/发现的工程问题（诚实记录）**：
  1. **Graph 的 `format.aspectRatio` 是开放字符串**（契约如此），而组件协议画幅是 4 值枚举——合成层显式归一（未知值按 16:9，尺寸不缩放）；避免把契约收窄成两处枚举打架。
  2. **输入类型解耦**：`timelineOf` 起初要求完整 Scene DTO，导致测试与 render-worker 的局部对象无法复用——改为最小结构接口（TimelineInput/CompositionSceneInput），完整 DTO 结构兼容。
  3. 预览侧素材解析逐个 try/catch（单个资产解析失败不影响整片预览），失败 = null = 占位。
