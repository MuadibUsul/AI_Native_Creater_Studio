- **验收条款对照**：
  1. **过期被正确处理** → 通过：Web 会话过期后解析为 null（真实 TTL 2s）；Access Token 过期拒绝（50ms）；Refresh 过期拒绝；授权码过期拒绝。
  2. **退出被正确处理** → 通过：Web 退出后原 Cookie 立即 401；原生 revoke 后 Bearer 与 Refresh 同时失效（家族撤销）。
  3. **刷新重放被正确处理** → 通过：旧 Refresh 重放 → `INVALID_GRANT` 且**整个 family 撤销**（新 Refresh 与派生 Access 一并失效）；并发兑换/轮换用条件更新保证恰好一次成功（`Promise.allSettled` 断言 1 fulfilled）。
  4. **错误回调被正确处理** → 通过：authorize 未登录 → 302 重定向 `error=login_required&state=…`；未注册 client / 非法 redirectUri → 400 `INVALID_CLIENT`（不重定向）；token 端点 → 400 `INVALID_GRANT` / `VALIDATION_FAILED` 统一信封。
  5. **客户端无长期明文凭据**（服务端侧保障）→ 通过：令牌与授权码仅存 sha256 哈希（测试断言整行序列化不含明文）；Access 默认 15 分钟；Refresh 单次使用 + 轮换 + 可撤销。
