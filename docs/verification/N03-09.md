## 实现证据

- **契约**（`packages/contracts/src/range-edit.ts`）：
  - `createRangeEditPlanRequestSchema`：`prompt` + `sequenceId` + **`selectedClipIds`（至少一个）** + **`allowedOperations`（调用方声明的允许操作清单）** + `brief` + `languageTag`；
  - `rangeEditSourceEvidenceSchema`：每条证据给出片段 id／轨道／是否选中或相邻／序列与源区间（ms）／资产版本／**`sourceHasAudio`**／锁定状态；
  - `rangeEditPlanSchema`：`operations`（经全部校验、可直接交给统一编辑协议）+ `outOfScope`（含原因枚举：`NOT_IN_ALLOWED_OPERATIONS`／`UNKNOWN_SOURCE_REFERENCE`／`POLICY_FORBIDDEN`／`LOCKED_TARGET`／`INVALID_OPERATION`）+ `evidence` + `originalAudioPreserved` + **`providerMediaCalls: 0`**（字面量）+ `policy` + `documentRevision`；
  - 错误原因：`INVALID_PLANNER_OUTPUT`／`NO_EXECUTABLE_OPERATIONS`／`PLANNER_UNAVAILABLE`／`INVALID_SELECTION`。
- **规划器**（`packages/domain/src/range-edit.ts`，`planRangeEdit`）：
  1. 读取序列／工程策略与片段，取**选中片段 + 同轨相邻片段**作为源证据（规划器只能引用这些）；
  2. 提示词把证据（含 `hasAudio`、区间、锁定）与允许操作清单写进去，可审计（`RANGE_EDIT_PROMPT_VERSION = range-edit-v1`）；
  3. LLM 结构化输出 → **契约校验** → **允许清单校验** → **源引用校验（不虚构素材）** → **对象锁校验** → **原声保护策略校验** → **注册表可用性校验**；每条被拒的操作连同原因进入 `outOfScope`（不静默丢弃、不整批失败）；
  4. 计划阶段**不写库、零 Provider 媒体调用**（`providerMediaCalls` 恒为 0；生成式意图只能由用户显式发起）；
  5. 可执行操作为空 → 422 `RANGE_EDIT_NO_EXECUTABLE_OPERATIONS`，并把 `outOfScope` 一并返回（说明"为什么没做成"）。
- **API／SDK**：`POST /api/v1/workspaces/:id/projects/:projectId/ai-edit/range-plan`（`project:write` 授权）；SDK 新增 `client.narrative.rangeEditPlan(...)`（与既有 `aiEditPlan` 同一命名空间）；Mock LLM 新增三个确定性脚本模式（`range_edit_trim`／`range_edit_hallucinated`／`range_edit_disallowed`），从提示词的证据清单解析真实片段与区间。
- **与原计划衔接**：本项产出的"结构化操作 + 越界说明 + revision + 零媒体调用"正是增量设计中 `IntentRevision` 的落点；后续接入流式语音时复用这条路径，不另建协议。

## 基础设施修复（随本次一并交付）

GitHub Actions 的 verify 作业在 `test:unit` 失败（`spawn ffprobe/ffmpeg ENOENT`）：真实媒体用例（探测/索引/转码）此前落在 unit 项目里，而 runner 没有 ffmpeg。修复方式**不放宽断言、不静默跳过**：
1. 三个文件改名 `*.integration.test.ts` 归入 integration 项目（unit 项目按仓库定义 = 无外部依赖的快速测试），文件头写明需要系统 ffmpeg/ffprobe；
2. CI 的 verify 作业新增 FFmpeg 安装步骤（安装后打印版本），使真实媒体用例在 CI 上真正运行。
本地证据：`pnpm test:unit` 67 files / **428 passed**；三个改名用例作为 integration → 3 files / **7 passed**。

## 范围边界（明确未做）

- **语音入口**：本项是"文本 prompt → 计划"；流式语音（麦克风采集、部分转写、指代解析、打断改口）属增量设计的 N05-01-s1…（见 gap map）。
- **私有试改与原子采用**：本项只产出计划；预览分支与采用链属 N06-01-s1/N06-02-s1/N06-04-s1（v2 注册表里 `create_preview_branch` 等仍是 PLANNED 占位）。
- **几何选择上下文**：`SelectionAnchor`／`GeometrySelection`（点线面）尚不存在（N04-09-s1），本项的"选择"是最小形态（选中片段 id 列表）。
- **效果/生成式操作**：允许清单来自规范注册表，当前可用的都是非生成式操作；任何生成式意图一律写入 `outOfScope`（不触发付费制作）。
