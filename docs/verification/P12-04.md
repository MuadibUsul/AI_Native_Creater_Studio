- **implementationSummary**：
  1. 契约 `multilingual.ts`：`terminologyEntrySchema`（(projectId, sourceTerm, targetLanguage) 唯一；kind ∈ BRAND/PERSON/TERM/NUMBER_UNIT）+ `translationJobSchema`（units 逐块 sourceText/translatedText/termMappings + numbersCheck（数字序列多重集证据）+ entitiesCheck（逐词条）+ **sourceNarrationId/derivedNarrationId 双引用**）+ `translateNarrationRequestSchema` + `MULTILINGUAL_ERROR_REASONS`（TRANSLATION_UNAVAILABLE/SOURCE_NARRATION_MISSING/INVALID_TRANSLATION_OUTPUT/TRANSLATION_INCOMPLETE/NUMBERS_CHANGED/ENTITY_MISSING）。
  2. `masterNarrationSchema` 增 `language`（null = 源语言；派生版 = 目标语言）；迁移 0040：`terminology_entries` + `narration_translations` + `master_narrations.language` 列。
  3. **合成链语言隔离（核心纪律）**：`synthesizeMasterNarration` 增 `language`/`texts` 参数——缓存源查询按语言过滤（**原语言行（language IS NULL）永不作为译文缓存源**）；cacheKey 显式含语言（`@src`/`@en`）；`texts` 覆盖旁白文本（必须覆盖全部块）；落库行带 language。
  4. domain `multilingual.ts`：`upsertTerminologyEntry`（onConflictDoUpdate 幂等）/`listTerminology`/`translateNarration`——源 Master 存在性 409 → LLM seam 翻译（词典注入 systemPrompt `src=>tgt`；**翻译与 TTS 发音共用同一词典数据**）→ 输出解析（有限修复剥围栏）→ 完整性（缺块 422）→ **数字 fail-closed**（逐块数字序列多重集不等 → 422 NUMBERS_CHANGED，整个翻译不落库不合成）→ **实体 fail-closed**（词典命中源词但译名 0 次 → 422 ENTITY_MISSING）→ **全量重合成**（新语言 → 新 cacheKey → 全新 TTS/对齐/时间戳）→ 作业落库（核对证据随行）。
  5. Mock LLM 增翻译模式（purpose='translation'）：确定性词典替换 + 数字逐字保留；`translation_numbers_dropped` 模式抹掉首块数字（验证 fail-closed）。**Mock 输出 ≠ 真实翻译**：真实翻译 Provider BLOCKED 凭据（同 P06-02 纪律，不冒充）。
  6. API/SDK：`PUT/GET .../terminology`、`POST/GET .../narration/translations`；`client.multilingual.{translate,translations,upsertTerminology,terminology}`。
