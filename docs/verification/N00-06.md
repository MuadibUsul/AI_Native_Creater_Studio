日期：2026-10-08。需求：V03-58、V03-59。状态：**VERIFIED**。依赖 N00-03、N00-04 均已 VERIFIED。

## 实现

- `scripts/verification/n00-06-browser-media.mjs` 对固定媒体的 SHA-256、字节数、流信息和完整解码做前置校验；环回 HTTP 服务支持 Range，并用 Playwright Chromium 验证真实视频/音频时间推进、解码尺寸、页面错误和截图。
- `scripts/verification/n00-06-project-media.mjs` 强制只连接精确隔离库且要求 `DATABASE_URL` 未设置。它启动真实 API、临时 Web 代理和本地签名对象存储，创建两个测试身份和工作区，走产品 Web 完成项目创建、签名上传、确认、项目内播放、跨租户 404、删除一个租户后另一租户仍存在，以及按精确名称和邮箱定向清理。
- 素材确认保留上传文件名；素材详情按当前版本 MIME 和短时签名 URL 显示原生视频/音频预览，过期 URL 不渲染。没有把永久存储键或 Provider URL 交给客户端。
- 浏览器和项目媒体证据分别写入忽略目录 `.artifacts/n00-06-browser-media/` 与 `.artifacts/n00-06-project-media/`。

## 证据边界

- 骨架的验收目标是证明真实浏览器、授权测试身份、存储 fixture、媒体探测、可见截图、故意失败以及租户安全清理均可执行；以上均已满足，所以 N00-06 关闭。
- 固定项目媒体是仓库合成 CFR MP4；N00-04 另有可追溯 CC0 的 Galaxy S9 VFR/方向素材并已 VERIFIED。跨浏览器、长视频 Range、弱网续播、代理转码、编辑时间线和最终成片由 N02/N03/N13 对应任务继续验证，不能由本任务结论外推。
- `test:e2e` 仍为显式 `[PLANNED]` 零断言；N00-06 的专项脚本是真实可失败验证，但尚未冒充完整产品 E2E 套件。
- 没有真实 Provider、费用或生产数据。不得对 `ancs_dev` 运行迁移、清理或写入测试。

Contracts、migration、API/SDK 不适用；domain 保留资产文件名，UI 提供安全的当前版本媒体预览，tests/docs 提供可重复的浏览器和租户证据。回滚可撤销预览和 metadata 写入逻辑，不能删除已有资产或用户项目。
