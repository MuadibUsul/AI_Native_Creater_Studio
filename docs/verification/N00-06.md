## 证据边界与尚未通过的任务验收

- 新脚本已覆盖授权项目的上传、签名存储和 Chrome 视频播放；它使用仓库合成 CFR MP4、Mock LLM、本地对象存储、临时环回服务与隔离数据库，没有验证外部 Provider、真实手机 VFR、跨浏览器兼容、代理转码、编辑时间线或最终成片。
- Chromium 时间推进与 FFmpeg 解码只证明所测 WebM/WAV 可解码、可启动播放；没有采集浏览器实际声卡输出，不证明声画同步、原音保留、最终 MP4 或实际用户素材可用。
- 新脚本用精确测试租户名与邮箱清理，验证 A 被删除时 B 仍存续；历史开发库误清后，所有写入测试必须显式使用独立 `ANCS_TEST_DATABASE_URL` 并清除 `DATABASE_URL`。不得对 `ancs_dev` 清理、迁移或运行写入测试。
- N00-04 尚缺手机原始 VFR 的来源与授权证据。Chrome 对小型 MP4 的签名下载端点可播放，但该端点仍使用下载响应语义；Safari、长视频 Range、不同编码与弱网续播尚未验证，属于后续媒体服务任务。真实 `test:e2e`、Provider smoke、GitHub CI、部署本次**未运行**；`test:e2e` 仍是 `[PLANNED]` 零断言。
