- **本次修复/发现的工程问题（诚实记录）**：
  1. **smoke 渲染必须经 React**：初版直接调用组件函数 → hooks 无 dispatcher（"Cannot read properties of null (reading 'useContext')"）——改为 `createElement(component, props)` 经 renderToStaticMarkup。
  2. **vm 跨 realm 错误**：子上下文抛出的 Error 不是宿主 `Error` 实例（instanceof 为 false）——消息经字符串化（带 "Error: " 前缀）；测试按 `toContain('boom')` 断言。
  3. **子进程必须可被 Node 直接运行**：`.tsx` 改 `.ts`（无 JSX 语法，Node 24 原生类型剥离）；`analysis.ts` 以 **`.ts` 扩展显式导入**（类型剥离下 Node 按实际文件解析）+ `allowImportingTsExtensions`。
  4. **静态分析的偏宽取舍**：URL 字面量（https）会命中 NET_MODULE——词法层宁可偏宽（误拒可人工复审，漏放即安全事故）；测试断言"任一防线拒绝即不放行"。
  5. `NODE_OPTIONS` 清空传入子进程（防宿主环境注入干扰沙箱资源参数）。
