- **本次修复/发现的工程问题（诚实记录）**：
  1. **Next 会重写 tsconfig jsx=preserve**，导致 vitest（Node 侧）解析 TSX 失败——最终方案：Next 保持 `preserve`，vitest web 项目用 **oxc `jsx: 'automatic'`**（Vite 8 已切 oxc；esbuild 选项被忽略并产生告警）——测试与构建同时稳定。
  2. **jsdom 的 File 未实现 `arrayBuffer`**：初看像产品缺陷，实为测试环境缺口——产品代码使用标准 Web API 不退回 FileReader；测试提供 `testFile()` 垫片（并把 file input 注入改为 fireEvent + defineProperty）。
  3. **上传动作由 form submit 改为显式按钮**：jsdom 下 submit 事件路径不可靠；显式 `type="button"` + onClick 更可测（真实浏览器行为不变）。
  4. **eslint 未忽略 Next 生成物**（.next/next-env.d.ts）导致 7k+ 误报——加入 ignores（生成物不参与 lint）。
  5. **SDK 直传 body 类型**：`Uint8Array<ArrayBufferLike>` 在 DOM BodyInit 下不被接受——改用 `ArrayBuffer`（node/浏览器双通）；SDK 契约不变。
  6. `next build` 期间 TypeScript 增量文件（.tsbuildinfo）与 .next 均为生成物，不提交。
