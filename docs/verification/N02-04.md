## 实现范围

- Contracts / Migration：新增 `MEDIA_INDEX`、索引状态/类别、源 PTS 条目、分页 DTO、Indexer seam；迁移 0066 新增 `media_index_runs` 与 `media_index_entries`，按 source AssetVersion + processor version 唯一复用。

## 边界与回滚

- 真实边界是本地用户 MP4、合成 CFR/黑场/静音样例、本机 ffmpeg、真实隔离数据库和本地签名存储；未宣称云对象存储、自然长片性能、OCR、人物/动作理解或第三方 Provider 已验证。
- 镜头边界使用 `scene > 0.3`，记录检测依据、置信度和 250ms 误差；质量标记只记录 blackdetect/silencedetect 实测区间，不将未检测到解释为质量通过。
- 单次最多 100 张 320px JPEG；波形按 10ms 采样并分 256 点分页。更深的统一 Media Index、阶段 DAG 和局部失效由 N02-10/11 扩展。
- 回滚可停用 `MEDIA_INDEX` handler/API 并删除迁移 0066 的两表与索引对象；源 AssetVersion、代理和 SceneGraph 不需修改。
