## 本次代码与契约

- 新增 `packages/contracts/src/common/media-time.ts`，导出 `Rational`、`FrameRate`、`MediaTime`、左闭右开 `MediaRange` 的 Zod 契约；ticks 使用规范化有符号十进制字符串，限定 signed int64，时基与帧率使用正、约分且不超过 int32 的分子/分母。
- 比较、重采样和 PTS↔序列线性范围边界映射均使用 `bigint` 整数/有理运算，不经浮点秒；边界要求明确传入 `floor`、`ceil`、`towardZero` 或 `nearest`（半值远离零）。末端可作为**边界**映射，内容范围仍为 `[start,end)`。目标范围两端时基不同时，先约分端点的实际秒值，再用分母最小公倍数选取可无损表达两端的输出时基；超出有理分量范围即失败，防止越过末端。变速曲线和倒放映射属于后续 N01-03。
- 提供帧索引、48 kHz 等音频样本索引换算，及旧整数 ms→`ticks=ms,timebase=1/1000`、旧整数 fps→`num=fps,den=1` 的只读兼容适配。旧 `common/time.ts` 注释改为历史 ms 契约；旧 SceneGraph、数据库和 API 字段没有被新精度悄悄覆盖。
- `packages/contracts/src/index.ts` 公开上述 schema 与纯函数；未新增第三方依赖。
