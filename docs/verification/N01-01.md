# N01-01 有理时基与源 PTS 原语：验证记录

日期：2026-10-08。状态：**VERIFIED**。依赖 N00-02、N00-04 均已 VERIFIED。

## 契约与行为

- `packages/contracts/src/common/media-time.ts` 导出 `Rational`、`FrameRate`、`MediaTime` 和左闭右开 `MediaRange` 的 Zod 契约。ticks 使用规范化有符号十进制字符串并限制为 signed int64；时基和帧率要求正数、约分且分子分母不超过 int32。
- 比较、重采样、帧/样本换算与源 PTS↔序列边界映射全部使用 `bigint` 有理运算，不经过浮点秒。舍入必须明确指定 `floor`、`ceil`、`towardZero` 或 `nearest`。
- 内容范围统一为 `[start,end)`；末端只允许作为边界映射。不同目标时基先约分实际秒值，再选择能无损表达两端的公共输出时基；超出安全范围直接失败。
- 支持 24/25/30/50/60、24000/1001、30000/1001、60000/1001 和 48 kHz 音频样本；支持负源 PTS、跨时基比较、精确帧对齐和 VFR PTS 间隔。
- 旧整数毫秒和整数 fps 只提供无损兼容映射。负时间、分数毫秒、超 Number 安全范围或 29.97 伪小数输入明确拒绝，不会静默覆盖旧字段。
