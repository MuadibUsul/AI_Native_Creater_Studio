- **验收条款对照**：
  1. **"计划未 Apply 不改数据库"** → 通过（结构性 + 测试）：`planAiEdit` 不写任何表；集成测试对计划生成前后的 revision/场景逐字段比对完全相等；Web 侧断言生成计划时编辑协议未被调用。

  3. **差异预览 / 成本影响 / Apply / 拒绝 / Undo** → 通过：before/after 逐项展示（before 来自现状，不确定值显式标注）；成本影响恒为 NONE 并展示；Apply 才提交；拒绝=清空无副作用；Apply 后可撤销（补偿事件）。
- **本次修复/发现的工程问题（诚实记录）**：
  1. **每个 operation 产生独立编辑事件**：一次 AI Edit 计划含多条操作时，撤销是**逐条**回退（第一次 undo 只回退最后一条）——集成测试初版误以为一次 undo 全部回退；已用"逐条撤销直至回到应用前状态"固化正确语义（这也是 History 的产品语义：逐事件）。
  2. **`ApiFailure` 字段名是 `httpStatus`**（非 `status`）——单测断言修正。
  3. **SDK 批量替换的连带损伤**：向 import 段追加 `directorPlanSchema` 时命中了实现体中的同名参数行——已修复并由 typecheck 捕获（教训：SDK 内同名符号多处出现，替换必须锚定上下文）。
  4. lint：`attempts` 冗余赋值与无意义 try/catch 被规则拦截——直接使用循环变量、去掉多余包装。
