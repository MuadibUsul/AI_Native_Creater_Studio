**N06-04 集成测试覆盖：**
1. **缓存命中**：同一依赖重复试改 → 第二次 `cached=true`、`dependencyKey`/`trialRevision`/`clipRanges` 与首次一致；缓存行数仍为 1；**同一操作集的不同候选复用同一缓存键**且 `proposalId` 被正确重标注。
2. **依赖失效**：片段换源（素材版本签名变化、工程 revision 不变）→ 新依赖键 → `cached=false` 重算，缓存行数变 2；旧键不再被引用。
3. **显式失效与采用清理**：`invalidateProposalTrials` 删除缓存行；重新试改重建；**采用后该候选缓存行被清理**。

> 注：SDK 默认给 `previewProposal` 传固定幂等键 `preview_<proposalId>`，HTTP 幂等缓存会先于服务端缓存返回同一响应。测试因此对每次预览使用不同的 HTTP 幂等键，专门验证**服务端局部试片缓存**。

- 无 Provider 依赖、无费用。
