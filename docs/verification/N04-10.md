**集成测试覆盖（N04-10 4 项）：**
1. `FOLLOW_OBJECT`：片段右移 2000ms 后，时间选择 `[4500,5500]` 重投影为 `[6500,7500]`；`remapHistory` 记录「时序重投影」；再次恢复 `changed=false` 且修订不变（**刷新幂等**）。
2. `FOLLOW_SOURCE`：片段修头 1000ms（源 `[1000,4000]` ↔ 序列 `[4000,7000]`）后，时间选择 `[5000,7000]` 重投影为 `[4000,6000]`。
3. 并发保护：`expectedRevision` 与当前不符 → **409 `SELECTION_CONCURRENT_UPDATE`**。
4. 嵌套失效：父序列缺失 → 恢复为 **`PARTIAL`** 且 `remapHistory` 写入「父序列缺失」（不静默当作有效）。

## 失败与剩余缺口

- 恢复结果尚无可视化（后续 UI 显示"选择已跟随/失效"）；真实浏览器刷新恢复证据待 N04-01/N04-08。
- `FOLLOW_SOURCE` 依赖基线区间；旧锚点无基线时不自动跟随（明确保持固定/`SEQUENCE_FIXED` 语义，不猜测）。
- 嵌套仅检测父序列存在性；父序列自身时序变化对嵌套内容的影响（需 N03-12 的映射/代理）未覆盖。
- 无 Provider 依赖、无费用。
