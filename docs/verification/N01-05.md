# N01-05｜增量迁移与旧项目兼容适配验证

日期：2026-10-08。状态：**VERIFIED**。依赖 N01-03、N01-04 已 VERIFIED。

## UI 交付卡

- **用户目标 / 角色 / 空间：** 已有项目的创作者在升级 Composition 模型后仍能看到相同 Scene、字幕、音频和历史版本；迁移中断不得损坏原项目。
- **入口 / 对象 / 范围：** 本任务是内部按项目启用的迁移与单写切换，不新增用户页面。对象为旧 SceneGraph、`scenes`、不可变 `project_versions` 以及对应 Composition 投影。
- **主流程 / 恢复：** 先启用项目迁移开关；按 BASE → SCENES → VERSIONS 分步提交；失败保存最后完成步骤；重跑用确定性 ID 继续；全部成功后一次性把写权威切换为 `COMPOSITION`。
- **权限 / 费用 / 锁定：** 每次查询携带 workspace/project；跨租户返回 404。迁移不调用 Provider、不创建 Job、不计费。切换后旧编辑入口以 409 拒绝，不能覆盖新字段。
- **设计覆盖：** UI 不适用。N01-09 才公开工程 API/SDK，N03/N04 才提供真实编辑入口；本任务没有用临时后台表单暴露内部迁移控制。
- **业务 / 测试：** 使用隔离 PostgreSQL 真实执行 0060、故障注入、恢复、不可变数据对照和跨租户检查；完整 Render/Golden 回归确认旧渲染路径仍可解码。

## 实现

- 新增迁移 0060：
  - `project_composition_migrations` 保存项目级 feature flag、状态、最后完成步骤、尝试次数、源/目标 SHA-256、错误摘要和 `LEGACY | COMPOSITION` 写权威。
  - `project_version_composition_projections` 对每个不可变 ProjectVersion 保存一份可独立验签的 v1.0 投影；源快照和投影各有递归键排序后的 SHA-256。
- 旧 Scene 投影为稳定 VisualObject；旧 caption 投影为带逐词时间的 CaptionSpan；旧 audio 投影为覆盖旧时间线的 AudioRegion，并保留音量、fade、ducking 和资产引用参数；版本投影始终嵌入原 SceneGraph 兼容视图。
- ID 由项目／版本命名空间和旧对象 ID 确定性生成。已提交步骤用 `onConflictDoNothing` 重放，物理中断不会复制对象。
- 回填只向新表写入；不更新或删除 `scenes`、`project_versions`。源数据在中断后发生变化时以 `LEGACY_SOURCE_CHANGED_DURING_MIGRATION` 拒绝继续，避免把两个源状态拼成一次迁移。
- `COMPOSITION` 切换只在全部实时投影和版本投影成功后执行。`processEdits` 与 `addScene` 共用的旧写入口在切换后返回 `LEGACY_WRITE_BLOCKED_AFTER_COMPOSITION_CUTOVER`。
- 切换不可逆；完成后禁止关闭迁移开关，以免形成双写或恢复旧权威的错觉。

## 分层、限制与回滚

- Contracts、migration、domain/service、旧写入口门控、tests、docs 已实现。
- API、SDK、UI 不适用：本任务的 feature flag 是内部迁移控制。N01-09 统一公开工程 API/SDK/事件，N03/N04 接入产品交互。
- 当前实时旧模型只持久化 Scene；旧 caption/audio 主要存在于版本快照，因此实时投影在旧图为空时保持为空，版本投影完整迁移其字幕和音频。
- `COMPOSITION` 是单向切换。回滚应先停止 Composition 写入，在尚未切换的项目上关闭 flag，再删除确定性投影和 0060 两表；已切换项目需先导出/反向迁移新对象，不能直接恢复旧写入口。原旧记录始终保留。
