## 验收路径覆盖

1. **连续三轮修改后早先认可的内容仍引用相同资产与参数**：采集"开场"片段的三轴指纹后，对**别的片段**连做三轮修改 → `checkConfirmedContent` 报 `UNCHANGED`、`intact=true`、`diffs=[]`。已测。
2. **意外移位阻止自动采用**：候选只对片段 A 做 `ripple_clip DELETE`，片段 B 会被**附带**左移；B 受保护且非本批显式目标 → 采用 409 `CONFIRMED_CONTENT_REGRESSION`（`violations` 指明 B），**工程 revision 与事件数不变**，候选保持 OPEN。已测。
3. **显式目标不算范围外**：候选显式改受保护片段 → 采用成功；核对报告如实给出该对象变化并标 `explicitTarget=true`、`outOfScope=[]`。已测。
4. **不支持的保护类型 fail-closed**：保护字幕对象 → 501 `CONTENT_PROTECTION_UNSUPPORTED_KIND`（本项仅支持 CLIP，见缺口）。已测。
5. **"其他别动"范围守卫**：未声明 → `SAFE`；声明且等长 → `SAFE`；声明且变短但有等长替代 → `EQUAL_LENGTH_PLAN_RECOMMENDED` + `requiresExplanation`（计划附 rationale 提示）；变化量不可确定（涟漪 DELETE / delete_clip）→ `EXPLAIN_DURATION_CHANGE` + `DURATION_CHANGE_UNKNOWN`。**已由规划器端到端验证（`range_edit_ripple`）。**

## 关键实现要点（易错）

- 保护门必须比对 **试改后状态**（试跑在同一事务内跑完、回滚前采集的三轴指纹），**不是当前已提交状态**——附带移位发生在试改之后，用已提交状态会永远检测不到（本项开发中先踩到，已修）。
- 采用路径**只在传了 `protectionIds` 时**才多跑一次试改核对；不传则零额外开销、行为与之前一致。
- 总时长守卫是**确定性估算**（由操作负载推导），**不是**跑一遍执行器；估算不出时必须 `exact=false` 并要求解释。

## 失败与剩余缺口（已知限制，不阻塞本项）

1. **保护范围仅 CLIP**（视频与音频片段；"声音"以音频片段承载，`parameters` 已计入 CONTENT 轴，"产品外观"= 片段的变换/裁切/不透明度参数，同样被覆盖）。**字幕/音频区域/视觉对象**暂不可保护——显式 501 fail-closed，不静默放过。
2. 总时长变化是**估算**（插入/涟漪收缝/删除三类语义）；其他操作按未变处理。若将来引入会改变总时长的原语，必须同步扩展 `estimateRangeEditDurationDeltaMs`，否则守卫会漏判。
3. 无 UI 呈现（保护记录的界面属后续交付面）。
4. 无 Provider 依赖、无费用。
