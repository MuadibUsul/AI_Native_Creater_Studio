# N03-05 验证｜可编辑变换与基础关键帧

**结论：** `VERIFIED`（2026-10-09）

**需求：** V03-17、V03-18、V03-68

**迁移：** **0077** `striped_firestar`：`sequence_clips` 增加 `parameters`（`jsonb`，可空；缺省即旧语义，无需回填）。

**UI 适用性：** 权威层原语 + 纯函数命中换算；画布上的选择框/手柄/关键帧编辑器属 N03-08 时间线界面交付。关联用户切片：点击选中对象后拖动/缩放/旋转/裁切/调透明度，**不重生成镜头**，并能在画布上正确命中。

## 实现证据

- **变换参数契约**（`packages/contracts/src/visual-transform.ts`，平台中立、纯函数）：
  - `visualTransformSchema`（`position` 归一化位移、`scale` 0.01–16、`rotationDeg` ±360、`anchor` 0..1）；
  - `visualCropSchema`（四边归一化 0..1，且**必须留出非空可见区域**）；
  - `visualParametersSchema`（`schemaVersion = visual-params/1.0` + transform/crop/opacity + `values` 组件自定义参数），`DEFAULT_VISUAL_PARAMETERS` 即旧语义；
  - `VISUAL_KEYFRAME_PATHS`（`transform.position.x/y`、`transform.scale.x/y`、`transform.rotationDeg`、`opacity`）；
  - `projectVisualPoint`／`invertVisualPoint`／`hitTestVisualObject`：裁切 → 缩放 → 旋转（绕锚点）→ 位移 的正/逆变换，**同一实现供预览与命中检验共用**。
- **契约层**：`clipSchema` 增加可选 `parameters`；新增规范原语 `set_clip_transform`／`set_clip_crop`／`set_clip_opacity`（`EDIT_OPERATION_TYPES` 35→38），v2 覆盖层的同名来源操作由 `PLANNED` 翻为 `NATIVE`（来源操作计数不变，仍 40）。
- **执行器**：三个分支只做**参数化修改**——`nextVisualParameters` 把局部变更合并进片段 `parameters`（保持其余参数与组件 `values` 不变），落 `SET_CLIP_TRANSFORM`／`SET_CLIP_CROP`／`SET_CLIP_OPACITY` 事件；不触碰 Scene、不产生 Provider 任务（"不重生成镜头"由测试断言 Scene 行数不变）；裁切再校验非空可见区（`CROP_AREA_EMPTY` 422，服务端第二道）；对象锁（STYLE 维度）经影响面门与 `assertObjectLockAllows` 两层拦截。
- **继承与回退**：`splitClipRow` 与 `duplicate_clip` 让派生片段**继承父片段参数**（切分后子片段保持同一变换）；undo/redo 逐条恢复参数（`SET_CLIP_*` 的逆操作从 `before` 快照取原参数）。
- **投影**：`toClip` 把 `parameters` 纳入 `projects.state`（缺省不带字段 = 旧语义），旧版迁移投影不受影响。
