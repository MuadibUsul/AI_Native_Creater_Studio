# N01-11｜Edit Operation v2 全清单与别名编译

日期：2026-10-09。状态：**VERIFIED**。依赖 N01-06、N01-10 已 VERIFIED。

## UI 交付卡

- **用户目标 / 角色 / 空间：** GUI、快捷键、Agent 和旧客户端表达同一编辑意图时，进入同一服务端校验、锁、revision、事务、事件和撤销链路。
- **入口 / 对象 / 范围：** 新增公共 Edit Operation v2 来源操作注册表与 domain compiler；实际写入仍只走现有 `processEdits` 权威执行器。
- **主流程 / 恢复：** 来源操作 → 注册表查找 → 输入 schema 校验 → 原生／别名／待实现裁决 → 别名编译为 canonical EditOperation → 现有事务执行器。补偿沿用 canonical EditEvent。
- **权限 / 费用 / 锁定：** 所有项声明 `project:write`、读写集、前后条件、成本类别、补偿和后端；生成 Region 明确要求 Provider 报价。现有锁与 revision 校验不会被 compiler 绕过。
- **设计覆盖：** UI 不适用。本任务交付 GUI／快捷键／Agent 后续共用的命令边界，没有新增页面或控件。
- **真实业务 / 证据：** 真实 PostgreSQL 验证别名编译后通过现有执行器修改 Clip 与 AudioRegion；关键帧批内按同一权威 Animation 状态编译；未知、非法和待实现操作 fail closed 且不落 EditEvent。

## 实现

- §13.5 的 33 个来源操作均有严格输入 schema、目标类型、读写集、前后条件、成本、补偿、后端、限制、测试 ID 与归属任务。
- 11 类现有能力标记 `COMPILED_ALIAS`：move／trim／slip／恒速，关键帧 add／update／remove，音频 gain／fade／pan／automation。
- 其余 22 类标记 `PLANNED`；Preview 三命令单列 `PREVIEW_COMMAND`，Region 生成单列 `ASYNC_COMMAND`。调用返回 501 和 owning task，不产生空成功。
- 恒速只声明当前 LINEAR／REVERSE 子集；曲线／定格归 N11-02。关键帧只声明 LINEAR／HOLD 子集；高级曲线归 N11-01。
- 关键帧别名按 workspace/project 加载正式 AnimationBinding，验证 target，支持一个批次内连续 add/update/remove，并编译为完整 `update_animation`。
- `processEditsV2` 不建立第二个写路径，只把 canonical operations 交给 `processEdits`。

## 限制与回滚

- `PLANNED` 是能力目录和明确失败合同，不计为对应编辑能力完成；各 owning task 完成时才能改为原生或别名。
- N01-11 不新增 API/SDK/UI；N04-11 和 N07-09 后续分别把 GUI/快捷键与 Agent 能力投影接入同一注册表。
- 无迁移。回滚删除 v2 注册表、compiler 与 wrapper 即可；现有 canonical 编辑协议和历史数据不变。
