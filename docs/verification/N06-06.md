## N06-06 验收路径覆盖

1. **revision 与任务绑定**：候选带 `generation`（工程内单调递增）+ 绑定 `baseProjectRevision`/操作哈希/锚点指纹/意图修订。
2. **新指令 supersede 旧提案**：创建候选时，同谱系（`intentRevisionId` 优先，否则 `selectionAnchorId`）内旧 OPEN 候选自动标 `SUPERSEDED` 并写入 `supersededByProposalId`/`supersededAt`。**无谱系（两者皆空）的候选互不取代**（已测）。
3. **先慢后快两任务逆序完成仍展示最新意图**：慢任务（旧代际）的产物**晚到** → 因候选已 SUPERSEDED 被**隔离**（`bound=false`，reason `SUPERSEDED`）；快任务（当前代际）产物 → 绑定（`bound=true`）。台账同时显示隔离行与理由。
4. **取消标记不丢已有结果**：`cancelProposal` 标 `CANCELLED` + `cancelledAt`，**不删除**试片缓存与已绑定产物（与 `discardProposal` 的清理语义相反，已测）；幂等（再次取消返回同一终态）。
5. **取消后回调不改变 acceptedRevision**：取消后提交产物 → 隔离（reason `CANCELLED`）；采用/试改 → 409（`PROPOSAL_CANCELLED`）；工程 revision 全程不变。
6. **外部晚到产物隔离而非自动绑定**：代际与候选不符 → `STALE_GENERATION` 隔离；已提交 → `ALREADY_BOUND`；非当前代际 → `NOT_CURRENT`；均写台账 `bound=false`，不触碰候选与工程。
7. **孤儿资产按保留策略清理**：`runRetentionSweep` 清理 `bound=false` 且超期的隔离行；**`bound=true` 的已接受结果保留**为候选证据（已测）。
