- **验收条款对照**：
  1. **"URL、粘贴文章、手写脚本、Sources 编辑"** → 通过：三种文本输入均产出统一 ContentDocument；Sources 元数据可编辑且**快照事实（内容/哈希）不可改**；媒体输入经 P02-04 资产链路（MUST 清单的第四项）。
  2. **"URL 异常有明确结果"** → 通过：INVALID_URL（形态/协议/超长）、UNREACHABLE（DNS/网络/非 2xx）。
  3. **"安全限制有明确结果"** → 通过：BLOCKED_TARGET（回环/私网/链路本地/元数据/单标签主机名/非允许端口；服务层前置守卫 + 抓取器逐跳复检）。
  4. **"空正文有明确结果"** → 通过：EMPTY_CONTENT（页面只有脚本/导航或解析后无块）、EMPTY_INPUT（粘贴/脚本为空白）。
  5. **"错误编码有明确结果"** → 通过：ENCODING_UNSUPPORTED（未知 charset 或替换字符占比过高），且**不会静默输出乱码**。

- **本次修复的工程问题（诚实记录）**：
  1. **块 ID 跨文档冲突（真实缺陷）**：以内容哈希作为主键导致"同一标题出现在两篇文档"时主键冲突（500）。修复：块 ID = `blk_<docShort>_<digest>`（文档内稳定、跨文档唯一），tables/figures 的 blockId 引用同步。
  2. **URL 守卫的位置**：初版把校验完全托付给抓取器 → 脚本化/替代适配器会绕过安全限制；改为**服务层前置守卫 + 适配器逐跳复检**（双保险）。
  3. **单标签主机名**：`https:///path` 被 WHATWG 解析为 host=`path`（而非空）——补"单标签主机名拒绝"规则，同时挡住 `http://metadata/` 形态。
  4. **unit 项目的 domain 排除**：`packages/domain/**` 整体被排除会使纯函数单测**永不执行**（假通过风险）——改为仅排除 `*.integration.test.ts`。
