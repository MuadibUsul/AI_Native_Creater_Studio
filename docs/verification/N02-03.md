## 实现范围

- Contracts：增加 `MEDIA_PROXY` Job、标准视频／音频 profile、逐流 `PTS_AFFINE` 映射、播放状态 DTO、双向 PTS 换算与 `SourceMediaTranscoder` seam。
- Migration：不适用。复用迁移 0063 的 `media_derivatives` 和现有 Asset/AssetVersion；最新迁移仍为 0065。
- Domain：媒体探测成功后在同一事务创建确定性代理派生、隐藏输出资产和 SYSTEM Job；源 checksum 固定校验。代理完成、失败、缺失重建均不修改源版本。
- Worker/Storage：隔离 ffmpeg/ffprobe 生成 H.264/AAC 720p 视频代理或 48 kHz 立体声音频代理；输出通过 `persistFile` 流式原子写回对象存储。
- API/SDK：新增 `playbackUrl` 与 `rebuildProxy`；短期播放 URL 优先代理，必要时明确回退可直接预览的原件。所有查询携带 workspace scope。
- UI：素材详情新增编辑代理状态、PTS 映射、原件回退、失败／缺失重建；内部派生资产不会出现在素材列表。

## 边界、限制与回滚

- 真实边界是本地 MP4、合成 VFR／5.1 样例、本机 FFmpeg 6.1.1、真实数据库和 LocalSignedStorage；未使用 S3/R2，也未宣称全部专业格式、HDR、Safari/macOS 或长片性能已验证。
- 映射按源／代理 stream time base 与起始 PTS 做整数换算，不读取平均 fps。当前 profile 保留源旋转、色彩、声道布局和容器事实于派生元数据；正式输出仍必须回链已审核原件。
- 视频代理上限 1280×720、H.264 yuv420p；音频 conform 为 AAC 48 kHz 立体声。多轨保留、HDR 色彩转换和母版格式属于后续专业任务。
- 生产云存储 provider 需要实现 `materializeObject` 与 `persistFile`；worker 主机需要可控 ffmpeg/ffprobe。
- 回滚可停用 `MEDIA_PROXY` handler 和两个新 API，并删除代理对象／隐藏派生资产；源 AssetVersion 与 checksum 不需要修改或删除。
