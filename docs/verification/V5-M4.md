## M4-2a RenderPlan IR 由内核编译

### 交付

| 项 | 落点 |
|---|---|
| RenderPlan 契约（`render-plan/1.0`，全部 `MediaTime`，层序自下而上，需求词表新增 `KEYFRAME_ANIMATION`/`TIME_REMAP`/`NESTED_SEQUENCE`） | `packages/contracts/src/render-plan.ts`、`playback.ts` |
| 纯编译器 `compileRenderPlan`、后端裁决 `assertRenderPlanSupported` | `packages/kernel/src/render/compile.ts` |
| 内核纯 SHA-256 + 规范 JSON（`planHash`，不导入 `node:*`） | `packages/kernel/src/render/hash.ts` |
| 消费者投影：播放快照、服务端合成计划（回带 `planHash`，精确 BigInt 排序） | `packages/kernel/src/render/consumers.ts` |
| 领域层只加载 + 调内核：`loadRenderPlanInput`、`compileSequenceRenderPlan`、`buildPlaybackSnapshot` | `packages/domain/src/playback.ts` |

### 修复的缺陷（各有回归用例）

| 缺陷 | 回归 |
|---|---|
| `insert_clip` 带出的关联音频片段从不进入快照（预览/合成计划静默无声） | 集成：`playback-snapshot.integration.test.ts`「V5-M4：快照来自内核 RenderPlan」——旧投影音频段为空，断言失败 |
| 绑定片段的音频区域把片段局部时间当源区间 | 内核：「CLIP_LOCAL 区域的 sourceRange 是源时钟」 |
| 合成计划 `Number(ticks)` 排序在 >2^53 ticks 时失序 | 内核：「服务端合成计划按精确 BigInt ticks 排序」；变异验证：换回 `Number` 排序后该用例失败 |
| 关键帧/变速/嵌套序列被静默忽略 | 内核：需求推导 + 后端裁决 501（列出全部缺失项） |
