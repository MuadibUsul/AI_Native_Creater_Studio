## 关键断言

- 相同素材版本的 `SHOT_BOUNDARY`、`TRANSCRIPT_WORD/SEGMENT`、`SPEAKER_SEGMENT` 和 `USER_MARKER` 可用同一源时间范围查询。
- 能力矩阵固定包含 17 个互不重复类别；未运行是 `NOT_ANALYZED`，运行成功但无记录是 `EMPTY`，处理失败是 `FAILED`，输入不支持是 `UNSUPPORTED`。
- legacy FFmpeg 记录保留测量依据和真实 `video:n/audio:n` stream；转写保留 Provider、模型、版本和推断依据；人工标签标为 `USER_SUPPLIED`。
- 工作区过滤同时存在于 API 授权和 domain 查询；其他工作区无法枚举 asset 或记录。
