## 边界、限制与回滚

- 真实边界为本地 MP4、合成 VFR／旋转／5.1 样例、本机 FFmpeg 6.1.1、真实数据库和本地对象存储；未使用 S3/R2，也没有把有限样例描述为全部容器、编码、HDR、Safari 或 macOS 的生产支持。
- `AVAILABLE / PROXY_REQUIRED / TRANSCODE_REQUIRED / UNAVAILABLE / UNKNOWN` 是当前 Chrome 与 worker 基线的显式能力事实。N02-02 不生成代理；N02-03 承接代理文件和源时间映射。
- 探测失败不会改变或删除原件；下载保持可用。生产云存储 provider 需要实现同一 `materializeObject` 契约。
- 子进程超时 5 分钟，输出上限 8 MiB；用户响应不包含本地路径、存储键或原始工具输出。可用 `ANCS_FFPROBE_PATH`、`ANCS_FFMPEG_PATH` 配置受控二进制路径。
- 回滚可移除两个 0065 列和 `MEDIA_PROBE` handler，并恢复音视频上传后直接 READY；已有原件对象、AssetVersion 和 checksum 不需要删除。
