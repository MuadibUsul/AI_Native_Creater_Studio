- **验收条款对照**：
  1. **"将旁白语义、身份、语气和时长目标转为供应商无关 SpeechPlan"** → 通过：语义 → 角色（§94 默认规则）；身份 → voiceIdentityId/version（版本化引用）；语气 → toneInstruction/styleInstruction（供应商无关文本）+ 语速/能量；时长目标 → targetDurationMs 对照与偏差告警。
  2. **"不支持的风格参数得到可解释降级"** → 通过：语速/能量越界**钳制 + requested→applied 记录**（段级 degradations + 计划级 warnings，单测断言）；无可用 TTS Provider → STYLE_SUPPORT_UNVERIFIED 明确警示（不冒充可合成；风格参数支持情况待 P06 真实能力映射）。
  3. **"私有参数不泄漏到 Graph"** → 通过：SpeechPlan 契约不含任何 Provider 字段；集成测试在身份资产中写入真实形态的 provider/providerVoiceId（`mock-voice-provider` / `vo_secret_leak_check_9f8e7d`）后断言**整个计划序列化字符串**不含它们；Scene 侧（P04-05）也不携带 Provider 请求字段（providerRequirement 只表达能力）。
- **本次修复/发现的工程问题（诚实记录）**：
  1. **浮点噪声**：`0.6 + (-0.05) = 0.549999…` 导致计划值与断言/上游比较不稳——语速/能量统一 4 位小数收敛（计划值不需要更高精度）。
  2. **角色判定盲区**：初版只按语义类型判 NUMBER，导致"旁白含关键数字但语义为 PRICE_SERIES"的段落被漏判；改为**含数字文本（确定性抽取）即 NUMBER**，并明确结构角色优先序（末段含数字仍为 CONCLUSION）。
  3. **发音词典测试的语义修正**：词典命中基于**旁白文本**（而非原文）——初版测试用原文词导致未命中；这也是真实语义（词典作用于"实际要念的文本"）。
  4. 首段 HOOK 优先于 QUOTE/NUMBER（§94 "Hook：更高能量、更快进入重点"），已在角色优先序中显式固定并测试。
- **remainingRisks**：
