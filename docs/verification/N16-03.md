## 实现和边界

- UI 继续使用 `--ui-font-family` 的系统回退栈：`-apple-system`、`BlinkMacSystemFont`、`Segoe UI`、`PingFang SC`、`Hiragino Sans GB`、`Microsoft YaHei`、`Noto Sans CJK SC`、`sans-serif`。Web 源码无字体文件和 `@font-face`；浏览器加载设计系统页时无 font 请求。这里引用设备已有字体，不分发 Apple 字体。
- 设计系统页的页面标题、区域标题、正文和辅助标签示例按 28/36、18/26、16/24、12/18 px 对齐，使用 `rem`/语义字号变量。主要 `.btn`、`.textbtn`、`.navitem`、`.field` 采用 14/22 px。中文 UI 标题不再使用负字距。
- 将 `tabular-nums` 限定到徽标、键盘提示、表格、金额指标、播放器/时间轴时间显示和示例，不给 `body` 全局设置，避免改变作品画面内的文字。技术 ID 单独使用系统等宽字体栈。设计系统页加入中英混排、长文件名、金额/负号/小数、时码和版本号样例；完整文件名仍在可见文本和 `title` 中。
- 默认 QuietIcon 为 20×20 px、统一 1.6 stroke；已有小图标局部规则仍按其用途生效。41 个图标路径逐字等于用户提供的 Quiet Frame 原型包 `index.html` 内的静态路径，无图标库依赖。原始 ZIP 的 SHA-256 为 `a04a074c62f03dcb09f9aa94aa22f2861740a808e9872312501dd8871cb2ed4a`，见 [参考包盘点](../quiet-frame-rebuild/REFERENCE_INVENTORY.md)。包内未找到图标的明确商业使用/分发许可声明，因此**来源可追溯不等于许可已核验**。
- 作品预览与媒体内容仍使用其原有排版：浏览器中 `/welcome` 的 `.viewer h2` 保持负字距，数字变体为 `normal`，画面滤镜为 `none`。这只是公开设计示意的样式隔离检查，不能代表真实用户作品全链路。
- 对 320 CSS px 的真实浏览器缺陷作定点修复：首页两个 CTA 原先左右越界 4px，且移动端隐藏侧栏后 mock 作品仍被压入 40px 网格列；设计页色块使文档横向宽度达到 342px，圆角示例也缺少换行。现在首页作品预览占满剩余单列、CTA 可换行，设计色块改为两列并允许内容折行，圆角示例按容器换行。未改作品预览内部排版规则。
