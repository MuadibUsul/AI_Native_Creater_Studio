     ③ 支持视图**只含非私密元数据**（计数/状态/用量），不返回项目内容/素材/Prompt/旁白（测试断言无 prompt 字样）。
  3. **"恶意文件扫描"**（§43.3）→ 上传端点写入前扫描；检出**拒绝落盘**（422 + findings）+ 审计；

- **本次修复/发现的工程问题（诚实记录）**：
  1. **扫描必须先于落盘**：上传端点的扫描插入在 `writeObject` 之前——检出时对象**从未写入**（测试以存储目录全量
     核查断言，而非仅响应码；早期写法用"同 token 下载"验证会误判为 403 用途不符）。
  2. **drizzle `sql`` 相关子查询陷阱**：在 `sql` 模板中插入列对象会渲染**未限定列名**——子查询内 `"id"` 解析为
     子查询自身表的列（`workspace_members.user_id = workspace_members.id` 恒 false → 计数恒 0）。修正为显式
     表名限定（`wm.user_id = "user".id`）并注释原因；该陷阱由集成测试（参与数断言）暴露。
  3. **测试夹具 PNG 尺寸**：简化 PNG 头（宽高为 0）会被资产探测的尺寸校验拒绝（500）——夹具修正为完整宽高字段；
     记录：尺寸非法时应为 4xx 而非 500（既有行为，未在本任务扩大改动，留作小额改进）。
