## 验收路径覆盖

1. **无 WebCodecs/WebGPU 仍能看并剪受支持 proxy**：环境为"仅 HTMLMediaElement"、proxy READY → `playable=true`、`mode=HTML_MEDIA_ELEMENT`、**精度如实**为 `KEYFRAME_APPROXIMATE` 且给出 `NOT_FRAME_ACCURATE`/`NO_WEB_CODECS` 限制。已测。
2. **回退达不到逐帧时不得虚报 frame-accurate**：`precision` 只在**实际具备 WebCodecs** 时才可能为 `FRAME_ACCURATE`；调用方 `requireFrameAccurate: true` 而达不到 → **`playable=false`**（明确不可播，而不是悄悄降级后照播）。已测。
3. **过期 URL 刷新不重置选区**：`applyUrlRefresh` 只替换 URL 并推进 `generation`；`clock` 与 `selection` **逐字段不变**（测试对两者做深度相等断言）；只刷新临近过期的分段，未列出的分段 URL 原样保留。已测。
4. **冷／热缓存可分别测首帧**：`planSegmentFetch` 返回 `cacheHit`（当前段是否命中）与"当前段 + 有界预取"的待取清单；预取窗口可调且为 0 时只取当前段。**实测首帧耗时**属 N03-16。已测（策略层）。
5. **缓存有界**：条目数与字节**双上限**，超限按 LRU 淘汰；时钟落在所有分段之外时**不取任何段**（不乱猜）。已测。
6. **proxy 未就绪/失败不假装能播**：`PROCESSING` → `playable=false` + `PROXY_NOT_READY`；`FAILED` → 不可播；`NOT_REQUIRED`（原生素材）→ 可播。已测。
