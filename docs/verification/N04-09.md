## 实现证据

- **唯一选择结构**：`SelectionAnchor` 是 AttentionSnapshot 的选择子结构（不新增第二份权威选择状态）：几何（点/线/矩形/多边形/笔刷 × 用途）× 时间（POINT｜RANGES 半开区间，有理时基）× 轨道（ALL｜TRACKS）× 属性 × 区域模式 × 时间绑定策略 + 目标顺序引用与绑定版本 + 解析状态/证据/重映射历史/指纹输入。
- **持久化**（`packages/db/src/schema/selection.ts` + 迁移 0079）：同行身份 `(workspace, project, anchorId, revision)` 的**追加式修订日志**——同一锚点每次保存产生新 revision，历史可查；不写 `edit_events`、不推进工程 revision（**选择动作永不改工程**）。`fingerprint = sha256(selectionFingerprintInput(anchor))`。
- **旧格式兼容**（`selectionAnchorFromLegacySelection`）：分镜（SCENE）／片段（CLIP）／字幕（CAPTION）／素材范围（MEDIA_RANGE）／像素区域（PIXEL_REGION）五种旧 inline 选择**解析一次**成规范锚点；毫秒入口转 1/1000 有理时基（**新请求不丢有理时基**）；字幕场景携带 `utteranceSequenceTime`（**指代使用对应发话时间**，不是解析时刻）。
- **服务端校验**：越权（同工作区其他项目）永远 422；目标已消失只允许以非 `RESOLVED` 状态持久化（供重映射记录失效，而不是假装仍有效）；`assertNotFrameHashIdentity` 拒绝把 `framehash_*` 之类当目标身份（**帧哈希不能作为对象身份或授权**）；跨租户读取 404。
- **重映射**（`remapSelectionAnchor`，N04-10 的第一块）：目标消失 → `FAILED`／部分消失 → `PARTIAL`；同一源版本被多个位置引用 → `AMBIGUOUS` 并附候选证据（**不随机选一个**）；片段换源导致锚点记录的版本过期 → `STALE`；每次重映射写入 `remapHistory`（含原因与缺失/过期目标）。
- **API／SDK**：`POST/GET/POST .../selection-anchors[/:anchorId[/remap]]`，SDK 三个方法（`saveSelectionAnchor`／`selectionAnchor`／`remapSelectionAnchor`）。
