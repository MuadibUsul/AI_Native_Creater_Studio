  3. domain `publications.ts`：`requestPublication`——版本归属 404 → **批准闸门**（输出资产必须属于该版本的某个 Render【OUTPUT_ASSET_UNKNOWN 422】；最新 render_approval 必须 APPROVED 且 manifestHashAtApproval === render.manifestHash 且版本一致【漂移 → NOT_APPROVED 409——同 P07-06 导出守卫语义】）→ Provider 注册（未注册 501）+ 能力分级（capabilities 不含 DIRECT_PUBLISH → CAPABILITY_MISSING 422）→ **幂等落库**（onConflictDoNothing；冲突 → 返回既有行 deduped=true，不重发、不改写）→ Provider validate（拒绝 → FAILED + 问题逐条）→ publish（异常 → FAILED + lastError，**不自动重发**）→ PUBLISHED 回填（经 getStatus 补全远端引用）；`listProjectPublications`/`getPublication`（状态查询）；`reconcilePublication`——**以 Provider getStatus 为准回填**（结果未知先查询；绝不重发）。
  4. `MockDistributionProvider`（P1 tier；确定性：remoteId 由幂等键派生——同键同远端可对账；fetchAnalytics 空口径不写零）；`DomainDeps.distributionProviders` 注入；server 默认装配 Mock（真实平台 BLOCKED OAuth 凭据——**不冒充**，P13-02 YouTube）。
  5. API `POST/GET .../publications` + `GET :id` + `POST :id/reconcile`；SDK `client.publications.{request,list,get,reconcile}`。
