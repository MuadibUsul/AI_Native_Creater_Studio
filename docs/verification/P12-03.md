- **implementationSummary**：
  1. 契约：`textUnitSchema`（kind ∈ THREAD_POST/SHORT_POST/PLATFORM_COPY/NEWSLETTER_SECTION；prefix 不计入引文重建；`quotes`（逐字引文 + claim/source 引用））+ `textSetPayloadSchema`（topic/coverage/**unavailableFormats 显式列出**）+ `TEXT_VALIDATION_CODES`（10 码）+ `TEXT_SET` 并入产物载荷判别名联合。
  2. Recipe 数据化（**平台长度限制不硬编码**）：`channelRequirementsSchema` 增 `postMaxChars/threadMaxPosts/threadPostMaxChars/newsletterMaxChars`；新增三个文字渠道种子（TEXT_THREAD ≤12 条 × ≤280 字符；TEXT_POST ≤220 字符；NEWSLETTER ≤6000 字符——标注为**平台保守默认值**，可经版本化升级覆盖）。

  4. 官方 Text Pack（`ancs.pack.text@1.0.0`）：**generate**——Thread 逐字装条（前缀 `[i/N] `；条数上限用尽 → coverage 披露）/短文（首句）/平台文案（标题作前缀 + 首句）/Newsletter 逐 Atom 分节；**单句超限 → 该形态列入 unavailableFormats 并说明"不改文字、不截断"**；**validate**——引文重建正文（不一致 = error，即"引用/事实不丢失"的机器检查）、无来源引文 = error、逐渠道长度上限（未定义 → LIMIT_UNVERIFIED warning）、Thread 条数、Newsletter 总字数、单元顺序、逐单元来源链与单主题、节选披露。
  5. **并发种子竞态修复（CI 事故闭环）**：P12-01 的 CI 失败（`pack 运行时` 500 / `duplicate key ... channel_recipes_key_version_uq`）根因 = 种子播种"读后写"在**多测试文件并行**下的既有竞态（P12-01 起 analyze 每次调用都会 ensure recipes，暴露面扩大）。修复：`ensureDefaultChannelRecipes`（含版本化升级路径）与 `installPack` 改为 `onConflictDoNothing().returning()` + 冲突后重读判定（幂等语义不变）；并在**清空 channel_recipes/pack_installations 后的并行 6 文件**下复现验证（18/18 通过、种子恰 6 渠道各 1 版本）。
