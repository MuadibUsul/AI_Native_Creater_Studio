  1. 契约 `pack-artifacts.ts`：`SOCIAL_SQUARE_FRAME`（1080×1080/1:1）与 `SOCIAL_PORTRAIT_FRAME`（1080×1350/4:5）+ `SOCIAL_TEXT_BUDGET`（封面 60 字/正文页 180 字——长文本拆页的量化口径）+ `socialVisualPageSchema`（role ∈ COVER/POINT/CHART/INFOGRAPHIC/SOURCE；platformKey/format/textChars/dataSource/attribution/provenance/**continuationOf 续页衔接**）+ `socialVisualSetPayloadSchema`（topic/coverage（含 textTruncatedPages 披露）/pages）+ `artifactPayloadSchema` **判别名联合**（9:16 派生 Graph | 图文集）+ `SOCIAL_VALIDATION_CODES`（11 码）。

  3. 受限上下文增 `sources`（来源 id/标题/发布者元数据，仅 read_content_core；署名数据面）。
  4. 官方 Social Visual Pack（`official-social-pack.ts`，`ancs.pack.social-visual@1.0.0`，defaultChannelKey CAROUSEL）：**generate**——1:1 封面 + 4:5 竖版封面 → 数字 Atom 的 CHART 页（BIG_NUMBER，数值逐字取自 Atom payload，`dataSource: ATOM_PAYLOAD`）→ 主 Atom 文本按 180 字预算**拆页**（续页 `continuationOf` 显式衔接；页数上限用尽 → coverage 披露）→ 信息图（KPI_GRID，1:1）→ 来源页（署名文本由来源元数据生成，无元数据则明示"未收录"）。**validate**——平台尺寸逐页核对（1:1/4:5 帧一致）/页序（index 连续、首页 COVER、末页 SOURCE）/页数 vs Recipe 窗口（warning；窗口未定义 → PAGE_COUNT_UNVERIFIED）/来源页署名必填/图表数值可追溯（图表组件必须有 in-topic dataSource；无图表页 → warning）/文字预算（超 = error 拆页）/逐页来源链与单主题。
  5. 官方 Pack 注册：`buildServer` 默认插件列表 = Shorts + Social Visual；`PackPlugin.validate` 类型收窄为载荷联合（kind 不匹配 → PAYLOAD_KIND_MISMATCH 明确报错）。
