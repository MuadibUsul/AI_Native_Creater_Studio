## 真实发现（接入事实，非结论猜测）

1. **中文输出为繁体**（「夢想／未来」混排）：`nova-2` 的 `zh-CN` 结果按繁体字给出。需在后续决定是**加简体归一化**还是保持原样——注意 N03-07 的字幕是**以词条为权威**重建文本，因此归一化应作用在**词条**上，不能只改整句。
2. **逐词时间戳可用**：满足 N05-02 中 `WORD_EXACT` 精度的前提（此前只有协议与夹具）。
3. **耗时约 0.17× 实时**（20 秒音频 3.4 秒），**批量**路径可用；**流式**延迟仍未测。
4. 该素材是 **HEVC**，浏览器无法直接播放——再次印证 §20.6 **E17**「必须走标准 proxy」；ASR 侧不受影响（服务端解码）。
