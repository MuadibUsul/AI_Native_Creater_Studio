## 验收路径覆盖

1. **"回到上一版得到实际资产而非重新生成"**：对照载荷对每个差异对象回带**双方实际的 `assetVersionId`**（`beforeAssetVersionId`/`afterAssetVersionId`）与 `assetVersionIds` 汇总，证明对照引用的是真资产而非重新生成的近似。已测（同一素材版本 id 出现在前后两侧）。
2. **"相同锚点对照不会错位"**：当两侧片段集合/时长不同时，按**内容锚点**（素材版本 + 嵌套序列 + 源区间）对齐；clip id 不同但同源的对象计入 `anchorMatchedCount` 并标 `alignedBy='CONTENT_ANCHOR'`；无法唯一对齐的锚点如实进 `unmatchedAnchors`（不假装对齐）。片段被删除 → `REMOVED` 且 `afterAssetVersionId=null`；涟漪造成的位移 → `POSITION`。已测。
3. **"恢复音轨和关键帧都准确"**：本项**未新增**恢复逻辑——版本恢复沿用 N01-08 的**补偿事件**（`undo`/`redo` 与 `restore_project_version`，历史不改写、按事件逐条反演），该能力已 VERIFIED。对照提供的是"改前/改后到底差在哪"的可核对载荷。
4. **对照不改工程**：三项用例均断言对照后工程 revision 不变。
