## 先看什么

打开 `index.html` 即可浏览 13 个页面。它是独立 HTML，不依赖 npm、CDN、在线字体或后端服务。浏览器禁止直接运行本地 HTML 时，可在本目录运行 `python -m http.server 8000`，然后访问 `http://localhost:8000`。

推荐体验路径：**创作台 → 新建作品 → 脚本 → 导演工作台 → 成片审核 → 交付**。左下角“帮助与快捷键”中可打开产品首页与设计系统。`Ctrl / ⌘ + K` 可搜索全部页面，`Esc` 关闭弹窗或抽屉。

`ANCS_Quiet_Frame_Overview.png` 是六个核心页面的缩略总览。`screens/` 中是 **18 张高清截图**：13 个主页面、AI 修改抽屉、3 个移动端页面以及深色创作台。桌面截图宽 2400 像素；移动截图宽 780 像素。总览图使用视口裁切，完整截图保存在 `screens/`。

## 原型与生产能力的边界

全部项目、脚本、图片、数据曲线、声音选项、用量示例和版本信息均为演示内容。原型不读取任何真实账户数据，也不调用任何 API；运行不需要 GitHub 连接。URL 输入仅记录地址，导入 `.txt/.md` 仅读取本地文件；不会真实抓取文章。后续脚本仍为预置示例，不会把示例假称为生成结果。

图表与几何封面是本原型自制的展示素材，不是财经事实证据。视频界面是静帧，没有伪造已生成 MP4；可下载的样例是明确命名的 TXT 交付说明。浏览器语音试听若可用，仅使用系统语音，不代表供应商或克隆音色质量。

部分交互改变内存中的演示状态；原型尝试在当前浏览器保存输入、作品名、开场文本、主题和演示批准状态。不要在原型中填写敏感资料。“帮助与快捷键 → 清除演示数据”可清除本原型的保存项。服务配置页面**不提供真实 API Key 输入框**。

未修改、提交、推送或部署原 GitHub 仓库。移动稿是响应式 Web 方案，不代表 P15 原生桌面/手机阶段已经开工；扩展目录也不代表 Marketplace 已实现或开放。
