# ANCS 界面改版 2026-10：参照 Google Stitch 的"画布"设计语言

> 背景：项目所有者要求"参照 https://stitch.withgoogle.com/ 的交互方式继续设计项目，界面风格要趋于一致，目前的界面太丑了"。
> 裁决：`docs/decisions/0019-stitch-canvas-design-language.md`（放开 v0.4 Monochrome 的部分禁令，范围受控）。
> 权威 token：`docs/V04/ANCS_v0.4_Design_Tokens.json`（名称改为 "ANCS Canvas"）↔ 运行时 `apps/web/src/app/ui-tokens.css`，由 `ui-tokens.test.tsx` 逐值比对。
> 证据：`docs/verification/artifacts/ui-stitch/`（各流程的真实浏览器截图、跨引擎截图、全站图库）。

## 1. 研究：Stitch 的交互与视觉（真实浏览器测得）

方法：在云端容器里用真实 Chromium（1440×900 与 390×844，深浅两种偏好）打开 stitch.withgoogle.com，页面内容在 iframe 里，逐个元素读取**计算后的样式**；编辑器需要 Google 登录，未进入，编辑器内的组件形态取自公开的产品介绍文章与配图（[ITdaily 2026-03-19](https://itdaily.com/news/cloud/google-introduces-vibe-design-updates-stitch/)、[Design Compass 2026-03-19](https://designcompass.org/en/2026/03/19/google-stitch-major-update/)、[Abduzeedo](https://abduzeedo.com/vibe-design-google-stitch)）。第三方截图只留在本地临时目录用于分析，不进仓库。

| 部件 | 测得值 / 观察 |
|---|---|
| 底色 | 近黑（宿主 `#191A1F`），满屏淡点阵；只有一团紫—蓝—青的模糊光晕在主输入框背后 |
| 主标题 | Google Sans Display 96/96，字重 400，字距 −2.4px；副标题 24/32 |
| 主输入框 | 宽约 852，圆角 28，内边距 24，背景 `rgba(22,23,24,.5)` + `backdrop-filter: blur(40px)`，1px 边 `rgba(218,220,224,.15)`；正文 24/32 |
| 输入框里的工具 | 左下 "+"（48×48 圆）、App / Web 分段（容器圆角 32、内边距 4；按钮高 40、圆角 32、14px/500，选中 `#F1F3F4`，未选 `#BDC1C6`）；右下模型胶囊（高 48，`rgba(39,41,42,.576)` + 模糊）、麦克风、圆形发送 |
| 建议 | 输入框下方一排胶囊（高 32，13px/500，玻璃底 + 细边），点了只填进输入框 |
| 主按钮 | 浅色胶囊（`#F1F3F4` 底、`#202124` 字，14/500，高 40，左右 24） |
| 编辑器（文章配图） | 左侧与 AI 的对话栏 + 右侧无限画布；画布左缘一条浮动竖向工具条（+ / 指针 / 手 / 调色板 / 文件夹）；右上浮动 "Preview \| Edit" 胶囊；AI 工作中的卡片（•• + "Your vision…" + "✓ Built today"）；语音胶囊（静音 / 声音选择 / 框选 / 停止），在听时外沿发光 |

提炼出的规律（本项目照此设计，不复制其资产）：

1. **AI 是主角**：首页就是一个大输入框；编辑器里对话栏常驻左侧，所有改动从一句话开始。
2. **画布是底**：内容浮在点阵画布上，控件是浮起的胶囊 / 圆角面板，没有"墙"（满屏边框、分栏线）。
3. **一个输入框装下起点**：起点、附件、模型、语音、发送都在输入框的页脚，不散落在页面各处。
4. **克制的颜色**：中性灰为主，彩色只用来标识 AI（光晕、四角星、在听时的光边）。
5. **大圆角、胶囊、圆按钮**：按钮一律胶囊或正圆，面板 20–28 圆角。

## 3. 设计系统 v2（ANCS Canvas）

### 3.1 颜色（主题 token，全部指定色对通过对比度检查）

| Token | 浅色 | 深色 | 说明 |
|---|---|---|---|
| `ui.bg.canvas` | `#F8F9FA` | `#0E0E10` | 画布底（叠点阵） |
| `ui.bg.subtle` | `#F1F3F4` | `#151517` | 面板里的次级底（输入框、卡片缩略区） |
| `ui.bg.elevated` | `#FFFFFF` | `#1E1F22` | 浮起的面板与卡片 |
| `ui.bg.hover` | `#E8EAED` | `#2A2B2F` | |
| `ui.fg.primary / secondary / muted` | `#1F1F1F / #444746 / #5F6368` | `#F1F3F4 / #BDC1C6 / #9AA0A6` | 最低：muted 对 selection 浅 4.72、深 4.93（要求 4.5） |
| `ui.border.subtle / control` | `#E3E3E3 / #747775` | `#2D2E31 / #80868B` | 控件边界对各底 ≥ 3.53（要求 3） |
| `ui.action.primary.bg / fg / hover` | `#1F1F1F / #FFFFFF / #3C4043` | `#F1F3F4 / #202124 / #FFFFFF` | 主按钮：浅色主题深胶囊，深色主题浅胶囊（同 Stitch） |
| `ui.selection.bg` | `#E3E3E6` | `#303134` | 选中、开启、用户消息气泡 |
| `ui.ai.blue / violet / teal` | `#1A73E8 / #7C4DFF / #00897B` | `#7CACF8 / #A78BFA / #5ED3E0` | **只用于 AI 身份**（见 3.3） |

非主题 token（随主题重写，声明在 `body` 上以便按当前主题计算）：`--ui-tonal-bg/hover`（次级按钮的半透明填充）、`--ui-glass-bg/border/filter`（浮在画布或视频上的玻璃控件）、`--ui-canvas-dots`（20px 点阵）、`--ui-scrim`、`--ui-ai-gradient`、`--ui-ai-glow`、`--ui-ai-aurora`、`--ui-ai-mark-mask`。

### 3.2 形状、字体、层级

- 字体：Google Sans（SIL OFL 1.1，内置拉丁 + 拉丁扩展子集，`font-display: swap`），中文回退系统字体。展示标题 `clamp(40px, 5.2vw, 72px)`/400/−0.03em；页面标题 32/400/−0.02em；控件 14/500。
- 圆角：按钮、分段、筛选、徽标 = 胶囊；输入框 14；卡片与浮层 20；大面板（对话栏、抽屉、对话框、首页输入框）28。
- 层级：1 = 静止卡片（深色主题用 1px 内描边代替阴影）；2 = 浮起面板；3 = 抽屉、浮层、看片画面。

### 3.3 受控的"非单色"用法（ADR 0019，测试固定白名单）

| 用法 | 位置 |
|---|---|
| 四角星 AI 标识（渐变填充） | 对话栏标题、AI 消息前、首页建议胶囊 |
| AI 工作中：标题文字流光、输入框外沿流光描边 | 对话栏"AI 正在剪…"、AI 处理中的输入框 |
| 主输入框聚焦光晕 | `.ui-prompt:focus-within`（首页与对话栏） |
| 静止极光 | 首页、欢迎页主视觉背后各一团 |
| 语音在听：光边 | 语音胶囊（在听 / 正在听你说）与开着的麦克风按钮 |

`prefers-reduced-motion` 下流光停止（保留静态描边与文字状态）；极光本身不动。

### 3.4 共享原语（旧类名，新外观——所有旧页面自动继承）

`.btn`（胶囊、半透明填充；`.primary` 实心；`.ghost` 透明；`.blue` 描边）、`.field`（14 圆角、控件级边界、聚焦主色边 + 焦点环）、`.chip`、`.segmented`、`.badge`、`.panel`、`.notice`、侧栏与导航项（胶囊、选中为 selection 底）、顶栏（透明，浮在画布上）、浮层（遮罩模糊 + 28 圆角）。新原语：`.ui-prompt`（大输入框）、`.ui-round` / `.ui-send`（圆按钮 / 圆形发送）、`.ui-seg`（输入框里的分段）、`.ui-suggestion`、`.ui-glass`、`.ui-card`、`.ui-ai-mark`、`.ui-ai-working`、`.ui-ai-text`。

## 4. 各界面的交互（参照 Stitch）

### 4.1 首页
- 居中大标题"今天想做一条什么视频？"+ 一句说明 + 一个大输入框；输入框页脚：**"+"（放入素材，新建一条视频）**、起点分段（**素材剪辑 / 文章讲述 / 链接导入**）、圆形发送；输入框下方是"试试这样说"建议（只填进输入框，不直接发送）。
- 素材剪辑：发送 → 新建页（想法预填作品名）→ 共看片室（想法预填在 AI 对话框里，**不自动发送**，用户放好素材再发）。文章讲述：文章预填到新建页的文章框；没贴文章不能发送。链接导入：走旧版导入流程。草稿只放本标签页的 sessionStorage，读一次即删。
- 下方"继续创作"：卡片缩略区画出作品的画幅框（不画假内容），标明"素材剪辑 · 16:9 / 文章讲述 · 16:9"；素材剪辑与文章讲述作品都进共看片室（修复：文章作品此前落到旧编辑器）。

### 4.2 共看片室
- **左侧 AI 对话栏**（宽 `clamp(340px, 27vw, 420px)`）：标题"✦ AI 剪辑师"；完整对话记录（用户气泡靠右，AI 回复带四角星）；试改的"就这样 / 撤回"在 AI 回复下的决定卡里；报价卡也在对话里；底部是这一轮的**制作规则（特效 / 配音 / 生成）与风格**，再下面是输入框（指认胶囊、"+" 上传素材、麦克风、圆形发送）。
- **右侧点阵画布**：画面浮在画布上（圆角 + 阴影，不再是满屏黑块）；画布左缘**浮动工具条**：框选画面（M）、素材（带数量角标）、快捷键（?），悬停有提示；底部**浮动的播放与时间带卡片**（玻璃）。
- **顶栏**透明：返回、作品名、已保存；右侧 AI 用量、审片、任务、语言、主题、**导出**（主按钮）。
- 语音胶囊浮在画面下方预留的边上，玻璃质感，在听时外沿亮起 AI 光边。
- 手机：一列——顶栏 / 画面 / 横排工具条 / 播放与时间带 / 对话栏（高 `max(480px, 70vh)`），整页滚动；测试断言画面在对话栏之上。

### 4.3 其他页面
- 审片：与共看片室同构——讨论面板在左（浮起的大圆角面板），画面在右浮于点阵画布；手机仍是单列，底部执行栏改玻璃。
- 新建、我的形象与声音：画布上的一张大圆角卡；"我的形象与声音"改为套用工作区外壳（侧栏、顶栏）。
- 工作区与作品二级页、运营、设计系统页：继承新原语；登录与欢迎页同样落在点阵画布上，欢迎页主视觉背后一团静止极光。

改版过程中由验证发现并修复：Firefox 390 px 首页的极光层造成 11 px 横向滚动（改为左右裁切）；首页起点分段在手机上折成两行（改为独占一行三等分）；手机共看片室的对话栏跑到画面上方（显式排序 + 新增断言）；深色主题下短页面露出浅色 `html` 底（`html` 跟随主题）。

两处与改版无关、但验证时暴露的旧问题一并修复：
- 测试用脚本导演把"换成蓝色"当成付费重绘（"换成"是重绘触发词，V6-7/8 引入），导致特效验收自那时起失败；改为已有特效且说了颜色时优先改特效颜色。
- 共看片室验收里"任务结束提醒"的断言只认单项文案；同一次轮询里多段素材同时处理完时提醒合并为"N 项任务结束了"，断言改为两种都接受。

## 6. 尚未做 / 交接

- 共看片室的"无限画布"只做到视觉与布局（点阵、浮动工具条、浮动卡片），没有平移缩放画布、多画面并排（Stitch 的多屏画布）；视频剪辑的主对象只有一个画面，暂不需要。
- 中文字体仍走系统字体（Google Sans 不含 CJK）；如需统一中文字形可另行引入开源 CJK 字体子集（体积需评估）。
- 旧版导演工作台（`/w/…/p/…`）只继承了新原语，没有按画布语言重排；V6 计划在 V6-5 / V6-1 新界面就绪后下线这些页面。
