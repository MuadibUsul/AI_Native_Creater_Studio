## 用户目标与角色/空间

- 创作者在大画布上**点选"目标对象"**（结构化覆盖层/片段），而不是只保存屏幕坐标。
- 悬浮给出本地轻高亮候选；点击给出明确选择；重叠对象可轮换候选；Shift/多选保留选择顺序（A、B…）。

## 真实入口

- 覆盖层组件 `CanvasInteractionLayer` 待接入 Studio 画布（`N04-01` 共看片室壳 / `PreviewPlayer` 之上）。当前作为可复用、已测试的覆盖层组件交付，尚未挂载到已发布路由。

## 对象与范围

- 对象身份来自 `objectId`（+ 版本）；预览帧号/帧哈希**不是**身份也不是授权。
- 命中复用既有 `hitTestVisualObject` / `invertVisualPoint` / `projectVisualPoint`（裁切→旋转→缩放/位移），不新建第二套坐标公式。
- 叠放顺序：zOrder 降序 → 细粒度 `VISUAL_OBJECT` 先于 `CLIP` → 稳定输入顺序；隐藏对象/被隐藏父对象的子对象不参与命中。
- 框选：以对象投影四角几何中心落入选框为准。

## 主流程 / 取消 / 恢复

1. 悬浮 → 本地高亮候选（不触发选择、不联网）。
2. 点击 → 命中上层细粒度对象，发出 `OrderedTargetRef[]`（objectId + targetKind + 版本）。
3. 重叠且上层已选中 → 轮换到下一个候选。
4. Shift/多选 → 追加并重排 A/B 标签；空白点击清空；Esc/清除由父层处理。
5. 手势只产出选择结构，不直接改工程；采用仍走统一编辑协议。

## 权限 / 费用 / 锁定 / 审批

- 纯只读选择：不调用视觉模型、不触发费用、不改工程。
- 命中注册只负责定位与身份；越权/失效由服务端权限与 N04-10 重映射处理。

## 设计覆盖

- **新增**：无对应高保真稿，按 v0.4 黑白语义 Token 绘制轮廓/悬浮/选中（SVG polygon，`vector-effect: non-scaling-stroke`）。
- **扩展**：复用既有视觉变换权威层，新增命中候选排序与投影函数。
