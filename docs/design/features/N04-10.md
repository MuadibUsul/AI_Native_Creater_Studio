# N04-10 UI 交付卡｜刷新、嵌套与时序变更后的锚点自动恢复

**归属任务：** N04-10（刷新、嵌套与时序变更后的锚点恢复）。
**来源需求：** `docs/V04/ANCS_v04_Mouse_Voice_Incremental_Design_20261010.md` §4.3、§8.2；`docs/design/mouse-voice-gap-map.md`。
**状态：** IN_PROGRESS（恢复契约 + 服务端自动恢复 + 幂等/并发/时序重投影/嵌套失效已交付并验证；UI 呈现与真实浏览器证据未做）。

## 用户目标与角色/空间

- 用户选好对象/时间段后刷新页面、移动/修边片段或改动嵌套序列，再回来时选择**不应静默失效或悄悄扩大**：能跟随的跟随、不能保真的明确标成失效/部分/歧义。

## UI 覆盖

- **本增量 UI 不适用**：N04-10 是选择锚点的**服务端恢复语义与恢复报告**（契约 + domain + API/SDK），没有新增用户可见控件。
- 关联用户切片：时间带选区（N04-04-s1）、画布点选（N04-02-s1）、共看片室刷新（N04-01）、语音重连（N05-05）。恢复结果（`changed/previousStatus/status`）供后续 UI 显示"选择已跟随/已失效"。

## 对象与范围

- 目标绑定的**恢复基线**（`bindingBaseline`: 保存时的片段序列/源区间；不参与选择指纹，可选/可空以兼容旧锚点）。
- `timeBindingPolicy`：
  - `FOLLOW_OBJECT`：片段在序列上移动 → 时间选择**按位移跟随**；
  - `FOLLOW_SOURCE`：片段修边/换源 → 时间选择经基线映射到源时间，再映射到**新**序列区间；映射失败标 `STALE`；
  - `SEQUENCE_FIXED`：不自动跟随。
- 恢复报告：`changed / previousStatus / previousRevision / trigger / status`。

## 主流程 / 取消 / 恢复

1. 刷新/时序变更 → 客户端调用 `recoverSelectionAnchor(trigger)`。
2. 服务端重解析目标：消失 → `FAILED`/`PARTIAL`；重复素材引用 → `AMBIGUOUS`（附候选）；版本过期/无法重投影 → `STALE`。
3. **刷新幂等**：无实质变化时不追加新修订（`changed=false`）。
4. **并发保护**：`expectedRevision` 不符 → 409；并发追加同一修订 → 主键冲突也返回 409，绝不静默覆盖。
5. 选择动作仍不改工程。

## 权限 / 费用 / 锁定

- 需 `project:write`；恢复只写锚点修订日志，不推进工程 revision、不触发 Provider/费用。

## 业务依赖与浏览器证据

- 依赖：`@ancs/contracts`（`targetBindingBaselineSchema`、恢复请求/结果 schema、`addMediaTime`/`subtractMediaTime`）、`@ancs/domain`（`recoverSelectionAnchor`）、SDK/HTTP 恢复端点。
- 浏览器证据：**未做**（无 UI 呈现）；当前证据为集成测试 4 项 + 契约单测。
