# N02-01｜有界内存的批量分片直传

日期：2026-10-09。覆盖类型：**扩展**。

## UI 交付卡

1. **用户目标、角色与空间**：创作者或编辑者在项目素材页一次选择多个本地素材，看到每个文件的真实上传状态；网络波动时可暂停、继续或重试，不丢失已经确认的分片。
2. **入口、对象与范围**：`/w/:workspaceId/p/:projectId/assets` 的“上传素材”对话框；操作对象是当前工作区、当前项目下的本地文件和对应 UploadIntent。
3. **主流程与恢复**：多选文件 → 文件级队列 → 单文件分片直传 → 服务端逐片校验 → 流式合并 → 既有素材确认。暂停会中止在途请求并保留已确认分片；继续复用同一 intent；失败保留原因和继续入口；取消使 intent 失效并删除未完成分片。
4. **权限、费用与限制**：要求 `asset:manage`；服务端继续执行工作区隔离、存储额度、MIME、大小和最终 SHA-256 校验。上传本身不触发 Provider 费用。浏览器安全模型不允许页面重载后无授权重新读取本地文件，因此本任务保证当前会话断网／暂停恢复，以及 SDK 持有 `resumeIntentId` 时的恢复。
5. **设计覆盖**：沿用素材页、现有 Modal、Button 和语义 Token；扩展文件选择为多选，并新增紧凑的文件队列、进度、暂停／继续／取消状态。未新增独立页面，也未更改 Studio 布局。
6. **业务依赖与验收**：真实 PostgreSQL、Fastify、LocalSignedStorage、生产 Next 与 Chromium；浏览器使用用户提供的 MP4 和生成的 PNG 完成多选、排队取消、在途暂停、继续及最终 READY。

## 状态与交互

| 状态 | 呈现 | 合法操作 |
|---|---|---|
| `QUEUED` | 文件名、大小、等待状态 | 取消 |
| `UPLOADING` | 服务端已确认字节对应的真实进度 | 暂停、取消 |
| `PAUSED` | 保留 intent 与已完成分片 | 继续、取消 |
| `ERROR` | 可理解的服务端或网络错误 | 继续、取消 |
| `COMPLETE` | 100% 与完成语义 | 关闭后在素材列表查看 |
| `CANCELLED` | 明确取消结果 | 从队列移除 |

长文件名使用省略并保留原生 title；窄屏按钮换行但不遮挡进度。浅色、深色均只使用既有黑白语义层，视频缩略图保持原色。

## 组件与契约映射

- `DeliveryAssets`：选择、文件级队列与恢复操作。
- `CreatorStudioClient.uploadResumable`：分片读取、受限并发、进度和 AbortSignal。
- UploadIntent API：状态读取、分片目标、分片确认、取消和最终确认。
- `StorageProvider.composeObjects`：服务端有界内存合并 seam；Local provider 以流式管道实现。
