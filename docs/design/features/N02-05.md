# N02-05｜转写、说话人与字幕锚点

日期：2026-10-09。覆盖类型：**扩展**。

## UI 交付卡

1. **用户目标、角色与空间**：创作者在素材详情核对源音频机器转写，按源时间播放句段，校正错误数字/词语并维护该素材的术语字典。
2. **入口、对象与范围**：`/w/:workspaceId/assets` 与项目素材页的素材详情；对象是当前不可变 Source AssetVersion，转写绑定 source checksum 和 processor version。
3. **主流程与恢复**：媒体探测完成自动排队 → ASR 生成词/句/说话人锚点 → 用户点击句段回放 → 校正或更新术语创建新版本。失败显示原因和重试入口，同时保留原音、媒体索引与既有转写版本。
4. **权限、费用与限制**：读取要求 `workspace:read`，重试和校正要求 `asset:manage`；SYSTEM Job 不受成本任务上限阻塞。机器识别统一标为 `ASR_INFERENCE / 待核对`，不等同已确认字幕。
5. **设计覆盖**：沿用素材详情、播放器、Badge、Notice、Button 和折叠区，在播放器与源索引附近新增紧凑转写区；不新增页面。浅色/深色/窄屏复用现有黑白 Token，真实视频保持原色。
6. **业务依赖与证据**：真实 PostgreSQL、Fastify、LocalSignedStorage、production Next、Chromium、真实用户 MP4 和脚本化 ASR Adapter；第三方 ASR 凭据/准确率属于 N02-09 Provider smoke，未冒充验证。

## 状态和恢复

| 状态 | 界面 | 合法操作 |
|---|---|---|
| `QUEUED/RUNNING` | “等待识别/正在识别”，说明播放和其他媒体结果不受影响 | 播放、下载原件 |
| `READY` | 版本、语言、Provider/模型、匿名说话人、源时间句段 | 播放区间、单句校正、更新术语 |
| `FAILED/STALE` | 原因和“配置完成后重试”；已有版本继续显示 | 继续播放/核对旧版本、重试 |
| 版本冲突 | 保存失败并要求刷新 | 刷新当前版本后重做校正 |

未知说话人显示“说话人未知”，契约禁止 `UNKNOWN` 身份携带名字。点击时间使用源 PTS/time base；代理播放时复用 N02-03 音频 PTS 映射。校正只替换目标句段和该句段词锚，`affectedSegmentIds` 只包含目标；原始 AssetVersion 和音频对象不改动。

## 组件与契约

- `DeliveryAssets`：转写状态、源区间播放、单句校正、术语版本和失败恢复。
- `MediaTranscript/MediaTranscriptVersion`：显式推测证据、精确锚点、匿名说话人、不可变版本和受影响句段。
- `MEDIA_TRANSCRIPT`：媒体探测事务内创建的 SYSTEM Job；未配置 ASR 时由默认 handler 写入明确失败状态。
- `media_transcript_runs/media_transcript_versions`：迁移 0067；source version + processor version 唯一，版本快照只增不改。
- `SpeechRecognitionAdapter`：Worker I/O seam；生产可通过隔离进程协议配置，stdout 必须返回严格 JSON，stderr 和 Secret 不进入结果或错误。

证据见 [`N02-05 verification`](../../verification/N02-05.md)。
