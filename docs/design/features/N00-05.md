# N00-05 UI 交付卡｜工作区新能力与发布门

- **用户目标、角色与空间：** Workspace Owner/Admin 在工作区设置中查看 v0.4 能力是否可用，并提前选择所需能力；普通成员可读，不能修改。
- **入口与范围：** `/w/:workspaceId/settings` →“新能力”。对象是当前工作区的五个稳定功能键；不改变平台级发布门，不控制旧 v0.3 能力。
- **主流程与恢复：** 进入后读取服务端有效状态 → 选择/取消选择 → 服务端保存偏好并重新计算状态。发布门未通过时显示“等待发布门”并保持只读；取消选择恢复 `OFF`。关闭不删除项目、版本或素材。
- **权限、费用与审批：** 读取需 `workspace:read`，修改需 `workspace:update`；选择本身不生成、不报价、不扣费。有效写入必须同时满足工作区选择和服务端发布门，前端不能授权。
- **设计覆盖：** 现有设置侧栏、Panel、Badge、StateBlock 和按钮模式**扩展**；旧高保真没有该能力，按 v0.4 黑白 Token **新增**五行紧凑状态。加载、错误、未选择、等待发布门、已启用和无修改权限均由真实状态决定。
- **真实依赖与证据：** 0056 偏好表、domain 有效状态/写守卫、Workspace API、SDK、设置页；隔离数据库验证默认关闭、G0 不能绕过、旧项目可读及跨租户 404。Chromium 1440×900 浅色、1280×800 深色、390×844 窄屏执行真实点击和 PUT/重新读取，截图人工检查。
