# N04-05 UI 交付卡｜AttentionSnapshot 与事件缓冲

**归属任务：** N04-05（AttentionSnapshot 与事件缓冲）。
**来源需求：** `docs/V04/ANCS_v04_Mouse_Voice_Incremental_Design_20261010.md` §5.1、§8.4；`docs/design/mouse-voice-gap-map.md`。
**状态：** IN_PROGRESS（权威契约与有界缓冲/轨迹保留已交付；录制器接线与语音时钟映射的真实 Provider 未接）。

## 用户目标与角色/空间

- 支撑"边说边指"的可复核协议：记录**本地单调时钟**、会话 epoch、播放/暂停/seek、视口、显式选择、指针轨迹最小保留与语音采样时钟对应关系；语音指代用**发话时**的观看记录，而不是解析时刻。

## UI 覆盖

- **本增量 UI 不适用**：N04-05 是共同注意力的**权威数据层**（契约 + 有界缓冲 + 轨迹最小保留），没有新增用户可见控件；其 UI 消费面是后续垂直切片（时间带/画布/语音对话栏）与 N04-08。
- 关联用户切片：N04-02-s1（点选）、N04-04-s1（横向时间带）、N05-01/N05-02（流式语音）。无设计稿需求；不新增页面。

## 对象与范围

- 事件信封：`eventId / sessionId / epoch / seq / monotonicMs / producer`（`seq` 仅在同一生产者流内有意义）。
- 事件类型：指针采样/按下/抬起、悬浮变化、选择变化、播放状态、seek、视口变化、**媒体呈现帧**（真实呈现时间）、语音采样时钟、转写修订（`utteranceId/transcriptRevision/isFinal`）。
- 缓冲有界：默认时间窗口 8s、事件上限 512；鼠标轨迹去样（最小距离 0.01）且上限 120 点。
- 隐私：默认只做**短时**保留，不默认永久保存全程录音或鼠标轨迹。

## 主流程 / 取消 / 恢复

- 追加事件 fail-closed：epoch 不一致、同生产者单调时钟回退、seq 不递增均拒绝；换纪元必须显式新建缓冲。
- 快照导出：事件 + 去样后的指针轨迹 + 语音时钟映射（缺词级时间时 `wordTimingAvailable=false`，不假装精确）。
- 不写工程、不触发 Provider；恢复/重连由 N05-05 承接。

## 权限 / 费用 / 锁定

- 只读会话数据；无 Provider 调用、无费用、无工程写入。

## 业务依赖与浏览器证据

- 依赖：`@ancs/contracts` 的 `attention.ts`（本项新增）。
- 浏览器证据：**未做**（尚无录制器接线与真实语音会话）；当前证据为契约单测 9 项。不宣称"N04-05 已交付"。
