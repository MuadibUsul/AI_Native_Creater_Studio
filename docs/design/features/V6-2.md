# V6-2 UI 交付卡｜共看片室里边看边说

**归属：** V6-2 流式双语语音 + 共同注意力（`docs/V06/milestones/V6-2.md`）；V6 §5.1、§5.2。
**状态：** IN_PROGRESS —— 界面、网关与协议已在真实浏览器（假麦克风）上验证；流式识别是本地同协议假服务（界面明确显示"语音识别：测试替身"），真实 Deepgram 待密钥；AI 回应的朗读用浏览器自带语音。

## 用户目标与入口

- 创作者在共看片室里点对话框旁的麦克风，边看边说："把这里剪短一点"——说"这里"时指着哪段，就改哪段。中英文都可以。
- 入口：`/w/:workspaceId/studio/:projectId` 对话栏的麦克风按钮（只读成员不可用）。

## 主流程与状态

| 状态 | 表现 |
|---|---|
| 关 | 麦克风按钮（"开始语音"） |
| 连接中 | "正在连接语音…" |
| 在听 | "正在听，边看边说" + 音量条；识别实现不是真实供应商时显示"语音识别：测试替身" |
| 说话中 | "听到：<边说边出的文字>" + "指的是：片段「lake.mp4」（说"这里"时）"；开口即停止 AI 的朗读 |
| 没说完 | "听起来还没说完，接着说…"（以"但是/不对/除了"等结尾） |
| 说完 | 这句话作为一轮对话发出（对话里显示为"你"说的话），AI 回应后按"朗读回应"开关朗读 |
| 收尾 | 点"结束语音" → "正在收尾…" → 关 |
| 错误 | 浏览器不支持 / 没有麦克风权限 / 语音未配置 / 没有编辑权限 / 连不上 / 识别中断，各有说明 |

三种停止分开：**停止说话**（只停朗读）、**停止**（停止进行中的一轮）、**撤回**（不要这个试改）。

## 中英与可访问性

- 文案在 `messages.studio.voice`（中英同结构）；会话语言跟随界面语言，识别按语言选模型。
- 麦克风按钮有可读名称与按下状态（`aria-pressed`）；状态行 `aria-live="polite"`；错误 `role="alert"`。
