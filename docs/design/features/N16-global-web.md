# N16 跨页面 Web 视觉交付卡｜v0.4 黑白规范

**性质：** 用户 2026-10-08 指定的全站视觉工作包，映射 N16-03—12 和每个受影响功能切片；不新增或重编号 N 任务，也不提前将 D0/D1 标为完成。

| 项目 | 本轮执行边界 |
|---|---|
| 用户目标、角色、空间 | 创作者在 Studio/Workspace、平台人员在 Ops 的现有 Web 路由中获得一致、清晰的白/近黑/中性灰界面；作品画面和用户素材保持原色。 |
| 入口、对象、范围 | `apps/web/src/app` 的全部现存 21 个 `page.tsx` 路由及其共享导航、设置、表格、抽屉和状态。新功能随各自 UI 卡验收；此工作包先对真实存在的界面逐路由盘点、定点迁移和复测，不创建平行 Web 应用。 |
| 主流程与恢复 | 保持用户原有入口与操作次序；浅/深/跟随系统切换、导航、表单、播放、选区、确认和取消语义不变。视觉改动按组件/路由独立回退，不能重置作品、账本或数据。切换租户后清理前一租户的敏感可见状态。 |
| 权限、费用、锁定、审批 | 视觉层不持有新业务权威；原有服务端权限、预算、审批和项目锁继续生效。不得因主题/抽屉开关重提付费任务或把请求取消显示为完成。Ops 有副作用操作只随 AdminAction 切片开放。 |
| 设计覆盖 | Quiet Frame 参考包有 13 个创作相关页面和部分手机/深色图，**沿用**其中未与新规范冲突的结构、密度与内容原色；黑白语义 Token、深色/系统和缺失状态为**扩展**。参考包没有平台运营台，按 v0.4 §28/§29 **新增**紧凑 Ops 读面；旧蓝色强调、彩色 KPI 和 slate 管理模板在受影响区域**替代**。模型生成图不自动视为已批准设计。 |
| 复用与补全 | 以 `apps/web/src/app/ui-tokens.css`、Quiet Frame 共享控件、`StateBlock`、`StudioShell`、`QuietIcon` 为基础；优先修 Token 与组件，再定点修路由。无法复用时建立最小组件，不在各页散落色值。参考包图标许可仍待确认，不以视觉迁移掩盖权利状态。 |
| 必要状态 | 各路由按实际业务检查空、加载、成功、失败、无权、只读、锁定、缺素材/外部服务、版本与费用状态；保留输入与已确认作品。UI 用文字/边界/图标区分状态，不只靠颜色，不把未知数填零。 |
| 浏览器与证据 | 逐路由实际打开、交互和截图目检；桌面 1440×900、1280×800，相关 390/320px 与 Chrome 原生 200%，浅/深/系统、键盘焦点、降低动效、长中英混排。媒体另跑真实播放/选区/版本检查。每项记录真实 API、fixture/Mock 边界和截图路径；用户视觉批准另行记录。 |

**已查看的参考：** 实际打开 `screens/01-workspace.png`、`13-design-system.png`、`18-dark-workspace.png`。参考图的页面层级、导航宽度、密度和媒体色彩有价值；其蓝色按钮/链接与偏绿深色背景与当前 v0.4 黑白 Token 冲突，现行规范优先。设计包无运营后台图，不能称作 1:1 还原。

**当前结果：** 公共 Token 与共享组件已统一到黑白语义层；公开入口去除虚构绿色图表和假封面，Workspace/Studio 的项目、时间轴、素材、成片、分析、账单、团队状态已改为中性色并保留作品原色；Ops 使用紧凑独立会话和显式 scope 诊断。真实浏览器证据覆盖公开 15 场景布局、真实会话与播放、受保护路由 200%、Ops 真实 API 的深浅/窄屏/权限拒绝。任务级状态仍登记在 [`ui-coverage.md`](../ui-coverage.md)；Safari/macOS、图标许可及尚未实现的 N16 业务能力不因本轮视觉迁移而标通过。
