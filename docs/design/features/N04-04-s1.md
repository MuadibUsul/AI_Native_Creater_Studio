# N04-04-s1 UI 交付卡｜横向时间带（播放头与时间选区分离）

**归属任务：** N04-04（时间范围、逐帧和音频目标）的**首批子任务 s1**；依赖 N04-09-s1 已交付的选择/时间契约。
**来源需求：** `docs/V04/ANCS_v04_Mouse_Voice_Incremental_Design_20261010.md` §2.1、§4；`docs/design/mouse-voice-gap-map.md`。
**状态：** IN_PROGRESS（组件与契约已交付并通过测试；真实浏览器/高 DPI 目检待 N04-01 共看片室壳与真实时长数据接线）。

## 用户目标与角色/空间

- 创作者在现有分镜工作台（`/w/:workspaceId/p/:projectId/storyboard`，兼容 `/editor`）展开「轻时间线」后，看到一条**紧凑横向时间带**：轨道/片段块 + 播放头 + **独立时间选择带**。
- 目标：先选时间段（再叠加语音/点选得到完整作用域），而**不是**在"看片模式"和"时间轴模式"之间切换两份作品状态。

## 真实入口

- 现有 `WorkflowDirector` →「展开轻时间线」→ `LiteTimeline`。本次在 `LiteTimeline` 内**扩展**新增 `TimelineBand`（不重写 `LiteTimeline`）。
- 轨道块默认由既有场景/字幕数据投影（视频轨/字幕轨）；v2 片段/轨道数据由父层接入（属 N03-08 UI 接线与本增量后续）。

## 对象与范围

- 对象：片段块（sceneId / captionId），时间范围是既有有理时基上的**半开区间** `[start,end)`。
- 播放头（sequence time）与时间选区是两个模型：标尺拖动只改播放头；选择带拖动只改选区；二者命中区域不重叠。
- 单击（位移 < 阈值）产物是 `POINT`；拖动产物是 `RANGES`；Shift+拖动在既有区间上叠加**显式多区间**，不合并中间整段。

## 主流程 / 取消 / 恢复

1. 拖动标尺 → 播放头移动（本地即时，不走网络）。
2. 在选择带拖动 → 得到时间选区；Shift+拖动叠加第二个区间。
3. 点击片段块 → 选中对象（不改播放头）。
4. 清除按钮或 Esc → 取消当前手势/草案（清空选区），**不等于撤销工程**。
5. 选择动作永不写库；后续把选区与对象组装为 `SelectionAnchor`（N04-09 契约），采用仍走统一编辑协议。

## 权限 / 费用 / 锁定 / 审批

- 纯只读选择：不触发 Provider、不产生费用、不改工程、不绕过既有权限与锁。
- `disabled`（无编辑权限或提交中）时禁止交互；错误仍由既有编辑协议路径呈现。

## 设计覆盖
