# N02-06｜语义素材检索与实际片段查看

日期：2026-10-09。覆盖类型：**扩展**。

## UI 交付卡

1. **用户目标、角色与空间**：创作者在工作区素材库用自然描述找到已有素材中的具体画面、声音或回答，并立即查看真实音视频上下文。
2. **入口、对象与范围**：`/w/:workspaceId/assets` 与项目素材页的“搜索真实片段”；对象是当前 Source AssetVersion 的精确 PTS 范围。素材详情可为确定范围维护用户标签。
3. **主流程与恢复**：输入至少两个字符 → 返回视觉/声音/转写/用户标签证据 → 查看证据性质与源时间 → 点击打开原素材并只播放该范围。无结果显示真实空态；搜索或播放失败不创建替代资产，也不改变素材。
4. **权限与安全**：搜索和标签读取要求 `workspace:read`，标签增删要求 `asset:manage`；API 与 domain 均强制 workspace scope。上传字幕、转写和索引文本统一为 `REFERENCE_DATA_ONLY`，没有可执行 action 字段。
5. **设计覆盖**：扩展现有素材筛选与素材详情，复用 Panel、Searchbox、Badge、Button、播放器和源时间映射；没有新增页面。桌面保持紧凑列表，390px 变为纵向操作，真实媒体保持原色。
6. **业务依赖与证据**：真实 PostgreSQL、Fastify、LocalSignedStorage、production Next、Chromium、真实用户 MP4；脚本 ASR 只提供受控转写证据，不代表第三方 Provider 实测。

## 证据语义与状态

| 类型 | 证据标签 | 含义 |
|---|---|---|
| 媒体索引 | `OBSERVATION` / 媒体观测 | FFmpeg 媒体处理器产生的镜头、波形、缩略或质量区间 |
| 转写 | `INFERENCE` / 机器推测 | ASR 推测文本和“第 N 次回答”位置，不等于用户确认事实 |
| 用户标签 | `USER_ASSERTED` / 用户标记 | 用户为当前 Source AssetVersion 明确命名的范围 |

空结果只返回空数组并显示“不会生成替代素材”。结果固定携带 `assetId`、`sourceAssetVersionId`、源 PTS、time base 和 `REFERENCE_DATA_ONLY`；播放代理时复用 N02-03 的音视频 PTS 映射。标签绑定当前版本，素材切换 current version 后旧标签不会误用于新版本。

## 组件与契约

- `DeliveryAssets`：片段搜索、证据标签、真实空态、源区间播放和片段标签管理。
- `MediaSegmentSearchResponse`：四类 modality、三类 evidence、精确时间范围和固定内容处置。
- `media_range_tags`：迁移 0068；workspace、asset 与 current source version 绑定，数据库和契约共同保证正区间。
- `searchMediaSegments`：统一读取用户标签、当前 READY 转写版本和媒体索引；排除软删除资产并稳定排序，不创建媒体。
