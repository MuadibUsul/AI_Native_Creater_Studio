# N02-04｜缩略、波形、镜头与片段索引

日期：2026-10-09。覆盖类型：**扩展**。

## UI 交付卡

1. **用户目标、角色与空间**：创作者在素材详情中快速浏览真实源媒体结构，点击缩略、波形、镜头或质量区间即可播放对应源区间。
2. **入口、对象与范围**：`/w/:workspaceId/assets` 与项目素材页的素材详情；对象是当前不可变 Source AssetVersion，对应索引绑定源 checksum、源 PTS 与 processor version。
3. **主流程与恢复**：探测完成自动排队 → 分阶段写入索引 → READY；用户切换四类索引、分页浏览、点击区间播放。索引失败时保留原件、代理与旧条目，显示原因和“重新生成索引”。
4. **权限、费用与限制**：读取要求 `workspace:read`，重建要求 `asset:manage`；索引是 SYSTEM Job，不调用收费 Provider。所有查询再次携带 workspace scope。
5. **设计覆盖**：沿用素材详情、播放器、Badge、Chip 和 Button；在播放器附近新增紧凑“源媒体索引”区。媒体缩略保持原色，波形使用中性前景色；不新增页面或常驻工具栏。
6. **业务依赖与证据**：真实 PostgreSQL、Fastify、LocalSignedStorage、production Next、Chromium 和本机 ffmpeg；真实用户 MP4 完成生成、区间播放、故障隔离、UI 重建和恢复。

## 状态和交互

| 状态 | 界面 | 合法操作 |
|---|---|---|
| `QUEUED/RUNNING` | “正在生成”，原件或代理照常播放 | 播放、下载原件 |
| `PARTIAL` | 已写入条目可读，覆盖率和检查点继续推进 | 浏览已有页、播放已有区间 |
| `READY` | 四类标签、源区间、真实缩略/波形、分页 | 点击区间播放；切换类别和页 |
| `EMPTY` | 明确无该类检测结果 | 继续使用媒体 |
| `FAILED/STALE` | 原因、保留的旧索引和恢复入口 | 重新生成；继续播放原件/代理 |

索引点击先读取条目的源 PTS；播放代理时通过 N02-03 的 `PTS_AFFINE` 映射换算代理 PTS，播放原件时按条目 time base 换算秒。播放器在区间结束暂停，不改变项目选区、源版本或 SceneGraph。

## 组件与契约

- `DeliveryAssets`：索引类别、分页、失败恢复、源区间播放。
- `MediaIndexPage/MediaIndexEntry`：状态、覆盖率、检查点、源 PTS、time base、置信度、白名单 payload 和短期缩略 URL。
- `MEDIA_INDEX`：有限重试 SYSTEM Job；失败不迁移 Asset 或代理状态。
- `media_index_runs/media_index_entries`：迁移 0066；稳定 source version + processor version 复用，一条记录一个源时间区间。
- `SourceMediaIndexer`：Worker seam；真实实现用隔离 ffmpeg 生成缩略、100 Hz 波形峰值、scene score 镜头边界、blackdetect/silencedetect 质量标记。
