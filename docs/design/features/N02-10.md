# N02-10 UI 交付卡｜统一 Media Index 契约与证据记录

1. **用户目标、角色和空间**：创作者在素材详情、搜索和后续 Studio 选区中看到来自同一源时间轴的可靠分析证据；工作区成员只能读取本租户素材。
2. **入口与范围**：本任务没有新增可见入口。现有素材详情和片段搜索继续作为用户入口；新增的 `/assets/:assetId/media-index-records` 与 SDK `mediaIndexRecords` 是这些界面的统一读模型。
3. **主流程与状态**：按素材当前不可变版本读取测量、模型推断和用户标记；可按种类、源 PTS 范围分页。每个能力明确为 `NOT_ANALYZED / PARTIAL / READY / EMPTY / FAILED / UNSUPPORTED`，避免把未分析误报为空结果。
4. **权限与恢复**：读取要求 `workspace:read`，domain 查询再次约束 `workspaceId`；跨租户统一 404。记录包含版本、来源证据、置信和校准，不包含存储键或临时 URL。
5. **设计覆盖**：**沿用**素材详情和搜索的既有交互；**扩展**其后台数据契约。UI 不适用，因为本切片没有新的用户决策或操作，新增控件会制造第二套状态。N02-11—15 将按实际用户流程消费阶段、纠错和检索能力。
6. **业务与验收证据**：迁移 0071、真实 PostgreSQL、真实 FFmpeg 索引、脚本 ASR、HTTP/SDK 与跨租户测试；详见 [`docs/verification/N02-10.md`](../../verification/N02-10.md)。本任务没有页面视觉变化，因此浏览器截图不适用。

## 复用与单一权威

- 复用 `media_index_runs/entries`、`media_transcript_runs/versions` 和 `media_range_tags`，在 domain 形成统一投影，没有复制第二份索引事实。
- 同一记录统一携带 `sourceAssetVersionId + streamId + sourceRange`，ASR 与视觉结果可按有理数时间基交叉查询。
- 类别 payload 使用判别联合严格校验；工具/模型/配置 hash、观测依据、证据引用、隐私和生命周期均为公共契约。
