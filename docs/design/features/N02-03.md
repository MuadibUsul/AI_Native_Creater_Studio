# N02-03｜代理转码与源时间映射

日期：2026-10-09。覆盖类型：**扩展**。

## UI 交付卡

1. **用户目标、角色与空间**：创作者或编辑者上传音视频后，系统自动准备稳定的 Web 编辑代理；用户可预览代理、下载原件，并明确知道正式输出仍回链原件。
2. **入口、对象与范围**：`/w/:workspaceId/p/:projectId/assets` 和工作区素材库的素材详情；对象是当前不可变 SourceAssetVersion 及其 `PROXY` 派生记录。
3. **主流程与恢复**：媒体探测完成 → 自动选择视频 720p 或音频 48 kHz 立体声 profile → 系统转码 → 播放使用短期签名代理地址。生成中且原件可直接预览时明确回退原件；代理失败或对象丢失时保留原件并提供“重新生成代理”。
4. **权限、费用与限制**：读取播放地址要求 `workspace:read`；人工生成／重建要求 `asset:manage`。代理是 SYSTEM Job，不触发 Provider 费用。内部派生资产不出现在素材清单，跨租户统一 404。
5. **设计覆盖**：沿用素材详情 Modal、Button、Badge 和黑白语义 Token；新增“编辑代理”状态区，不新增页面。播放器保持媒体原色，详情分别呈现生成中、已就绪、失败、文件缺失和重新提交状态。
6. **业务依赖与验收**：真实 PostgreSQL、Fastify、LocalSignedStorage、生产 Next、Chromium 与本机 FFmpeg/ffprobe；使用真实 MP4 执行上传、探测、转码、三次 seek、删除代理、UI 重建和再次播放。

## 交互与状态

| 状态 | 呈现 | 合法操作 |
|---|---|---|
| `PENDING` / `PROCESSING` | “正在生成”；原件可直接预览时说明当前回退原件 | 继续预览原件、下载原件 |
| `READY` | “已就绪”、实际 PTS 映射、代理播放器 | 播放／seek、重新获取签名链接、下载原件 |
| `FAILED` | 稳定失败说明；原件不变 | 重新生成代理、下载原件 |
| `MISSING` | “文件缺失”；可用时回退原件 | 重新生成代理、下载原件 |
| `NOT_REQUIRED` | 兼容 N02-03 前已探测素材，显示“尚未创建” | 生成编辑代理 |

重新生成复用同一个派生身份与确定性对象键，不创建第二个源版本。主题切换、Modal 开关和播放 seek 不改变项目选择或触发额外转码。

## 组件与契约映射

- `DeliveryAssets`：编辑代理状态、代理／原件回退、重建入口和播放器。
- `MediaPlaybackResponse`：当前 rendition、代理状态、短期 URL、profile 与逐流 PTS 映射。
- `MEDIA_PROXY` Job：探测完成事务内创建的系统任务；失败有限重试。
- `media_derivatives`：复用 N01-10 的单一派生权威，绑定源 checksum 与输出 AssetVersion。
- `SourceMediaTranscoder`：Worker I/O seam；默认实现通过隔离 ffmpeg/ffprobe 子进程生成标准代理。
- `StorageProvider.persistFile`：流式、临时写入后原子发布代理对象。
