# V6-6 UI 交付卡｜从参考视频学风格

**归属：** V6-6 蒸馏器（`docs/V06/milestones/V6-6.md`）；V6 §6.7、§6.6（风格是可选功能，只以数据进入 AI 上下文）。
**状态：** IN_PROGRESS —— 上传文件与直接视频链接的全链路已在真实浏览器 + 真实 FFmpeg 测量上验证；平台页面链接需要部署方配置下载命令；模型撰写说明待密钥。

## 用户目标与入口

- 创作者拿 1–5 条想学的视频（最好同一位博主），让系统测出它们的剪法，做成一个**可选**的风格；剪自己的素材时选上它，AI 把它当参考，不当模板。
- 入口：共看片室 `/w/:workspaceId/studio/:projectId` 对话框上方"风格（可选）"一行末尾的"从参考视频学风格"。

## 主流程与状态

| 状态 | 表现 |
|---|---|
| 添加参考 | 抽屉：说明测量哪些手法、版权由用户负责；"添加视频文件"（可多选，显示上传百分比）或粘贴链接（非 http(s) 链接就地提示）；可移除；最多 5 条；可选填风格名 |
| 学习中 | 四步进度：获取视频 → 测量剪辑手法 → 写风格说明 → 保存（当前步 `aria-current="step"`），每 1.5 秒刷新 |
| 失败 | 按原因说明：平台页面链接没配置下载工具（提示下载后上传）、内网地址被拒、太大、不是视频、文件损坏、分析工具未装、模型撰写出错；"重新开始" |
| 结果 | 风格名；说明由谁写（"按测量统计自动写的说明（没有 AI 看片）"或"AI 看过测量结果和画面后写的说明"）；只列真实测量：镜头时长（中位与常见区间）、剪辑频率、卡点比例、黑场过渡、色调、声音、节奏曲线（10 段柱状）；测量依据（几条、几分钟、几个镜头）；**测不到的如实列出**（景别、推拉缩放、变速、字幕样式；没有稳定节拍时列"卡点"） |
| 改说明 | "改说明"→ 编辑当前语言的说明与"给 AI 的要点"→ 保存（版本 +1，测量数值不变） |
| 选用 | "用这个风格"→ 抽屉关闭，"风格（可选）"选中它（旋钮取默认值）；下一轮对话带上这个风格 |

## 中英与可访问性

- 文案在 `messages.studio.distill` 与 `studio.strategy.learn`（中英同结构）；色调与声音是写给 AI 的英文测量描述，按原文显示并标 `lang="en"`。
- 抽屉为 `complementary` 地标（名称"从参考视频学风格"），打开时焦点到关闭按钮，Esc 关闭并还焦点；进度为 `role="status"`，失败为 `role="alert"`；节奏曲线为 `role="img"`，可读名称列出 10 段数值。
- 390 px 宽度下抽屉占满宽度，无横向溢出。
