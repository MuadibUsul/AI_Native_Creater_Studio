# N06-04 UI 交付卡｜局部试片缓存与依赖失效

**归属任务：** N06-04（局部试片缓存与依赖失效）。
**来源需求：** 增量设计 §6.2、§8.5、§9.3；`docs/design/mouse-voice-gap-map.md`。
**状态：** IN_PROGRESS（服务端局部试片缓存 + 依赖键失效 + 显式/采用清理已交付并验证；UI 呈现与真实浏览器证据未做）。

## 用户目标与角色/空间

- 用户反复查看同一个候选试改（切换页面、重连、重开面板）时，**不应重复付出**确定性试改的计算；但依赖一旦变化（工程版本、操作集、选择、素材版本），**不得**返回陈旧试片。

## UI 覆盖

- **本增量 UI 不适用**：N06-04 是服务端缓存与失效语义（`ProposalTrial.cached/dependencyKey`），没有新增用户可见控件。
- 关联用户切片：候选试改呈现（ghost 预览、局部回放对照）属 N04-02-s1／N04-04-s1；本项只是让它们拿到的试片可复用且不陈旧。
- 客户端可通过 `cached` 显示"复用已有试片"（可选），但不是权威状态。

## 对象与范围

- 缓存键 `dependencyKey = sha256(baseProjectRevision + operationsHash + selectionFingerprint + intentRevisionId + assetVersionSignature)`。
- 缓存行身份 `(workspace, project, dependencyKey)`，按工程隔离；内容为只读 `ProposalTrial`。
- 失效：
  - **键失效（主）**：任一依赖变化 → 新键 → 自然不命中（含片段换源导致的素材版本签名变化）；
  - **采用/丢弃清理**：候选采用或丢弃后删除其缓存行；
  - **显式失效**：`invalidateProposalTrials(project)` 供素材版本变化等主动清理。

## 主流程 / 取消 / 恢复

1. 试改请求 → 计算依赖键 → 命中则返回同一试片（`cached=true`），不跑执行器。
2. 未命中 → 真实执行器事务内跑完回滚（`projectUntouched=true`）→ 写入缓存。
3. 依赖变化 → 新键 → 重算；旧缓存行不再被引用。

## 权限 / 费用 / 锁定

- 试改本身经既有权限/锁/预算路径；缓存只复用**只读**试片结果，不绕过采用时的服务端重验。
- 无 Provider、无费用、不改工程。

## 业务依赖与浏览器证据

- 依赖：`@ancs/contracts` 的 `ProposalTrial.cached/dependencyKey`、`@ancs/db` 的 `proposal_trials`（迁移 0082）、`@ancs/domain` 的 `previewProposal`/`invalidateProposalTrials`。
- 浏览器证据：**未做**（服务端缓存）；当前证据为真实 PostgreSQL + HTTP + SDK 的 3 项集成用例。
