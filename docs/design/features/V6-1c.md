# V6-1c UI 交付卡｜共看片室编辑器外壳

**归属：** V6-1 共看片室最小闭环（`docs/V06/milestones/V6-1.md`）；V6 §5（指、说、改）、§7.4（改哪里渲染哪里）。
**状态：** IN_PROGRESS —— 界面与服务端闭环已在真实浏览器 + 真实 FFmpeg 上验证；AI 导演在验证中是**脚本导演（SCRIPTED）**，真实 Claude 的剪辑质量未验证；语音（V6-2）、窄屏/移动审片（V6-4）不在本切片。

## 用户目标与角色/空间

- 创作者（工作区 OWNER/ADMIN/EDITOR）用自己拍的素材做一条视频：放入素材 → AI 剪第一版 → 在时间带上指出"哪里"、说一句"怎么改" → 原地看试改 → "就这样"采用或"撤回" → 需要时整体撤销这次修改 → 导出。
- 只读成员（REVIEWER/VIEWER）可以看、播放、看对话；不能说话、采用、上传、导出（服务端拒绝为准，界面给出只读说明）。

## 真实入口

- 首页 `/`："用你拍的素材剪一条视频 → 进入共看片室"（中英双语卡片）。
- 新建 `/w/:workspaceId/studio/new`：标题 + 画幅（16:9 / 9:16 / 1:1 / 4:5）。
- 工作台 `/w/:workspaceId/studio/:projectId`：单屏，不套用侧栏与全局顶栏；首页作品卡片里素材工程（FOOTAGE_EDIT）直接进入这里。

## 对象与范围

- 工程状态只来自服务端：工作台状态（`studio.state`）、工程文档（`projects.state`，按版本号读取）、轮次（`agent.listTurns`）、提案（`projects.proposal`）、预览（`previews.request/get`）。界面不维护第二套工程状态。
- "指"：时间带拖选 = 有理时间区间（帧网格吸附，`@ancs/contracts` timeline-band 换算）；点片段 = 片段 id。两者组成对话的 `pointer`。
- 试改时，时间带显示的是试改预览计划里的片段（与采用后 id 一致），因此可以继续指着试改里的片段说话。

## 主流程 / 取消 / 恢复 / 撤销

1. 新建 → 空工作台（放入素材的拖放与按钮）。
2. 上传（可断点续传的 SDK 上传）→ 处理中（探测、代理、索引；AI 理解进度在素材抽屉）→ 素材就绪、还没剪 → "让 AI 剪第一版"。
3. AI 一轮完成 → 提案成为**试改**：画布播放试改预览（明确标记"试改预览 · 还没采用"），工程不变。
4. "就这样" → 按看过的操作哈希采用；之后"撤销这次修改"整组撤销（一个提案 = 一次修改）。"撤回" → 丢弃，工程不变。
5. 不采用、继续说一句 → **在试改上继续**：新一轮从这份试改出发，新试改取代旧试改；AI 只回答不再改 → 沿用原试改。
6. 三种"停"分开：停止进行中的一轮（"停止"）、撤回试改（"撤回"）、撤销已采用的修改（"撤销这次修改"）。
7. 导出：冻结当前版本 → 渲染 → 技术检查 → 短期下载链接；导出期间作品被改 → 明确提示重新导出。

## 权限 / 费用 / 锁定

- 写操作全部经服务端鉴权；界面按工作区角色只做提示。
- AI 用量：顶栏显示本条视频累计的模型费用（按公开单价估算）；含未定价调用时显示"含未定价调用"，不填零。本轮费用显示在回应下方。
- 导出与预览都是服务端计算（预览归入昂贵端点限流），不涉及付费 Provider。
