# N02-14 UI 交付卡｜索引纠错覆盖层与删除权限同步

1. **用户目标与角色**：Workspace 创作者校正机器转写后可以放心重新分析；删除素材或失去成员权限后，旧检索结果、游标和派生预览立即失效。
2. **入口与作用范围**：沿用 `/w/:workspaceId/assets` 与 `/w/:workspaceId/p/:projectId/assets` 的素材详情、转写校正、片段搜索和生命周期删除；不新增独立页面。
3. **主流程与恢复**：打开素材 → 校正转写 → 重跑 ASR → 人工覆盖继续生效、未校正片段采用新结果。删除时先在事务内撤销索引，再清理派生对象和客户端查询缓存；恢复素材后明确显示相关阶段“等待重建”，由用户逐阶段重试。未启用的能力仍保持“未启用”。
4. **权限与边界**：每次检索和分页都重新执行 `workspace:read`，旧 cursor 不是授权凭据；撤销成员后返回 404。相同字节在不同 Workspace 仍创建独立逻辑资产和版本，派生结果不跨租户共享。
5. **设计覆盖**：**沿用**素材详情、转写编辑、渐进分析、片段搜索和生命周期操作；**扩展**“人工覆盖 · 已确认”、删除后搜索空态与恢复后的阶段重建状态。没有建立第二套素材或索引界面。
6. **状态与交互**：区分机器结果、用户标签、已确认纠错；覆盖排队、READY、STALE、DISABLED、删除、恢复、无结果和权限撤销。移动端弹层使用 `90vh` 与内部滚动，操作和证据均可到达。
7. **业务与验收证据**：真实 PostgreSQL、用户 MP4、FFmpeg 索引、脚本 ASR seam、REST/SDK 授权、对象存储删除和 Playwright 浅深色桌面/窄屏；详见 [`docs/verification/N02-14.md`](../../verification/N02-14.md)。脚本 ASR 只证明覆盖和恢复协议，不代表第三方模型质量。

## 复用组件

- `DeliveryAssets`：转写校正、渐进分析、真实片段搜索、删除与恢复后的状态说明。
- `media_transcript_versions`：不可变机器结果与人工覆盖版本链。
- 统一 Media Index：机器记录、用户标签、人工确认、权限过滤和删除 tombstone 共用同一读投影。

## 视觉判断

- “人工覆盖 · 已确认”直接出现在转写元信息中，避免把用户校正继续标成机器推测。
- 删除后搜索保留用户查询并显示真实空态，不生成替代内容；恢复后只把实际运行过的阶段标为“等待重建”。
- 浅色、深色和 390 px 窄屏沿用黑白中性 Token，视频原色不受主题影响。
