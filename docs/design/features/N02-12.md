# N02-12 UI 交付卡｜动作、对象与匿名人物轨迹索引

1. **用户目标与角色**：Workspace 创作者从真实素材中查找动作或对象候选片段，回看原画面，并把确认结果保存为人工片段标签。
2. **入口与作用范围**：沿用 `/w/:workspaceId/assets` 与 `/w/:workspaceId/p/:projectId/assets` 的“搜索真实片段”和素材详情；结果只来自当前 Workspace 可读素材，人工标签绑定具体素材版本和源时间范围。
3. **主流程与恢复**：上传视频 → Probe 后异步执行 Sampling/Vision → 搜索“举起手机” → 结果标明机器推测和精确源范围 → 播放实际素材区间 → 在素材详情添加人工标签。视觉分析失败时素材仍可剪辑，可在“渐进分析”中重试该阶段。
4. **权限与边界**：沿用 `workspace:read`/`workspace:update`；人物轨迹只保存匿名 `person` 与 `UNKNOWN` 身份，不推断姓名，不跨项目做人脸实名匹配。机器结果是检索证据，不自动改写素材、项目或人工确认状态。
5. **设计覆盖**：**沿用**现有素材库、片段搜索、播放器和片段标签；**扩展** Sampling/Vision 阶段状态与视觉记录投影；**新增**亚秒时间显示，避免短动作范围被显示为同一整秒。没有新增页面或第二套媒体状态。
6. **状态与交互**：覆盖排队、运行、READY、EMPTY、FAILED、DISABLED；对象/动作/视觉事件/运动强度、人物遮挡和不确定关键帧保留证据；搜索空态与错误沿用现有恢复路径。点击候选只播放对应源区间，人工标签可删除并重新添加。
7. **业务与验收证据**：真实 PostgreSQL、真实用户视频、FFmpeg Probe、Worker 视觉 Adapter seam、统一 Media Index、搜索/播放/人工纠正及 Playwright 浅色桌面和深色窄屏；详见 [`docs/verification/N02-12.md`](../../verification/N02-12.md)。Scripted Adapter 只证明 I/O seam 与产品链路，不作为第三方视觉 Provider 实测。

## 复用组件

- `DeliveryAssets`：搜索、证据语义、实际片段播放、人工范围标签和阶段恢复。
- `media_analysis_stages`：Sampling/Vision 的权威状态和局部重建。
- 统一 Media Index：对象、动作、人物轨迹、视觉事件和运动强度与既有媒体证据共用读取、权限和搜索投影。

## 视觉判断

- 机器推测与用户标记使用既有中性 badge 和文字层级，不引入彩色 AI 装饰。
- 亚秒范围显示毫秒；整秒结果保持简洁的 `mm:ss`。
- 手机窄屏结果按证据、标签、时间和操作纵向排列，视频原色不受主题处理。
