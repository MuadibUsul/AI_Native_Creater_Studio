# V6-5 UI 交付卡｜从文章开始：讲述 + 图解

**归属：** V6-5 文章转视频（`docs/V06/milestones/V6-5.md`）；V6 §4.2、§7.2、§5.3。
**状态：** IN_PROGRESS —— 全链路已在真实浏览器 + 真实语音合成（本地 flite，英文）+ 真实特效渲染 + 真实 FFmpeg 上验证；AI 为脚本导演（测试替身）；供应商配音（中文）待接入。

## 用户目标与入口

- 创作者贴一篇文章或讲稿，AI 写讲述稿、配音、为每个要点配一张图解卡（标题、要点、步骤、引用、柱状图、大数字），得到一条解说视频的第一版；之后在共看片室里像改任何视频一样改。
- 入口：新建页 `/w/:workspaceId/studio/new`"从哪里开始 → 从文章开始"；共看片室顶栏"配音：关/开"。

## 主流程与状态

| 状态 | 表现 |
|---|---|
| 新建 | "从素材开始 / 从文章开始"两张单选卡；选文章后出现文章框（字数 / 40,000）与"AI 配音讲述"（默认勾选，附说明：声音与语言取决于部署的配音引擎）；没贴文章点开始 → 就地提示"请贴上文章" |
| 文章已就绪 | 画布："文章已就绪（N 段）"+ 说明 +"让 AI 讲成视频"（主按钮）+"添加素材"（次按钮） |
| 生成中 | 与普通一轮相同："AI 正在剪…"，可停止 |
| 试改 | 画面播放带讲述与图解卡的试改预览，字幕逐句出现；时间带最上方"特效"轨（✦ 卡片名），"讲述"轨片段上显示讲述稿开头 |
| 规则 | 顶栏"配音：开/关"（`aria-pressed`，提示说明合成配音的含义）；关闭后 AI 加讲述会如实说明需要先开启 |
| 能力不足 | 没配置配音引擎、或没有会说该语言的声音时，AI 回复如实说明（例如中文文章只有英文声音）；数据图里文章没有的数字被拒绝，AI 改用文章原数或改成文字要点 |

## 中英与可访问性

- 文案在 `messages.studioNew`（起点、文章、配音）、`studio.canvas.article*`、`studio.narration`、`studio.strip.narration*`（中英同结构）。
- 起点为 `radiogroup` + `radio`（`aria-checked`）；文章框有可读标签、字数说明经 `aria-describedby` 关联；配音开关 `aria-pressed`；讲述片段可读名称为"片段 讲述「…」，开始 到 结束"。
- 390 px 宽新建页无横向溢出，两张起点卡并排。
