# N16 公开入口与创作台首页 UI 交付卡

| 项目 | 本轮边界 |
|---|---|
| 用户目标、角色与空间 | 访客从 `/welcome` 理解入口并登录；创作者在 `/` 继续实际工作区作品；所有人可从 `/design-system` 查看现行视觉与状态样例。 |
| 入口、对象、范围 | `/welcome`、`/sign-in`、`/`、`/design-system`。项目列表展示 SDK 返回的真实标题、状态和时间；无媒体封面时明确显示中性占位，不伪造项目画面。 |
| 主流程与恢复 | 欢迎页进入登录或现有工作区；登录支持密码、TOTP、失败后重试及返回密码步骤；创作台支持空工作区/空项目、加载/故障重试、项目导航和输入草稿。主题选择仍由共享外观逻辑处理。 |
| 权限、费用与锁定 | 本轮不改变认证、工作区权限、成本或生成规则。欢迎页的工作台视图明确为界面示意，不提交任务、不展示虚构指标。创作台的创建和导航继续使用原 SDK 与服务端权限。 |
| 设计覆盖 | **沿用**已查看 Quiet Frame 01/12/13 的层级、入口、页宽和中文排版；**替代**参考稿及现存代码中与 v0.4 冲突的绿色标题、假趋势曲线、彩色项目封面占位和状态色；**扩展**无封面的可辨认占位、登录异常恢复和黑白状态样例。无新增页面。 |
| 复用与业务依赖 | 复用 `StudioShell`、`StateBlock`、`QuietIcon`、现有 Button/Panel/Token、`useSession`/SDK。页面局部样式仅引用 `ui.*` 语义 Token；contracts、migration、domain、API、SDK 均不适用，原因是本轮不改变业务语义。 |
| 浏览器证据 | 用隔离 GET fixture 检查 `/`、公开页使用未登录状态；以真实浏览器查看 1440×900、1280×800、390×844 的浅/深色、键盘焦点、低动效和必要 200% 缩放，核对截图与网络调用。Fixture 结果不代表真实业务验收。 |

参考图已实际查看：`docs/design-reference/quiet-frame/a04a074c62f0/ANCS_Quiet_Frame/screens/01-workspace.png`、`12-landing.png`、`13-design-system.png`。其彩色内容和纯文章导向不覆盖现行 v0.4 需求。
