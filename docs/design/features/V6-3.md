# V6-3 UI 交付卡｜画圈说"这里加个特效"

**归属：** V6-3 代码生成特效（`docs/V06/milestones/V6-3.md`）；V6 §7.2、§5.1。
**状态：** IN_PROGRESS —— 模板特效全链路已在真实浏览器 + 真实渲染上验证；AI 为脚本导演（测试替身），真实模型待密钥；AI 写特效代码缺省关闭。

## 用户目标与入口

- 创作者在共看片室里暂停到某一刻，在画面上框出一块，说"这里加个爆炸 / 光效"；几秒后在试改里看到特效，满意就"就这样"。说"换成蓝色"只重渲这一层。
- 入口：`/w/:workspaceId/studio/:projectId` 顶栏"特效：关/开"（项目规则开关）、播放条"框选画面"、对话框。

## 主流程与状态

| 状态 | 表现 |
|---|---|
| 特效未开启 | 顶栏"特效：关"（`aria-pressed=false`，提示说明素材作品缺省不加程序化特效）；此时请求特效，AI 回复需要先开启，没有试改 |
| 开启 | 点一下变为"特效：开"（服务端持久化、记事件）；再点关闭 |
| 框选 | "框选画面"→ 画面上出现可拖动的框选层（十字光标）→ 拖出区域后框留在画面上；对话框上方显示"画面区域 · 00:01.0"，可清除 |
| 生成中 | 与普通一轮相同："AI 正在剪…"，可停止 |
| 试改 | 画面播放带特效的试改预览（只重渲受影响的分段）；时间带最上方出现"特效"轨与"✦ 特效名"片段 |
| 已采用 | 特效轨与片段留在时间带上；可"撤销这次修改" |
| 失败 | 渲染失败、门禁不通过等由 AI 如实说明（AI 写的代码不通过时 AI 会修改或换模板） |

## 中英与可访问性

- 文案在 `messages.studio.effects`、`canvas.markArea*`、`pointer.region*`、`strip.effects/effect`（中英同结构）。
- 开关与"框选画面"用 `aria-pressed`；框选层 `role="application"` 带说明；框出的区域 `role="img"` 名为"框出的画面区域"；特效片段的可读名称为"片段 特效 X，开始 到 结束"。
