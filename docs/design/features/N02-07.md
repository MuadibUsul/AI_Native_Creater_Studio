# N02-07｜来源、许可与媒体生命周期

日期：2026-10-09。覆盖类型：**扩展**。

## UI 交付卡

1. **用户目标、角色与空间**：创作者在工作区素材详情确认来源和许可，理解哪些作品或冻结版本仍依赖原件，并选择移除引用、删除原件或请求隐私删除。
2. **入口、对象与范围**：沿用 `/w/:workspaceId/assets` 与项目素材页的素材详情；对象是一个逻辑 Asset 及其不可变 AssetVersion、权利记录、Scene 引用、ProjectVersion 引用和派生边。
3. **主流程与恢复**：打开素材 → 查看许可状态、允许用途、敏感级别和期限 → 编辑并明确声明 → 查看引用/派生 → 可只移除某个 Scene 角色引用。普通删除进入可恢复废纸篓；隐私删除要求输入素材 ID，并在依赖解除后清除原始字节。
4. **权限、发布与删除条件**：读取要求 `workspace:read`；许可更新、引用移除和删除要求 `asset:manage` / `project:write`。许可过期、未确认或不含 `PUBLISH` 时，服务端阻止新发布和导出包。冻结版本、其他 Scene 和派生关系保护 GC。
5. **设计覆盖**：扩展现有素材详情，复用 Panel、Badge、Button、Field、Checkbox 与可折叠危险操作；没有新增后台页。黑白层级不改变视频原色，桌面双列字段在 390px 收为单列。
6. **真实依赖与证据**：PostgreSQL、Fastify、SDK、LocalSignedStorage、production Next、Chromium 和用户提供的真实 MP4。许可与删除不依赖第三方 Provider。

## 状态与恢复语义

- `ACTIVE / EXPIRED / PUBLISH_NOT_PERMITTED / UNCONFIRMED` 是服务端权利状态；UI 不自行推断发布资格。
- “移除这一处引用”复用统一 `replace_asset(newAssetId: null)` 编辑协议，携带项目和 Scene revision，可 Undo；不会删除原件。
- “删除原件到废纸篓”沿用 30 天软删除和恢复路径；引用保护仍在 GC 时执行。
- “隐私删除”单独要求原因和完整素材 ID。存在 Scene 或冻结版本依赖时返回 `DEFERRED_BY_REFERENCES` 和逐项依赖，原件继续保留；无依赖时进入立即清理候选。
- 媒体代理创建时记录 `MEDIA_PROXY` 派生边；来源原件在派生产物存在时不可被普通 GC 清除，派生缓存本身仍可按 TTL 清理。

## 组件与契约

- `AssetLifecyclePanel`：权利编辑、状态、引用、派生、普通删除与隐私删除确认。
- `AssetLifecycle` / `UpdateAssetRightsRequest` / `AssetPrivacyDeletionResult`：公开契约不含存储键、签名 URL 或对象密钥。
- `asset_derivation_edges` 与 `assets.sensitivity_class/privacy_deletion_*`：迁移 0069。
- `assertProjectVersionAssetRights`：冻结版本发布/打包前的权利闸门。
