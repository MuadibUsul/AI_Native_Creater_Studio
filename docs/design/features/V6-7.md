# V6-7 / V6-8 UI 交付卡｜付费生成报价卡 + 我的形象与声音

**归属：** V6-7 数字人与嗓音、V6-8 视频生成重特效（`docs/V06/milestones/V6-7.md`、`V6-8.md`）；V6 §4.3、§7.3、§5.3。
**状态：** IN_PROGRESS —— 全链路已在真实浏览器 + 真实 FFmpeg 上验证；AI 为脚本导演，生成供应商为 FFmpeg 测试替身（卡片上标明）；HeyGen / Fish Audio 适配器待网络放行后做真实验证。

## 用户目标与入口

- 在共看片室里让 AI 用付费生成做素材做不到的事：你的数字人出镜说一段话、生成一个镜头、把框出的区域换成别的画面；**花钱前一定先看到价格并由你确认**。
- 入口：共看片室顶栏"生成：关/开"（制作规则，素材作品默认关）；对话里提出要求后，对话下方出现报价卡；素材面板与数字人报价卡里的"我的形象与声音"；页面 `/w/:workspaceId/studio/identity`。

## 主流程与状态

| 状态 | 表现 |
|---|---|
| 规则关闭 | AI 如实回复"这个作品还没允许付费生成"，提示点顶栏"生成：关" |
| 待确认（报价卡） | 图标 + 类型（数字人出镜 / 生成镜头 / 重绘框出的区域）+ "测试替身"徽标（如是）；AI 写的一句话说明；"约 N 秒 · 预计 $a–$b · 供应商模型 X"；"确认后先从生成预算预留上限；本期还剩 $r"（没设预算时改为说明会被拒绝）；主按钮"确认生成（最多 $b）"、次按钮"不要了"；数字人报价卡附"我的形象与声音"链接 |
| 确认被拒 | 卡片下方说明原因：没设预算、超预算、报价过期、报价变化、授权被撤回、AI 正在处理上一句 |
| 进行中 | "正在生成…只调用一次，不会自动重试。"；对话里出现"你：确认生成：…（预计 …）/ AI：正在生成…"，可停止 |
| 完成 | 对话：AI 回复"…好了：…。实际花费 $x（没报告费用时注明按报价上限计）。已放进试改…"；画面播放试改；时间带出现"重绘框出的区域"/"数字人出镜"片段（数字人另有人声轨）；卡片"生成好了 · 实际花费 $x"，圈外被改时附说明 |
| 失败 / 待对账 | "没有生成成功 · 没有扣费，预留已释放"或"已扣费 $x"；结果不明时以提醒样式说明不会重试、预留暂不释放、等待核对 |
| 过期 / 放弃 | "报价已过期（30 分钟有效），请让 AI 重新报价" / "已放弃这份报价，没有花钱" |
| 我的形象与声音 | 档案卡：形象（照片）与声音（样本）两栏，各有状态徽标（可用于生成 / 先上传参考素材 / 需要授权）、提示、当前参考、上传/更换；有参考未授权时显示声明全文（当前界面语言）+ "这是我本人 / 我已获得本人授权" + "我同意以上声明"；已授权显示时间与对象 + "撤回授权"；换参考后提示需要重新授权；底部"授权记录 (N)"可展开（时间 · 形象/声音 · 授权/撤回 · 声明版本） |

## 中英与可访问性

- 文案在 `messages.studio.generation`、`messages.studio.chat.generating`、`messages.identity`（中英同结构，文案目录测试校验键一致）。
- 报价卡是 `article`，可读名称"类型 · 说明"；进行中为 `status`，待对账与被拒为 `alert`；"生成"开关 `aria-pressed`；身份档案卡是带名称的 `region`；"这是谁"为 `radiogroup`；上传输入有可读标签。
- 报价卡在窄屏横向滚动不挤压对话；身份页两栏在 640 px 以下变为一栏，390 px 无横向溢出。
