# N15-03 UI 交付卡｜限定范围的运营诊断

**状态：** `IN_PROGRESS`；本卡界定 N15-03 的 TEST/STAGING 只读产品切片，不代表 N15-03、O0 或生产运营台整体完成。需求：V04-27/28/29，规范 §28.3—28.5、§29。写动作所需 AdminAction 属 N15-04，当前服务端继续拒绝。

| 项目 | 本轮决定 |
|---|---|
| 用户目标、角色、空间 | `PRODUCTION_OPERATOR` 在 Platform Ops 中查看指定工作区的项目状态与存储用量；`SUPPORT_L2` 携带有限期工作区+工单 scope，查看仅属于当前主体/工单的支持授权，必要时主动打开已获授权的脱敏支持摘要。 |
| 入口、对象、范围 | 沿用 `/admin` 与独立运营 TOTP 会话；明确显示环境、角色和会话到期。输入工作区 ID 后提交诊断；支持人员另输入工单 ID。查询不能跨工作区、跨工单或枚举用户联系方式。生产旧 `/admin/*` 固定拒绝。 |
| 主流程与恢复 | 选择已授权范围 → 查询项目状态/存储或工单授权 → 查看带单位、时间与状态的摘要；网络失败保留输入并允许手动重试。切换已提交范围时清理上一范围可见结果；修改草稿不隐式发请求。只读查询无撤销；打开支持摘要会写访问审计并通知客户，须明确告知后主动触发。 |
| 权限、费用、锁定、审批 | API 以独立 ops session、当前角色、环境、policy hash、workspace/ticket/time scope 判定；UI 只呈现对应角色的可用读操作，后端仍是权威。不读取标题、存储键、客户原片或 Secret。不触发 Provider/生成费用。高风险写无独立审批时既无入口也被服务端 403。 |
| 设计覆盖与复用 | **新增**：参考包 18 张截图无 Platform Ops；沿 v0.4 黑白语义 Token 做紧凑筛选、数据表与详情摘要，复用 `OpsSessionPanel`、`StateBlock`、公共 `.btn`/`.field`。**替代**：旧 `/admin` Tailwind slate/彩色状态卡与可点击却被拒绝的遗留写控件，与当前权限和 §29 冲突；只替换本轮受影响的运营工作区，不改 Studio 或已确认创作页面。 |
| 必要状态 | 未输入范围、加载、空结果、成功、查询失败/手动重试、403 无权、会话过期、工单或限时 scope 过期、支持访问被拒；结果标清当前工作区和工单。未知值显示“未提供”，不造零值或百分比。 |
| 真实依赖与验收 | 0053—0055 角色 scope、策略版本与独立 TOTP；受限项目/存储/支持授权 API、SDK。隔离数据库至少两租户/两主体/两工单；浏览器真实登录完成输入、切换范围、权限拒绝、深浅主题、1440×900/1280×800/窄屏/原生 200%、焦点与低动效，并实际查看截图。证据写 `docs/verification/N15-03.md`。 |
